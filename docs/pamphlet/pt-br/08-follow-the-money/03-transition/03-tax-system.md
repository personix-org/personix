# Sistema Tributário Simples — a Isca de Entrada

A primeira ferramenta é um sistema tributário simples e transparente construído sobre a infraestrutura DID. Uma única alíquota proporcional sobre toda renda. Sem exceções, sem isenções fiscais, sem deduções corporativas, sem incentivos. Cada pagamento é vinculado, de forma auditável, à DID que o pagou. O cruzamento de dados é trivial.

A alíquota seria fixada de forma um pouco mais favorável do que no sistema antigo para uma parcela dos contribuintes — essa é a isca de entrada. A carga tributária declinaria ano após ano, o sistema se tornaria cada vez mais atraente, e a migração ganharia ritmo. O sistema é, ao mesmo tempo, o guardião dos registros e o arrecadador — sem intermediário, sem opacidade.
