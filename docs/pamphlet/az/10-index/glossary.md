# Terminlər Lüğəti

| Termin | Azərbaycanca | Məna |
|------|-------|---------|
| **Authority** | Avtoritet | Məlumatı doğrulayan və ona öz reputasiyasını qoyan etibarlı bir qurum (şəxs, təşkilat). İxtisaslaşmış ola bilər (istintaq, hüquqi, texniki). |
| **Claim** | İddia | Ümumi olaraq: istənilən doğrulana bilən ifadə. Burada: reputasiya şəbəkəsinə dərc olunan qeyd — kriptoqrafik olaraq imzalanmış və doğrulanmış hadisə, xüsusiyyət ya münasibət haqqında bir iddia. Məsələn, “Mən X bələdiyyəsinin sakiniyəm” ya da “bu şəxs müqaviləni pozdu.” |
| **Compartmentalization** | Bölmələnmə | Ümumi olaraq: məlumatı təcrid olunmuş vahidlərə ayırmaq ki, bir vahidin ifşası digərlərini təhlükə altına salmasın. Kəşfiyyat xidmətlərindən tanınan prinsip. Burada: diktaturalarda paralel DID kimlikləri — birinin ifşası digərlərini üzə çıxarmır. |
| **Consistent Hash Ring** | Ardıcıl heş halqası | Doğrulayıcıları seçmək üçün alqoritmik mexanizm — halqadakı mövqe sosial qraf daxilindəki DID sənədinin heşi ilə müəyyən edilir. Qeyri-deterministik, yenə də doğrulana bilən seçimi təmin edir. |
| **DID** | DID (Mərkəzsizləşdirilmiş kimlik) | Özünüzün yaratdığınız və idarə etdiyiniz rəqəmsal kimlik, mərkəzi avtoritet olmadan. Özəl açarınızla kriptoqrafik olaraq imzalanır — heç kim onu ləğv ya saxtalaşdıra bilməz. |
| **DID Document** | DID sənədi | DID kimliyinizi təsvir edən açıq şəkildə əlçatan verilənlər faylı — açıq açarları, şəbəkə ünvanlarını və metadatanı ehtiva edir. Şəbəkədə kimliyinizi doğrulamaq üçün istifadə olunur. |
| **Due Diligence** | Due diligence (əsaslı yoxlama) | Ümumi olaraq: biznes ya hüquqi münasibətə girməzdən əvvəl qarşı tərəfin dərindən yoxlanması — onların tarixçəsinin, maliyyəsinin, reputasiyasının və risklərinin yoxlanması. Burada: reputasiya şəbəkəsində doğrulanmış qeydlərin əlçatanlığı sayəsində daha tez və daha avtomatik baş verir. |
| **Economic Neutrality Principle** | İqtisadi neytrallıq prinsipi | Şəbəkədə dürüst davranış iqtisadi olaraq sıfıra yaxındır — dərc xərcləri doğrulama mükafatları kimi geri qayıdır. Dürüstsüz davranış xalis itkidir. |
| **Emergent** | Yaranan | Heç kimin dizayn ya idarə etmədən daha sadə hissələrin qarşılıqlı əlaqələrindən özbaşına yaranan. Bir quş sürüsü plansız səf halında uçur — səf hər fərdin riayət etdiyi sadə qaydalardan yaranır. |
| **Emergent Social Contract** | Yaranan sosial müqavilə | Yuxarıdan (qanun) deyil, aşağıdan — icma daxilindəki təkrar qarşılıqlı əlaqələrdən və konsensusdan — yaranan davranış qaydaları. |
| **ESR** | Electronic Spending Register (Elektron Xərc Reyestri) | İctimai xərclərin şəffaf izlənməsi üçün təklif olunan sistem — dövlətin hər reallaşdırılmış xərci planlaşdırılmış ödənişlə uyğunlaşdırılır. Çex EET-dən ilham alıb, amma dövlətə qarşı çevrilib. |
| **Hash** | Heş (barmaq izi) | Ümumi olaraq: istənilən girişdən unikal sabit uzunluqlu “barmaq izi” yaradan birtərəfli riyazi funksiya — sənədin barmaq izi kimi. Eyni giriş həmişə eyni çıxış verir, amma çıxışdan giriş çıxarıla bilməz. Burada: heş halqasında mövqeyi müəyyən etmək və sənədin bütövlüyünü yoxlamaq üçün istifadə olunur. |
| **Just-in-Time Funding** | Tam vaxtında maliyyələşdirmə | Şəffaflıqdan asılı dövlət maliyyələşdirməsi — pul yalnız dövlət ESR-i qəbul edib xərclərini uyğunlaşdırdıqda axır. Əməkdaşlığa məcbur etmək üçün rıçaq. |
| **Meritocracy** | Meritokratiya | Ümumi olaraq: mövqeyin formal titullar, əlaqələr ya irsən keçən imtiyazla deyil, faktiki ləyaqət və sübut olunmuş qabiliyyətlə müəyyən edildiyi sistem. Burada: reputasiya şəbəkəsi təbii şəkildə icmaya sübut oluna bilən töhfə verənlərin xeyrinədir — onların səsi vəzifəyə görə deyil, keçmiş nailiyyətlər tarixçəsinə görə daha çox çəki daşıyır. |
| **Onion Gateway** | Onion gateway | DID kimliyinin onion şəbəkəsindəki şəbəkə ünvanı. DID sənədindən ayrıdır — kimliyi itirmədən dəyişdirilə bilər (domenin arxasındakı IP ünvanının dəyişdirilməsi kimi). |
| **Onion Routing** | Onion routing (Tor) | Şəbəkənin senzura edilə bilməzliyini təmin edən ünsiyyət protokolu. Mesajlar qatlarla şifrələnir — hər qovşaq bir qatı soyur, amma tam yolu bilmir. |
| **Oracle Problem** | Orakul problemi | Ümumi olaraq: rəqəmsal sistemə daxil olan məlumatın fiziki dünyada əslində baş verənə sədaqətlə uyğun gəlməsini necə təmin etmək. Termin blokçeyn sahəsindən qaynaqlanır. Burada: rəqəmsal qeydin fiziki reallığa uyğun gəldiyinə zəmanət kimi öz reputasiyasını ortaya qoyan avtoritetlər vasitəsilə həll edilir. |
| **Phenomenological** | Fenomenoloji | Ümumi olaraq: hadisələri birbaşa təcrübədə özlərini göstərdikləri kimi, onlardan nəyin çıxdığını müşahidə edərək, əvvəlcədən verilmiş nəzəriyyələr olmadan öyrənən yanaşma. Burada: azadlıq, sosial müqavilə və davranış normaları müşahidə olunan hadisələrdir — yuxarıdan müəyyən edilmiş prinsiplər deyil, insanlar arasındakı minlərlə mikro-qarşılıqlı əlaqənin nəticələri. |
| **Policy** | Policy (siyasət) | Ümumi olaraq: verilmiş kontekstdə davranışı tənzimləyən qaydalar ya prinsiplər toplusu. Burada: DID şəbəkəsindəki hər iştirakçı öz siyasətini bəyan edir — başqalarının konkret davranışına necə reaksiya verdiyini, hansı qaydalara riayət etdiyini və hansı cəzaları mütənasib saydığını. Siyasətlərin cəmi yaranan sosial müqaviləni formalaşdırır. |
| **Proxy** | Proksi | Ümumi olaraq: əvəzedici ya vasitəçi — başqasının adından çıxış edən bir sistem ya qurum. Burada iki kontekstdə istifadə olunur: (1) ESR ictimai xərcləri planlaşdırılmış ödənişlərlə uyğunlaşdıran proksi kimi; (2) müşahidəçi fəndində naşir ilə doğrulayıcı arasında müşahidəçilər proksi kimi. |
| **Publisher** | Naşir | Qeyd yaradan və dərc edən şəbəkə iştirakçısı (haqsızlıq, düzəltmə və s. haqqında iddia). Dərcin xərcini daşıyır. |
| **Reputation-Based Social Network (RSN)** | Reputasiya şəbəkəsi | İştirakçıların real dünyadakı davranış haqqında geribildirim mübadiləsi etdiyi mərkəzsizləşdirilmiş sosial şəbəkə. Qeydlərin yaradılması baha, oxunması ucuzdur. |
| **Reputation Signal** | Reputasiya siqnalı | Şəbəkədəki fərdi qeyd — müsbət (zərərin düzəldilməsi, öhdəliyin yerinə yetirilməsi) ya da mənfi (haqsızlıq, müqavilənin pozulması). Cəmlənərək siqnallar reputasiya profili formalaşdırır. |
| **Social Graph** | Sosial qraf | Sizin kontaktlarınızın və kontaktlarınızın kontaktlarının şəbəkəsi. Alqoritm doğrulayıcıları konfiqurasiya oluna bilən dərinlikdə axtarır (məsələn, 3 səviyyə). Qlobal blokçeyn yoxdur — şəbəkə təbii şəkildə üst-üstə düşmələrlə icmalar formalaşdırır. |
| **Tax Allocation** | Vergi bölüşdürməsi | Vergiödəyicinin vergisinin bir hissəsinin hara getdiyinə qərar verdiyi mexanizm. Bölüşdürülə bilən faiz ildən-ilə artır. |
| **Track Record** | Keçmiş nailiyyətlər tarixçəsi | Ümumi olaraq: bir insanın ya təşkilatın keçmiş nəticələrinin, uğurlarının və uğursuzluqlarının tarixi. Burada: verilmiş DID kimliyinin şəbəkədəki bütün keçmiş qarşılıqlı əlaqələrinin cəmi — doğrulanmış iddialar, qəbul və rədd edilmiş qeydlər — ki, onun reputasiyası bundan törəyir. |
| **Verifier** | Doğrulayıcı | Bir qeydi doğrulamaq və dərc etmək üçün alqoritmik olaraq seçilmiş iştirakçı. Məlumatın doğruluğuna öz yaxşı adını qoyur. |
