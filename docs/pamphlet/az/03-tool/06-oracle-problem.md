# Orakul Problemi — Rəqəmsal və Fiziki Dünyalar Arasında Körpü

“Orakul problemi” termini son zamanlar ən çox kriptovalyutalar, blokçeynlər və mərkəzsizləşdirilmiş sistemlər dünyası ilə əlaqələndirilir. Ümumi olaraq: rəqəmsal sistemə daxil olan məlumatın fiziki dünyada əslində baş verənə sədaqətlə uyğun gəldiyini necə təmin edirsiniz? Sistem özü kiminsə həqiqətən başqasına zərər vurub-vurmadığını, ya da müqavilənin həqiqətən pozulub-pozulmadığını doğrulaya bilməz — o, yalnız rəqəmsal qeydləri görür.

Burada biz bunu avtoritetlər vasitəsilə həll edirik — rəqəmsal qeydin fiziki reallığa uyğun gəldiyinə öz reputasiyalarını qoyan qurumlar. Avtoritetin reputasiyası nə qədər yüksəkdirsə, qeyd bir o qədər etibarlıdır.
