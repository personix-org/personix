# Rollara Baxış

Şəbəkə və onun əsas xüsusiyyətləri haqqındakı fəsildə bu rollardan bəzilərinə artıq qısaca toxunmuşduq. İndi onlara yenidən daha ətraflı baxmağın və şəbəkəni daha möhkəm etmək üçün lazım olan əlavələri qatmağın vaxtıdır. Hər doğrulama əməliyyatı bir neçə rolu əhatə edir — gəlin onların necə davrandığına baxaq.

> [!note] Doğrulama Əməliyyatındakı Rollar
> Hər doğrulama aşağıdakı cədvəldə xülasə edilmiş altıya qədər fərqli rolu əhatə edir. Onların hamısının mərkəzsizləşdirilmiş reputasiya şəbəkəsində öz DID-i ola bilər.

| Rol | Təsvir |
| --------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Naşir** | Şəbəkəyə məlumat dərc edən şəxs — nəyinsə baş verdiyini iddia edən (bir DID yaradıldı, redaktə edildi ya da ləğv edildi, bir iddia, verilmiş DID-in siyasəti və s.) |
| **Subyekt** | Məlumatın haqqında olduğu şəxs — iddianın ünvanlandığı tərəf |
| **Avtoritet** | İddianı araşdıraraq və ya təqdim edilən sübutu nəzərdən keçirərək, ya da onu aktiv şəkildə toplayaraq iddianın keyfiyyətinə öz adını qoyan etibarlı qurum |
| **Müşahidəçi** | Doğrulayıcının iddianı necə idarə etdiyini qeyd edən müstəqil üçüncü tərəf — doğrulayıcının nə susduğuna, nə də bəyan etdiyi siyasətdən saptığına əmin olan |
| **Doğrulayıcı** | Əməliyyatı emal edən alqoritmik olaraq seçilmiş iştirakçı |
| **Səlahiyyətli (delegat)** | Başqa bir iştirakçının adından çıxış edən şəxs |
