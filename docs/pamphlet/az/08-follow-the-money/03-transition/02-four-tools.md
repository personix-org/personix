# Bir-birini Dəstəkləyən Dörd Alət

İndiyə qədər DID reputasiya şəbəkəsi əsasən ədalət və konsensus üçün faydalı görünmüş ola bilər. İnanıram ki, o, özünü sabitləşdirə və hücumlara tab gətirə bilər — meritokratik olaraq, formal titullar deyil, faktiki ləyaqət əsasında. Amma reputasiya təkbaşına dövləti geri çəkilməyə məcbur etməyəcək. İqtisadiyyat edəcək və onun vasitəsilə tətbiq olunan təzyiq.

Heç nə bizə DID kimliklərini pula bərk təzyiq edən əlavə alətlərin menecerləri kimi istifadə etməyə mane olmur. Vətəndaşların tam könüllülüyü ilə başlamayın — dövlətin dayandıra bilməyəcəyi bir istiqamət qoyun. Keçid bir-birinin arxasını möhkəmləndirən dörd konkret alətə söykənir. Onların heç biri təkbaşına kifayət deyil.
