# Օրակուլի խնդիրը — կամրջելով թվային և ֆիզիկական աշխարհները

«Օրակուլի խնդիր» տերմինը վերջին ժամանակներում ամենից հաճախ ասոցացվում է կրիպտոարժույթների, բլոկչեյնների և ապակենտրոնացված համակարգերի աշխարհի հետ։ Ընդհանուր առմամբ․ ինչպե՞ս ապահովել, որ թվային համակարգ մուտք գործող տվյալները հավատարմորեն համապատասխանեն նրան, ինչ իրականում տեղի է ունեցել ֆիզիկական աշխարհում։ Համակարգն ինքն իրեն չի կարող ստուգել, թե արդյոք մեկն իսկապես վնաս է հասցրել մյուսին, կամ արդյոք պայմանագիրն իսկապես խախտվել է — այն տեսնում է միայն թվային գրառումներ։

Այստեղ մենք սա լուծում ենք հեղինակությունների միջոցով — սուբյեկտներ, որ իրենց հեղինակությունը գրավ են դնում այն բանի վրա, որ թվային գրառումը համապատասխանում է ֆիզիկական իրականությանը։ Որքան բարձր է հեղինակության հեղինակությունը, այնքան ավելի վստահելի է գրառումը։
