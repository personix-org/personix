# Ինչու է ցանցն անգրաքննելի

Մինչ այժմ նկարագրեցինք, թե ինչ կարող է անել ցանցը։ Այժմ կենտրոնանանք, թե ինչու այն հնարավոր չէ փակել կամ գրաքննել։

Ցանցն ամենայն հավանականությամբ կկառուցվի Tor ցանցի և onion երթուղավորման (Mixnet սկզբունքներով ցանցային տրաֆիկը քողարկելու եղանակ) սկզբունքների վրա — տեխնոլոգիա, որտեղ հաղորդակցությունն անցնում է կոդավորման մի քանի շերտով, և ոչ մի առանձին հանգույց միաժամանակ չգիտի և՛ ուղարկողին, և՛ ստացողին։ Կենտրոնական ինստիտուտը չի կարող քո ուսի վրայից նայել, քանի որ չկա տեղ, որտեղից նայել։

Կարող ես պայքարել դրա դեմ, բայց չես կարող հաղթել — եթե ամբողջ երկիրը չընկղմես տոտալիտար հսկողության մեջ առանձին ցանցային փաթեթների և ինտերնետին միացող ու տվյալ հեղինակության ցանցում հաղորդակցվող ամեն մի սարքի ցածր մակարդակի գործողությունների մակարդակով։ Եվ հենց սա է այն ընտրությունը, որ կանգնած է ցենտրալիզմի առջև․ կա՛մ ընդունել, որ քաղաքացիներն ունեն քեզ անհասանելի գործիք, կա՛մ քեզ փորել տնտեսական լճացման մութ անկյուններում՝ տոտալիտար վերահսկողության անունով։

Եկեք պատրանքներ չունենանք — նույնիսկ ժողովրդավարական ռեժիմները կփորձեն սա՝ ցենտրալիզմի համար իրենց պայքարում։ Նրանք կնախընտրեն մարդկանց շղթայել, քան հանձնել իշխանությունը։
