# Պարզ հարկային համակարգ — մուտքի խայծը

Առաջին գործիքը պարզ, թափանցիկ հարկային համակարգ է՝ կառուցված DID ենթակառուցվածքի վրա։ Միասնական համաչափ դրույք ամբողջ եկամտի վրա։ Ոչ մի բացառություն, ոչ մի հարկային արձակուրդ, ոչ մի կորպորատիվ նվազեցում, ոչ մի խթան։ Ամեն վճարում աուդիտով կապվում է այն DID-ի հետ, որ վճարել է։ Խաչաձև ստուգումը տրիվիալ է։

Դրույքը կսահմանվեր որոշ չափով ավելի բարենպաստ, քան հին համակարգում՝ հարկատուների մի մասի համար — դա մուտքի խայծն է։ Հարկային բեռը կնվազեր տարեցտարի, համակարգը կդառնար էլ ավելի գրավիչ, և միգրացիան կհավաքեր տեմպ։ Համակարգը միաժամանակ և՛ գրառումների վարողն է, և՛ հավաքողը — ոչ մի միջնորդ, ոչ մի անթափանցություն։
