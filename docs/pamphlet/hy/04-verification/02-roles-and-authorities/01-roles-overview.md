# Դերերի ակնարկ

Այս դերերից մի քանիսին համառոտ անդրադարձանք արդեն ցանցի ու դրա հիմնական հատկությունների մասին գլխում։ Հիմա ժամանակն է կրկին ավելի մանրամասն դիտարկել դրանք և ավելացնել լրացուցիչները, որ պետք են ցանցն ավելի ամուր դարձնելու համար։ Յուրաքանչյուր ստուգման գործարք ներառում է մի քանի դեր — տեսնենք, թե ինչպես են դրանք վարվում։

> [!note] Դերերը ստուգման գործարքում
> Յուրաքանչյուր ստուգում ներառում է մինչև վեց տարբեր դեր՝ ամփոփված ներքևի աղյուսակում։ Դրանք բոլորն էլ կարող են ունենալ իրենց սեփական DID-ն ապակենտրոնացված հեղինակության ցանցում։

| Դեր | Նկարագրություն |
| --------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Թողարկող** | Այն մարդը, ով ցանցում տեղեկություն է հրապարակում — պնդում է, որ ինչ-որ բան տեղի է ունեցել (ստեղծվել, խմբագրվել կամ լուծարվել է DID, պնդում, տվյալ DID-ի քաղաքականություն և այլն) |
| **Սուբյեկտ** | Այն մարդը, ում մասին է տեղեկությունը — պնդման հասցեատերը |
| **Հեղինակություն** | Վստահելի սուբյեկտ, որ իր անունը գրավ է դնում պնդման որակի վրա՝ քննելով այն և կա՛մ վերանայելով ներկայացված ապացույցները, կա՛մ ակտիվորեն հավաքելով դրանք |
| **Դիտորդ** | Անկախ երրորդ կողմ, որ գրառում է վարում, թե ինչպես է ստուգողը վարվում պնդման հետ — համոզվելով, որ ստուգողը ոչ լռում է, ոչ էլ շեղվում իր հայտարարած քաղաքականությունից |
| **Ստուգող** | Ալգորիթմային կերպով ընտրված մասնակից, որ մշակում է գործարքը |
| **Պատվիրակ** | Այլ մասնակցի անունից հանդես եկող մարդ |
