# Բառարան

| Տերմին | Հայերեն | Իմաստ |
|------|-------|---------|
| **Authority** | Հեղինակություն | Վստահելի սուբյեկտ (մարդ, կազմակերպություն), որ ստուգում է տեղեկությունը և իր հեղինակությունը գրավ դնում դրա վրա։ Կարող է լինել մասնագիտացված (քննչական, իրավական, տեխնիկական)։ |
| **Claim** | Պնդում | Ընդհանուր առմամբ․ ցանկացած ստուգելի հայտարարություն։ Այստեղ․ հեղինակության ցանց հրապարակված գրառում — պնդում իրադարձության, հատկության կամ հարաբերության մասին, որ կրիպտոգրաֆիկորեն ստորագրված ու ստուգված է։ Օր. «Ես X համայնքի բնակիչ եմ» կամ «այս մարդը խախտել է պայմանագիրը»։ |
| **Compartmentalization** | Բաժանում | Ընդհանուր առմամբ․ տեղեկությունը մեկուսացված միավորների բաժանելը, որպեսզի մի միավորի բացահայտումը չկոմպրոմատացնի մյուսներին։ Հետախուզական ծառայություններից հայտնի սկզբունք։ Այստեղ․ զուգահեռ DID ինքնություններ բռնապետություններում — մեկի կոմպրոմատացումը չի բացահայտում մյուսներին։ |
| **Consistent Hash Ring** | Հետևողական հեշ օղակ | Ստուգողներ ընտրելու ալգորիթմային մեխանիզմ — օղակի վրա դիրքը որոշվում է սոցիալական գրաֆում DID փաստաթղթի հեշով։ Ապահովում է ոչ դետերմինիստիկ, բայց ստուգելի ընտրություն։ |
| **DID** | DID (Ապակենտրոնացված ինքնություն) | Թվային ինքնություն, որ ստեղծում ու վերահսկում ես ինքդ՝ առանց կենտրոնական հեղինակության։ Կրիպտոգրաֆիկորեն ստորագրված է քո մասնավոր բանալիով — ոչ ոք չի կարող այն չեղարկել կամ կեղծել։ |
| **DID Document** | DID փաստաթուղթ | Հրապարակայնորեն հասանելի տվյալների ֆայլ, որ նկարագրում է քո DID ինքնությունը — պարունակում է հանրային բանալիներ, ցանցային հասցեներ և մետատվյալներ։ Օգտագործվում է ցանցում քո ինքնությունը ստուգելու համար։ |
| **Due Diligence** | Դյու դիլիջենս | Ընդհանուր առմամբ․ կոնտրագենտի խորը ստուգում մինչ գործարար կամ իրավական հարաբերության մեջ մտնելը — նրա պատմության, ֆինանսների, հեղինակության ու ռիսկերի ստուգում։ Այստեղ․ հեղինակության ցանցում այն կատարվում է ավելի արագ ու ավտոմատ՝ ստուգված գրառումների հասանելիության շնորհիվ։ |
| **Economic Neutrality Principle** | Տնտեսական չեզոքության սկզբունք | Ցանցում ազնիվ վարքը տնտեսապես մոտ է զրոյի — հրապարակման ծախսերը վերադարձվում են որպես ստուգման վարձատրություն։ Անազնիվ վարքը զուտ կորուստ է։ |
| **Emergent** | Ի հայտ եկող | Ինքնաբերաբար ծագող ավելի պարզ մասերի փոխազդեցություններից՝ առանց որևէ մեկի կողմից նախագծելու կամ ուղղորդելու։ Թռչունների երամը թռչում է կազմով՝ առանց պլանի — կազմն ի հայտ է գալիս յուրաքանչյուրի կողմից հետևվող պարզ կանոններից։ |
| **Emergent Social Contract** | Ի հայտ եկող հասարակական պայմանագիր | Վարքի կանոններ, որ ծագում են ոչ թե վերևից (օրենք), այլ ներքևից — համայնքի ներսում կրկնվող փոխազդեցություններից ու կոնսենսուսից։ |
| **ESR** | Ծախսերի էլեկտրոնային ռեգիստր | Հանրային ծախսերի թափանցիկ հետևման առաջարկվող համակարգ — պետության ամեն իրականացված ծախս համապատասխանեցվում է պլանավորված վճարման։ Ներշնչված չեխական EET-ից, բայց շրջված պետության դեմ։ |
| **Hash** | Հեշ (մատնահետք) | Ընդհանուր առմամբ․ միակողմանի մաթեմատիկական ֆունկցիա, որ ցանկացած մուտքից ստեղծում է եզակի ֆիքսված երկարությամբ «մատնահետք» — ինչպես փաստաթղթի մատնահետք։ Նույն մուտքը միշտ նույն ելքն է տալիս, բայց մուտքը հնարավոր չէ ելքից բխեցնել։ Այստեղ․ օգտագործվում է հեշ օղակի վրա դիրք որոշելու և փաստաթղթի ամբողջականությունը ստուգելու համար։ |
| **Just-in-Time Funding** | Ճիշտ ժամանակին ֆինանսավորում | Պետության ֆինանսավորում՝ պայմանավորված թափանցիկությամբ — փողը հոսում է միայն երբ պետությունն ընդունում է ESR-ը և համապատասխանեցնում իր ծախսերը։ Համագործակցության հարկադրման լծակ։ |
| **Meritocracy** | Մերիտոկրատիա | Ընդհանուր առմամբ․ համակարգ, որտեղ դիրքը որոշվում է փաստացի արժանիքով ու ապացուցված ունակությամբ, ոչ թե ֆորմալ կոչումներով, կապերով կամ ժառանգված արտոնությամբ։ Այստեղ․ հեղինակության ցանցը բնականաբար նախապատվություն է տալիս նրանց, ովքեր ապացուցելիորեն նպաստում են համայնքին — նրանց ձայնն ավելի մեծ կշիռ է կրում հետագծի, ոչ թե պաշտոնի շնորհիվ։ |
| **Onion Gateway** | Onion gateway | DID ինքնության ցանցային հասցեն onion ցանցում։ DID փաստաթղթից առանձին — այն կարելի է փոխել առանց ինքնությունը կորցնելու (նման է դոմենի հետևում IP հասցեն փոխելուն)։ |
| **Onion Routing** | Onion routing (Tor) | Հաղորդակցման արձանագրություն, որ ապահովում է ցանցի անգրաքննելիությունը։ Հաղորդագրությունները կոդավորվում են շերտերով — յուրաքանչյուր հանգույց հանում է մեկ շերտ, բայց չգիտի ամբողջ ուղին։ |
| **Oracle Problem** | Օրակուլի խնդիր | Ընդհանուր առմամբ․ ինչպես ապահովել, որ թվային համակարգ մուտք գործող տվյալները հավատարմորեն համապատասխանեն նրան, ինչ իրականում տեղի է ունեցել ֆիզիկական աշխարհում։ Տերմինը ծագում է բլոկչեյնի ոլորտից։ Այստեղ․ լուծվում է հեղինակությունների միջոցով, ովքեր իրենց հեղինակությունը գրավ են դնում որպես երաշխիք, որ թվային գրառումը համապատասխանում է ֆիզիկական իրականությանը։ |
| **Phenomenological** | Ֆենոմենոլոգիական | Ընդհանուր առմամբ․ մոտեցում, որ ուսումնասիրում է երևույթներն այնպես, ինչպես դրանք դրսևորվում են ուղիղ փորձառության մեջ՝ դիտարկելով, թե ինչ է դրանցից բխում, առանց նախապես տրված տեսությունների։ Այստեղ․ ազատությունը, հասարակական պայմանագիրը և վարքի նորմերը դիտարկվող երևույթներ են — մարդկանց միջև հազարավոր միկրոփոխազդեցությունների հետևանք, ոչ թե վերևից սահմանված սկզբունքներ։ |
| **Policy** | Policy (քաղաքականություն) | Ընդհանուր առմամբ․ տվյալ համատեքստում վարքը ղեկավարող կանոնների կամ սկզբունքների ամբողջություն։ Այստեղ․ DID ցանցի յուրաքանչյուր մասնակից հայտարարում է իր քաղաքականությունը — ինչպես է արձագանքում ուրիշների կոնկրետ վարքին, որ կանոններին է հետևում, և որ պատիժներն է համարում համաչափ։ Քաղաքականությունների ագրեգատը կազմում է ի հայտ եկող հասարակական պայմանագիրը։ |
| **Proxy** | Պրոքսի | Ընդհանուր առմամբ․ փոխարինող կամ միջնորդ — համակարգ կամ սուբյեկտ, որ հանդես է գալիս մեկ ուրիշի անունից։ Այստեղ օգտագործվում է երկու համատեքստում․ (1) ESR-ը որպես պրոքսի, որ համապատասխանեցնում է հանրային ծախսերը պլանավորված վճարումների հետ. (2) դիտորդները որպես պրոքսի հրապարակողի ու ստուգողի միջև՝ դիտորդի հնարքում։ |
| **Publisher** | Հրապարակող | Ցանցի մասնակից, որ ստեղծում ու հրապարակում է գրառում (պնդում անարդարության, շտկման և այլնի մասին)։ Կրում է հրապարակման ծախսը։ |
| **Reputation-Based Social Network (RSN)** | Հեղինակության ցանց | Ապակենտրոնացված սոցիալական ցանց, որտեղ մասնակիցները փոխանակում են հետադարձ կապ իրական աշխարհում վարքի մասին։ Գրառումները ծախսատար են ստեղծել, էժան՝ կարդալ։ |
| **Reputation Signal** | Հեղինակության ազդանշան | Ցանցում առանձին գրառում — դրական (վնասի շտկում, պարտավորության կատարում) կամ բացասական (անարդարություն, պայմանագրի խախտում)։ Կուտակվելով՝ ազդանշանները կազմում են հեղինակության պրոֆիլ։ |
| **Social Graph** | Սոցիալական գրաֆ | Քո կոնտակտների և քո կոնտակտների կոնտակտների ցանցը։ Ալգորիթմը փնտրում է ստուգողներ կարգավորելի խորությամբ (օրինակ՝ 3 մակարդակ)։ Ոչ մի գլոբալ բլոկչեյն — ցանցը բնականաբար ձևավորում է համայնքներ՝ համընկնումներով։ |
| **Tax Allocation** | Հարկերի բաշխում | Մեխանիզմ, որով հարկատուն որոշում է, թե ուր է գնում իր հարկերի մի մասը։ Բաշխելի տոկոսն աճում է տարեցտարի։ |
| **Track Record** | Հետագիծ (track record) | Ընդհանուր առմամբ․ մարդու կամ կազմակերպության անցյալ արդյունքների, հաջողությունների ու ձախողումների պատմություն։ Այստեղ․ ցանցում տվյալ DID ինքնության բոլոր անցյալ փոխազդեցությունների գումարը — ստուգված պնդումներ, ընդունված ու մերժված գրառումներ — որից բխում է դրա հեղինակությունը։ |
| **Verifier** | Ստուգող | Մասնակից, որ ալգորիթմային կերպով ընտրվում է գրառումը ստուգելու ու հրապարակելու համար։ Իր բարի անունը գրավ է դնում տեղեկության ճշմարտացիության վրա։ |
