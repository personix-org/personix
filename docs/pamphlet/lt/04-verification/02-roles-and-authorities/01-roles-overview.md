# Vaidmenų apžvalga

Kai kuriuos iš šių vaidmenų jau trumpai palietėme skyriuje apie tinklą ir jo pagrindines savybes. Dabar metas pažvelgti į juos vėl išsamiau ir pridėti papildomus, kurių reikia, kad tinklas taptų tvirtesnis. Kiekvienoje patikros transakcijoje dalyvauja keli vaidmenys — pažiūrėkime, kaip jie elgiasi.

> [!note] Vaidmenys patikros transakcijoje
> Kiekvienoje patikroje dalyvauja iki šešių atskirų vaidmenų, apibendrintų toliau esančioje lentelėje. Visi jie gali turėti savo DID decentralizuotame reputacijos tinkle.

| Vaidmuo | Aprašymas |
| --------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Išdavėjas** | Asmuo, skelbiantis informaciją tinkle — teigiantis, kad kažkas įvyko (DID buvo sukurta, redaguota ar panaikinta, teiginys, duotosios DID politika ir t. t.) |
| **Subjektas** | Asmuo, apie kurį yra informacija — teiginio adresatas |
| **Autoritetas** | Patikimas subjektas, statantis savo vardą ant teiginio kokybės, jį tirdamas ir arba peržiūrėdamas pateiktus įrodymus, arba aktyviai juos rinkdamas |
| **Stebėtojas** | Nepriklausoma trečioji šalis, fiksuojanti, kaip tikrintojas tvarko teiginį — užtikrinanti, kad tikrintojas nei nutylėtų, nei nukryptų nuo deklaruotos politikos |
| **Tikrintojas** | Algoritmiškai parinktas dalyvis, apdorojantis transakciją |
| **Įgaliotinis** | Asmuo, veikiantis kito dalyvio vardu |
