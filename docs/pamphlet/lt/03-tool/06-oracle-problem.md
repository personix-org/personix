# Orakulo problema — tiltas tarp skaitmeninio ir fizinio pasaulio

Terminas „orakulo problema“ pastaruoju metu dažniausiai siejamas su kriptovaliutų, blokų grandinių ir decentralizuotų sistemų pasauliu. Bendrai: kaip užtikrinti, kad į skaitmeninę sistemą patenkantys duomenys ištikimai atitiktų tai, kas iš tikrųjų nutiko fiziniame pasaulyje? Pati sistema negali patikrinti, ar kas nors iš tiesų padarė kam nors žalą, ar sutartis tikrai buvo pažeista — ji mato tik skaitmeninius įrašus.

Čia tai sprendžiame per autoritetus — subjektus, statančius savo reputaciją ant to, kad skaitmeninis įrašas atitinka fizinę tikrovę. Kuo aukštesnė autoriteto reputacija, tuo patikimesnis įrašas.
