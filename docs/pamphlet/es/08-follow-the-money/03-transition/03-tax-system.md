# Un sistema fiscal simple — el señuelo de entrada

La primera herramienta es un sistema fiscal simple y transparente construido sobre la infraestructura DID. Un único tipo proporcional sobre todos los ingresos. Sin excepciones, sin exenciones fiscales, sin deducciones para empresas, sin incentivos. Cada pago queda auditablemente vinculado a la DID que lo abonó. El cruce de datos es trivial.

El tipo se fijaría algo más favorable que en el viejo sistema para una parte de los contribuyentes: ese es el señuelo de entrada. La carga fiscal iría descendiendo año tras año, el sistema resultaría cada vez más atractivo, y la migración cobraría ritmo. El sistema es a la vez el registrador y el recaudador: sin intermediario, sin opacidad.
