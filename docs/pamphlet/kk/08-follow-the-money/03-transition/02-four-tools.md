# Бір-бірін тіреп тұратын төрт құрал

Осыған дейін DID беделдік желісі негізінен әділдік пен консенсус үшін пайдалы болып көрінген болар. Ол өзін тұрақтандырып, шабуылдарға төтеп бере алады деп сенемін — меритократиялық түрде, формальды атақтарға емес, нақты еңбекке сүйене отырып. Бірақ бедел жалғыз өзі мемлекетті ырық беруге мәжбүрлемейді. Экономика мәжбүрлейді, әрі ол арқылы қолданылатын қысым.

DID сәйкестіктерін ақшаны қатты қысатын қосымша құралдардың менеджерлері ретінде пайдалануға ешнәрсе кедергі болмайды. Азаматтар тарапынан толық еріктіліктен бастамаңыз — мемлекет тоқтата алмайтын бағыт белгілеңіз. Өту бір-бірінің арқасын тіреп тұратын төрт нақты құралға сүйенеді. Олардың бірде-бірі жеке дара жеткіліксіз.
