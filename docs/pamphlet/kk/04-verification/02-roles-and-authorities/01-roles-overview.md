# Рөлдерге шолу

Осы рөлдердің кейбіріне желі мен оның негізгі қасиеттері туралы тарауда қысқаша тоқталған едік. Енді оларға тағы да толығырақ қарап, желіні берігірек ету үшін қажет қосымша рөлдерді енгізетін уақыт келді. Әр тексеру транзакциясы бірнеше рөлді қамтиды — олардың қалай әрекет ететінін көрейік.

> [!note] Тексеру транзакциясындағы рөлдер
> Әр тексеру алты дербес рөлге дейінгіні қамтиды, олар төмендегі кестеде жинақталған. Олардың бәрінде орталықсыздандырылған беделдік желіде өз DID-і болуы мүмкін.

| Рөл | Сипаттама |
| --------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Issuer** | Желіге ақпарат жариялайтын адам — бір нәрсе болғанын мәлімдейді (DID жасалды, өңделді немесе таратылды, мәлімдеме, берілген DID саясаты және т.б.) |
| **Subject** | Ақпарат кім туралы болса — мәлімдеменің адресаты |
| **Authority** | Мәлімдемені тергеп, ұсынылған дәлелдерді қарастыру немесе оларды белсенді жинау арқылы мәлімдеменің сапасына өз атын тігетін сенімді субъект |
| **Observer** | Тексеруші мәлімдемені қалай өңдейтінін жазып отыратын тәуелсіз үшінші тарап — тексеруші үнсіз де қалмайтынына, жариялаған саясатынан да ауытқымайтынына көз жеткізеді |
| **Verifier** | Транзакцияны өңдейтін алгоритмдік түрде таңдалған қатысушы |
| **Delegate** | Басқа қатысушының атынан әрекет ететін адам |
