# Глоссарий

| Термин | Қазақша | Мағынасы |
|------|-------|---------|
| **Authority** | Авторитет | Ақпаратты тексеретін және оған өз беделін тігетін сенімді субъект (адам, ұйым). Мамандандырылған болуы мүмкін (тергеу, құқықтық, техникалық). |
| **Claim** | Мәлімдеме | Жалпы: кез келген тексерілетін тұжырым. Мұнда: беделдік желіге жарияланған жазба — криптографиялық қол қойылған және тексерілген оқиға, қасиет немесе қатынас туралы тұжырым. Мысалы, «мен X муниципалитетінің тұрғынымын» немесе «бұл адам шартты бұзды». |
| **Compartmentalization** | Компартментализация | Жалпы: бір бірлікті әшкерелеу басқаларын әшкерелемейтіндей ақпаратты оқшауланған бірліктерге бөлу. Барлау қызметтерінен белгілі қағидат. Мұнда: диктатуралардағы параллель DID сәйкестіктер — біреуін әшкерелеу басқаларын ашпайды. |
| **Consistent Hash Ring** | Хеш сақина | Тексерушілерді таңдаудың алгоритмдік тетігі — сақинадағы орын әлеуметтік граф ішіндегі DID құжатының хешімен анықталады. Детерминистік емес, бірақ тексерілетін таңдауды қамтамасыз етеді. |
| **DID** | DID (Орталықсыздандырылған сәйкестік) | Сіз орталық биліксіз өзіңіз жасайтын және басқаратын цифрлық сәйкестік. Жеке кілтіңізбен криптографиялық қол қойылған — оны ешкім қайтарып ала да, жасай да алмайды. |
| **DID Document** | DID құжаты | Сіздің DID сәйкестігіңізді сипаттайтын жария қолжетімді дерек файлы — жария кілттерді, желі мекенжайларын және метадеректерді қамтиды. Желіде сіздің сәйкестігіңізді тексеру үшін пайдаланылады. |
| **Due Diligence** | Due diligence | Жалпы: іскерлік немесе құқықтық қатынасқа кірмес бұрын қарсы тарапты терең тексеру — оның тарихын, қаржысын, беделін және тәуекелдерін тексеру. Мұнда: беделдік желіде тексерілген жазбалардың қолжетімділігінің арқасында жылдамырақ әрі автоматтырақ жүреді. |
| **Economic Neutrality Principle** | Экономикалық бейтараптық қағидаты | Желідегі адал мінез-құлық экономикалық тұрғыдан нөлге жақын — жариялау шығындары тексеру сыйақылары ретінде қайтады. Адал емес мінез-құлық — таза шығын. |
| **Emergent** | Эмергентті | Оны ешкім жобаламай немесе бағыттамай, қарапайымырақ бөліктердің өзара әрекетінен өздігінен туындайтын. Құстар тобы жоспарсыз формация бойынша ұшады — формация әр жеке құстың қарапайым ережелерінен туындайды. |
| **Emergent Social Contract** | Эмергентті қоғамдық келісім | Жоғарыдан (заң) емес, төменнен — қоғамдастық ішіндегі қайталанатын өзара әрекеттер мен консенсустан туындайтын мінез-құлық ережелері. |
| **ESR** | Electronic Spending Register | Қоғамдық шығыстарды мөлдір қадағалаудың ұсынылған жүйесі — мемлекеттің әр жүзеге асырылған шығысы жоспарланған төлеммен сәйкестендіріледі. Чех EET-тен шабыт алған, бірақ мемлекетке қарсы бұрылған. |
| **Hash** | Хеш (отпечаток) | Жалпы: кез келген кірістен бірегей тұрақты ұзындықтағы «саусақ ізін» шығаратын бір бағытты математикалық функция — құжаттың саусақ ізі сияқты. Бірдей кіріс әрқашан бірдей шығыс береді, бірақ кірісті шығыстан шығаруға болмайды. Мұнда: хеш сақинадағы орынды анықтауға және құжат тұтастығын тексеруге пайдаланылады. |
| **Just-in-Time Funding** | Just-in-time қаржыландыру | Мөлдірлікке шартталған мемлекеттік қаржыландыру — ақша тек мемлекет ESR-ды қабылдап, шығыстарын сәйкестендіргенде ғана ағады. Ынтымақтастыққа мәжбүрлеу иінтірегі. |
| **Meritocracy** | Меритократия | Жалпы: жағдай формальды атақтарға, байланыстарға немесе мұрагерлік артықшылыққа емес, нақты еңбек пен дәлелденген қабілетке қарай анықталатын жүйе. Мұнда: беделдік желі қоғамдастыққа дәлелденген түрде үлес қосатындарды табиғи түрде қолдайды — олардың дауысы лауазымға емес, track record-қа байланысты үлкенірек салмақ алып жүреді. |
| **Onion Gateway** | Onion gateway | DID сәйкестігінің onion желісіндегі желі мекенжайы. DID құжатынан бөлек — оны сәйкестікті жоғалтпай өзгертуге болады (доменнің артындағы IP мекенжайын өзгерткенге ұқсас). |
| **Onion Routing** | Onion routing (Tor) | Желінің цензураланбаушылығын қамтамасыз ететін коммуникация протоколы. Хабарламалар қабаттармен шифрланады — әр түйін бір қабатты алып тастайды, бірақ толық жолды білмейді. |
| **Oracle Problem** | Оракул мәселесі | Жалпы: цифрлық жүйеге енетін деректер физикалық әлемде шын мәнінде болғанға дәл сәйкес келуін қалай қамтамасыз ету керек. Термин блокчейн саласынан шыққан. Мұнда: цифрлық жазбаның физикалық шындыққа сәйкес келетініне кепіл ретінде беделін тігетін авторитеттер арқылы шешіледі. |
| **Phenomenological** | Феноменологиялық | Жалпы: құбылыстарды алдын ала берілген теориясыз, олардан не туындайтынын бақылай отырып, тікелей тәжірибеде көрінгендей зерттейтін тәсіл. Мұнда: еркіндік, қоғамдық келісім және мінез-құлық нормалары — бақыланатын құбылыстар, жоғарыдан анықталған қағидаттар емес, адамдар арасындағы мыңдаған микроәрекеттердің салдары. |
| **Policy** | Policy (саясат) | Жалпы: белгілі бір контексте мінез-құлықты реттейтін ережелер немесе қағидаттар жиыны. Мұнда: DID желісінің әр қатысушысы өз саясатын жариялайды — басқалардың нақты мінез-құлқына қалай әрекет ететінін, қандай ережелерді ұстанатынын және қандай жазаларды пропорционалды деп есептейтінін. Саясаттардың жиынтығы эмергентті қоғамдық келісім құрайды. |
| **Proxy** | Proxy | Жалпы: орынбасар немесе делдал — басқаның атынан әрекет ететін жүйе немесе субъект. Мұнда екі контексте пайдаланылады: (1) ESR қоғамдық шығыстарды жоспарланған төлемдермен сәйкестендіретін прокси ретінде; (2) бақылаушылар айласындағы жариялаушы мен тексеруші арасындағы прокси ретіндегі бақылаушылар. |
| **Publisher** | Жариялаушы | Жазба жасайтын және жариялайтын желі қатысушысы (әділетсіздік, жою туралы мәлімдеме және т.б.). Жариялау шығынын көтереді. |
| **Reputation-Based Social Network (RSN)** | Беделдік желі | Қатысушылар нақты әлемдегі мінез-құлық туралы кері байланыс алмасатын орталықсыздандырылған әлеуметтік желі. Жазбаларды жасау қымбат, оқу арзан. |
| **Reputation Signal** | Беделдік сигнал | Желідегі жеке жазба — оң (зиянды жою, міндеттемені орындау) немесе теріс (әділетсіздік, шартты бұзу). Жинақталып, сигналдар беделдік профиль құрайды. |
| **Social Graph** | Әлеуметтік граф | Сіздің контактілеріңіздің және контактілеріңіздің контактілерінің желісі. Алгоритм тексерушілерді бапталатын тереңдікте іздейді (мысалы, 3 деңгей). Жаһандық блокчейн жоқ — желі табиғи түрде қиылыстары бар қоғамдастықтар құрайды. |
| **Tax Allocation** | Салық бөлу | Салық төлеуші салығының бір бөлігі қайда баратынын шешетін тетік. Бөлуге болатын пайыз жылдан жылға өседі. |
| **Track Record** | Track record | Жалпы: адамның немесе ұйымның өткен нәтижелерінің, жетістіктері мен сәтсіздіктерінің тарихы. Мұнда: берілген DID сәйкестігінің желідегі барлық өткен өзара әрекеттерінің қосындысы — тексерілген мәлімдемелер, қабылданған және қабылданбаған жазбалар — олардан оның беделі шығарылады. |
| **Verifier** | Тексеруші | Жазбаны тексеруге және жариялауға алгоритмдік түрде таңдалған қатысушы. Ақпараттың шынайылығына өз жақсы атын тігеді. |
