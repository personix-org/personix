# Оракул мәселесі — цифрлық және физикалық әлемдерді жалғау

«Оракул мәселесі» термині соңғы кездері көбіне криптовалюталар, блокчейндер және орталықсыздандырылған жүйелер әлемімен байланыстырылады. Жалпы: цифрлық жүйеге енетін деректер физикалық әлемде шын мәнінде болғанға дәл сәйкес келуін қалай қамтамасыз етесіз? Жүйенің өзі біреу шынымен басқаға зиян келтіргенін немесе шарт шынымен бұзылғанын тексере алмайды — ол тек цифрлық жазбаларды ғана көреді.

Мұны біз авторитеттер арқылы шешеміз — олар цифрлық жазбаның физикалық шындыққа сәйкес келетініне өз беделін тігетін субъектілер. Авторитеттің беделі неғұрлым жоғары болса, жазба соғұрлым сенімді.
