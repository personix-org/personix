# Problem wyroczni — pomost między światem cyfrowym a fizycznym

Termin „problem wyroczni” (oracle problem) w ostatnim czasie najczęściej kojarzony jest ze światem kryptowalut, blockchainów i systemów zdecentralizowanych. Ogólnie: jak zapewnić, by dane wchodzące do systemu cyfrowego wiernie odpowiadały temu, co faktycznie wydarzyło się w świecie fizycznym? Sam system nie może zweryfikować, czy ktoś naprawdę skrzywdził kogoś innego albo czy umowa faktycznie została naruszona — widzi jedynie zapisy cyfrowe.

Rozwiązujemy to tutaj poprzez autorytety — podmioty, które stawiają swoją reputację na tym, że zapis cyfrowy odpowiada rzeczywistości fizycznej. Im wyższa reputacja autorytetu, tym wiarygodniejszy zapis.
