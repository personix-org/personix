# Prosty system podatkowy — przynęta na wejście

Pierwszym narzędziem jest prosty, przejrzysty system podatkowy zbudowany na infrastrukturze DID. Jedna proporcjonalna stawka od wszystkich dochodów. Bez wyjątków, bez wakacji podatkowych, bez odliczeń dla firm, bez zachęt. Każda płatność jest audytowalnie powiązana z DID, który ją zapłacił. Sprawdzanie krzyżowe jest trywialne.

Stawka byłaby ustawiona nieco korzystniej niż w starym systemie dla części podatników — to jest przynęta na wejście. Obciążenie podatkowe malałoby rok do roku, system stawałby się coraz atrakcyjniejszy, a migracja nabierałaby tempa. System jest zarazem prowadzącym ewidencję i poborcą — bez pośrednika, bez nieprzejrzystości.
