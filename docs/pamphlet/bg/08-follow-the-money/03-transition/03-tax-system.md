# Проста данъчна система — примамката за влизане

Първият инструмент е проста, прозрачна данъчна система, изградена върху DID инфраструктура. Единна пропорционална ставка върху всички доходи. Без изключения, без данъчни ваканции, без корпоративни облекчения, без стимули. Всяко плащане е одитируемо свързано с DID, която го е извършила. Кръстосаната проверка е тривиална.

Ставката би била зададена малко по-благоприятно от старата система за част от данъкоплатците — това е примамката за влизане. Данъчната тежест би намалявала година след година, системата би ставала все по-привлекателна, а миграцията би набирала скорост. Системата е едновременно водещият записите и събиращият — без посредник, без непрозрачност.
