# Orakelproblemet — att brygga den digitala och den fysiska världen

Termen ”orakelproblem” har på senare tid oftast förknippats med kryptovalutornas, blockkedjornas och de decentraliserade systemens värld. Generellt: hur säkerställer man att data som förs in i ett digitalt system troget motsvarar det som faktiskt hände i den fysiska världen? Systemet självt kan inte verifiera om någon verkligen skadade någon annan, eller om ett avtal verkligen bröts — det ser bara digitala poster.

Här löser vi detta genom auktoriteter — entiteter som sätter sitt anseende på spel för att den digitala posten motsvarar den fysiska verkligheten. Ju högre auktoritetens anseende, desto mer trovärdig är posten.
