# Fyra verktyg som stödjer varandra

Fram till nu kan DID-anseendenätverket ha framstått som användbart främst för rättvisa och konsensus. Jag tror att det skulle kunna stabilisera sig självt och stå emot attacker — meritokratiskt, på grundval av faktisk förtjänst snarare än formella titlar. Men anseende ensamt kommer inte att tvinga staten att ge vika. Ekonomin kommer att göra det, och trycket som utövas genom den.

Inget hindrar oss från att använda DID-identiteter som förvaltare av ytterligare verktyg som trycker hårt på pengarna. Börja inte med full frivillighet från medborgarnas sida — sätt en riktning som staten inte kan stoppa. Övergången vilar på fyra specifika verktyg som spjärnar mot varandras ryggar. Inget av dem räcker på egen hand.
