# Fogalomtár

| Fogalom | Magyar | Jelentés |
|------|-------|---------|
| **Authority** | Autoritás | Megbízható entitás (személy, szervezet), amely információt ellenőriz, és a reputációját teszi rá. Lehet specializált (nyomozói, jogi, technikai). |
| **Claim** | Állítás | Általánosan: bármely ellenőrizhető kijelentés. Itt: a reputációs hálózatba közzétett bejegyzés — egy eseményről, tulajdonságról vagy kapcsolatról szóló állítás, amely kriptográfiailag aláírt és ellenőrzött. Pl. „X település lakosa vagyok" vagy „ez a személy szerződést szegett". |
| **Compartmentalization** | Kompartmentalizáció | Általánosan: az információ elszigetelt egységekre való szétválasztása, hogy az egyik egység lelepleződése ne veszélyeztesse a többit. A titkosszolgálatoktól ismert elv. Itt: párhuzamos DID-identitások a diktatúrákban — az egyik lelepleződése nem fedi fel a többit. |
| **Consistent Hash Ring** | Konzisztens hash-gyűrű | Algoritmikus mechanizmus az ellenőrzők kiválasztására — a gyűrűn elfoglalt pozíciót a DID-dokumentum hashe határozza meg a közösségi gráfon belül. Nemdeterminisztikus, mégis ellenőrizhető kiválasztást biztosít. |
| **DID** | DID (Decentralizált identitás) | Digitális identitás, amelyet magad hozol létre és irányítasz, központi hatóság nélkül. Kriptográfiailag a privát kulcsoddal aláírva — senki sem tudja visszavonni vagy meghamisítani. |
| **DID Document** | DID-dokumentum | Nyilvánosan elérhető adatfájl, amely a DID-identitásodat írja le — nyilvános kulcsokat, hálózati címeket és metaadatokat tartalmaz. Az identitásod hálózatbeli ellenőrzésére szolgál. |
| **Due Diligence** | Due diligence | Általánosan: egy ellenfél alapos ellenőrzése, mielőtt üzleti vagy jogi kapcsolatba lépnénk vele — a története, pénzügyei, reputációja és kockázatai átvizsgálása. Itt: a reputációs hálózatban gyorsabban és automatikusabban történik az ellenőrzött bejegyzések elérhetőségének köszönhetően. |
| **Economic Neutrality Principle** | A gazdasági semlegesség elve | A becsületes viselkedés a hálózatban gazdaságilag közel nulla — a közzététel költségei ellenőrzési jutalomként térülnek meg. A becstelen viselkedés tiszta veszteség. |
| **Emergent** | Emergens | Egyszerűbb részek interakcióiból spontán módon keletkező, anélkül, hogy bárki megtervezné vagy irányítaná. Egy madárraj terv nélkül repül alakzatban — az alakzat az egyes madarak által követett egyszerű szabályokból bontakozik ki. |
| **Emergent Social Contract** | Emergens társadalmi szerződés | Viselkedési szabályok, amelyek nem felülről (törvényből), hanem alulról keletkeznek — egy közösségen belüli ismételt interakciókból és konszenzusból. |
| **ESR** | Elektronikus kiadásnyilvántartás | Javasolt rendszer a közkiadások átlátható követésére — az állam minden realizált kiadását összevetik egy tervezett fizetéssel. A cseh EET ihlette, de az állam ellen fordítva. |
| **Hash** | Hash (ujjlenyomat) | Általánosan: egyirányú matematikai függvény, amely bármely bemenetből egyedi, fix hosszúságú „ujjlenyomatot" állít elő — mint a dokumentum ujjlenyomata. Ugyanaz a bemenet mindig ugyanazt a kimenetet adja, de a bemenet nem vezethető le a kimenetből. Itt: a hash-gyűrűn elfoglalt pozíció meghatározására és a dokumentum sértetlenségének ellenőrzésére szolgál. |
| **Just-in-Time Funding** | Just-in-time finanszírozás | Átláthatóságtól függő állami finanszírozás — a pénz csak akkor folyik, amikor az állam elfogadja az ESR-t és összeveti a kiadásait. Kar az együttműködés kikényszerítésére. |
| **Meritocracy** | Meritokrácia | Általánosan: olyan rendszer, ahol a rangot a tényleges érdem és a bizonyított képesség határozza meg, nem a formális címek, kapcsolatok vagy örökölt kiváltság. Itt: a reputációs hálózat természetesen azokat részesíti előnyben, akik bizonyíthatóan hozzájárulnak a közösséghez — a hangjuk a track record, nem a hivatal miatt bír nagyobb súllyal. |
| **Onion Gateway** | Onion gateway | Egy DID-identitás hálózati címe az onion-hálózaton. Elkülönül a DID-dokumentumtól — megváltoztatható az identitás elvesztése nélkül (hasonlóan ahhoz, mint amikor egy domain mögötti IP-címet változtatunk). |
| **Onion Routing** | Onion routing (Tor) | Kommunikációs protokoll, amely biztosítja a hálózat cenzúrázhatatlanságát. Az üzeneteket rétegekben titkosítja — minden csomópont egy réteget fejt le, de nem ismeri a teljes útvonalat. |
| **Oracle Problem** | Oracle-probléma | Általánosan: hogyan biztosítható, hogy egy digitális rendszerbe belépő adatok hűen megfeleljenek annak, ami valójában történt a fizikai világban. A kifejezés a blockchain területéről ered. Itt: autoritásokon keresztül megoldva, akik a reputációjukat teszik garanciaként arra, hogy egy digitális bejegyzés megfelel a fizikai valóságnak. |
| **Phenomenological** | Fenomenológiai | Általánosan: olyan megközelítés, amely a jelenségeket úgy vizsgálja, ahogyan a közvetlen tapasztalatban megnyilvánulnak, azt figyelve, mi következik belőlük, előzetesen adott elméletek nélkül. Itt: a szabadság, a társadalmi szerződés és a viselkedési normák megfigyelt jelenségek — az emberek közötti több ezer mikrointerakció következményei, nem felülről definiált elvek. |
| **Policy** | Policy (elvek) | Általánosan: egy adott kontextusban a viselkedést szabályozó szabályok vagy elvek halmaza. Itt: a DID-hálózat minden résztvevője deklarálja a policyját — hogyan reagál mások konkrét viselkedésére, mely szabályokat követi, és mely büntetéseket tart arányosnak. A policyk összessége alkotja az emergens társadalmi szerződést. |
| **Proxy** | Proxy | Általánosan: helyettes vagy közvetítő — egy másik nevében eljáró rendszer vagy entitás. Itt két kontextusban használatos: (1) az ESR mint proxy, amely a közkiadásokat összeveti a tervezett fizetésekkel; (2) a megfigyelők mint proxy a közzétevő és az ellenőrző között a megfigyelő-trükkben. |
| **Publisher** | Közzétevő | Hálózati résztvevő, aki bejegyzést hoz létre és tesz közzé (állítás egy igazságtalanságról, orvoslásról stb.). Ő viseli a közzététel költségét. |
| **Reputation-Based Social Network (RSN)** | Reputációs hálózat | Decentralizált közösségi hálózat, amelyben a résztvevők a valós viselkedésről cserélnek visszajelzést. A bejegyzések létrehozása költséges, olvasásuk olcsó. |
| **Reputation Signal** | Reputációs jel | Egyedi bejegyzés a hálózatban — pozitív (kár orvoslása, kötelezettség teljesítése) vagy negatív (igazságtalanság, szerződésszegés). A jelek összeadódva reputációs profilt alkotnak. |
| **Social Graph** | Közösségi gráf | A kapcsolataid és a kapcsolataid kapcsolatainak hálózata. Az algoritmus egy konfigurálható mélységen (például 3 szinten) belül keres ellenőrzőket. Nincs globális blockchain — a hálózat természetesen közösségeket formál átfedésekkel. |
| **Tax Allocation** | Adóallokáció | Mechanizmus, amelyben az adófizető dönti el, hová megy az adója egy része. Az allokálható százalék évről évre nő. |
| **Track Record** | Track record | Általánosan: egy személy vagy szervezet múltbeli eredményeinek, sikereinek és kudarcainak története. Itt: egy adott DID-identitás összes múltbeli interakciója a hálózatban — ellenőrzött állítások, elfogadott és elutasított bejegyzések —, amelyekből a reputációja levezethető. |
| **Verifier** | Ellenőrző | Algoritmikusan kiválasztott résztvevő, aki egy bejegyzést ellenőriz és közzétesz. A jó nevét teszi az információ igazságára. |
