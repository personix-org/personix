# 용어집

| 용어 | 체코어 | 의미 |
|------|-------|---------|
| **권위자(Authority)** | Autorita | 정보를 검증하고 그것에 자기 평판을 거는 신뢰받는 주체(사람, 조직). 전문화될 수 있다(수사, 법률, 기술). |
| **클레임(Claim)** | Tvrzení | 일반적으로: 검증 가능한 모든 진술. 여기서는: 평판 네트워크에 게시된 기록 — 암호학적으로 서명되고 검증된, 사건·속성·관계에 대한 주장. 예: "나는 지자체 X의 주민이다" 또는 "이 사람은 계약을 위반했다." |
| **구획화(Compartmentalization)** | Compartmentalizace | 일반적으로: 한 단위의 노출이 다른 단위를 위태롭게 하지 않도록 정보를 고립된 단위로 분리하는 것. 정보기관에서 알려진 원리. 여기서는: 독재 체제에서의 병렬 DID 신원 — 하나가 노출되어도 다른 것들은 드러나지 않는다. |
| **일관 해시 링(Consistent Hash Ring)** | Hash ring | 검증자를 선정하는 알고리즘적 메커니즘 — 링 위의 위치는 소셜 그래프 안 DID 문서의 해시로 결정된다. 비결정론적이면서도 검증 가능한 선정을 보장한다. |
| **DID** | DID (Decentralizovaná identita) | 중앙 권력 없이 당신 스스로 만들고 통제하는 디지털 신원. 당신의 개인 키로 암호학적으로 서명된다 — 누구도 그것을 철회하거나 위조할 수 없다. |
| **DID 문서(DID Document)** | DID dokument | 당신의 DID 신원을 서술하는 공개 데이터 파일 — 공개 키, 네트워크 주소, 메타데이터를 담는다. 네트워크에서 당신의 신원을 검증하는 데 쓰인다. |
| **실사(Due Diligence)** | Due diligence | 일반적으로: 사업적·법적 관계에 들어가기 전에 상대방을 심층 검증하는 것 — 그의 이력, 재무, 평판, 위험을 확인. 여기서는: 평판 네트워크에서 검증된 기록의 가용성 덕분에 더 빠르고 자동적으로 이루어진다. |
| **경제적 중립성 원리(Economic Neutrality Principle)** | Princip ekonomické neutrality | 네트워크에서의 정직한 행동은 경제적으로 0에 가깝다 — 게시 비용이 검증 보상으로 돌아온다. 부정직한 행동은 순손실이다. |
| **창발적(Emergent)** | Emergentní | 누구도 설계하거나 지휘하지 않은 채 더 단순한 부분들의 상호작용에서 저절로 생겨나는 것. 새 떼는 계획 없이 대형을 이루어 난다 — 대형은 각 개체가 따르는 단순한 규칙에서 창발한다. |
| **창발적 사회 계약(Emergent Social Contract)** | Emergentní společenská smlouva | 위(법)에서가 아니라 아래 — 공동체 안의 반복된 상호작용과 합의 — 에서 생겨나는 행동 규칙. |
| **ESR** | Electronic Spending Register | 공공 지출의 투명한 추적을 위한 제안된 시스템 — 국가의 모든 실현된 지출을 계획된 지불과 대조한다. 체코의 EET에서 영감을 얻었으나 국가를 향해 뒤집은 것. |
| **해시(Hash)** | Hash (otisk) | 일반적으로: 어떤 입력으로부터든 고유한 고정 길이 "지문"을 만들어 내는 일방향 수학 함수 — 문서의 지문 같은 것. 같은 입력은 언제나 같은 출력을 내지만, 출력에서 입력을 도출할 수는 없다. 여기서는: 해시 링 위의 위치를 정하고 문서 무결성을 검증하는 데 쓰인다. |
| **적시 자금 조달(Just-in-Time Funding)** | Just-in-time financování | 투명성을 조건으로 하는 국가 자금 조달 — 국가가 ESR를 받아들이고 지출을 대조할 때에만 돈이 흐른다. 협력을 강제하는 지렛대. |
| **능력주의(Meritocracy)** | Meritokracie | 일반적으로: 지위가 형식적 직함이나 인맥, 상속된 특권이 아니라 실제 공로와 입증된 능력으로 결정되는 체제. 여기서는: 평판 네트워크는 공동체에 입증 가능하게 기여하는 이들을 자연히 우대한다 — 그들의 목소리는 직위가 아니라 실적 덕분에 더 큰 무게를 지닌다. |
| **어니언 게이트웨이(Onion Gateway)** | Onion gateway | 어니언 네트워크 상의 DID 신원의 네트워크 주소. DID 문서와는 별개다 — 신원을 잃지 않고 바꿀 수 있다(도메인 뒤의 IP 주소를 바꾸는 것과 비슷). |
| **어니언 라우팅(Onion Routing, Tor)** | Onion routing (Tor) | 네트워크의 검열 불가능성을 보장하는 통신 프로토콜. 메시지는 층층이 암호화된다 — 각 노드는 한 층을 벗기지만 전체 경로는 알지 못한다. |
| **오라클 문제(Oracle Problem)** | Oracle problém | 일반적으로: 디지털 시스템에 들어오는 데이터가 물리 세계에서 실제로 일어난 일에 충실히 대응하도록 어떻게 보장할 것인가. 이 용어는 블록체인 영역에서 비롯되었다. 여기서는: 디지털 기록이 물리적 현실에 대응한다는 보증으로 자기 평판을 거는 권위자를 통해 해결된다. |
| **현상학적(Phenomenological)** | Fenomenologický | 일반적으로: 현상을 미리 주어진 이론 없이 직접 경험 속에 나타나는 대로, 그로부터 무엇이 따라 나오는지를 관찰함으로써 살피는 접근. 여기서는: 자유, 사회 계약, 행동 규범은 관찰된 현상이다 — 위에서 정의된 원리가 아니라 사람들 사이 수천 번의 미시적 상호작용의 결과. |
| **정책(Policy)** | Policy (politika) | 일반적으로: 주어진 맥락에서 행동을 규율하는 규칙이나 원칙의 집합. 여기서는: DID 네트워크의 모든 참여자는 자기 정책을 선언한다 — 타인의 특정 행동에 어떻게 반응하는지, 어떤 규칙을 따르는지, 어떤 처벌을 비례적이라 여기는지. 정책의 총합이 창발적 사회 계약을 이룬다. |
| **프록시(Proxy)** | Proxy | 일반적으로: 대역이나 중개자 — 다른 주체를 대신해 행동하는 시스템이나 주체. 여기서는 두 맥락에서 쓰인다: (1) 공공 지출을 계획된 지불과 대조하는 프록시로서의 ESR; (2) 관찰자 트릭에서 게시자와 검증자 사이의 프록시로서의 관찰자. |
| **게시자(Publisher)** | Vydavatel | 기록(부당함, 시정 등에 관한 클레임)을 만들어 게시하는 네트워크 참여자. 게시 비용을 부담한다. |
| **평판 기반 소셜 네트워크(RSN)** | Reputační síť | 참여자들이 현실 세계 행동에 관한 피드백을 교환하는 탈중앙화 소셜 네트워크. 기록은 만들기에 값비싸고 읽기에 값싸다. |
| **평판 신호(Reputation Signal)** | Reputační signál | 네트워크의 개별 기록 — 긍정적(위해의 시정, 의무의 이행)이거나 부정적(부당함, 계약 위반). 누적되어 신호는 평판 프로필을 이룬다. |
| **소셜 그래프(Social Graph)** | Sociální graf | 당신의 접촉과 그 접촉의 접촉으로 이루어진 네트워크. 알고리즘은 구성 가능한 깊이(예: 3단계)에서 검증자를 찾는다. 전 지구적 블록체인은 없다 — 네트워크는 자연히 겹침이 있는 공동체를 이룬다. |
| **세금 배분(Tax Allocation)** | Alokace daní | 납세자가 자기 세금의 일부가 어디로 갈지 결정하는 메커니즘. 배분 가능한 비율은 해가 갈수록 커진다. |
| **실적(Track Record)** | Track record | 일반적으로: 한 사람이나 조직의 과거 성과, 성공, 실패의 이력. 여기서는: 네트워크에서 주어진 DID 신원의 과거 상호작용 전체 — 검증된 클레임, 받아들여지고 거부된 기록 — 이며, 그로부터 그 평판이 도출된다. |
| **검증자(Verifier)** | Ověřovatel | 기록을 검증하고 게시하도록 알고리즘으로 선정된 참여자. 정보의 진실성에 자기 이름을 건다. |
