# 오라클 문제 — 디지털 세계와 물리 세계를 잇기

"오라클 문제"라는 용어는 최근 들어 암호화폐, 블록체인, 탈중앙화 시스템의 세계와 가장 자주 결부되어 왔다. 일반적으로: 디지털 시스템에 들어오는 데이터가 물리 세계에서 실제로 일어난 일에 충실히 대응하도록 어떻게 보장할 것인가? 시스템 자체는 누군가가 정말로 다른 이에게 위해를 가했는지, 계약이 실제로 위반되었는지 검증할 수 없다 — 그것은 디지털 기록만 볼 뿐이다.

여기서 우리는 이것을 권위자를 통해 해결한다 — 디지털 기록이 물리적 현실에 대응한다는 데 자신의 평판을 거는 주체들 말이다. 권위자의 평판이 높을수록 그 기록은 더 신뢰할 만하다.
