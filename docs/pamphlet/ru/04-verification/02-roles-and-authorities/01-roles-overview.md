# Обзор ролей

Некоторых из этих ролей мы уже кратко касались в главе о сети и её базовых свойствах. Теперь самое время рассмотреть их снова подробнее и добавить дополнительные, которые нужны, чтобы сделать сеть более надёжной. В каждой верификационной транзакции участвует несколько ролей — посмотрим, как они себя ведут.

> [!note] Роли в верификационной транзакции
> В каждой верификации участвует до шести различных ролей, сведённых в таблицу ниже. У всех у них может быть собственный DID в децентрализованной репутационной сети.

| Роль | Описание |
| --------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Эмитент (Issuer)** | Человек, который публикует информацию в сеть, — заявляет, что нечто произошло (DID был создан, изменён или распущен, утверждение, политика данного DID и т. п.) |
| **Субъект (Subject)** | Человек, о котором информация, — тот, к кому относится утверждение |
| **Заверяющая организация (Authority)** | Доверенный участник, который ручается своим именем за качество утверждения, исследуя его и либо рассматривая представленные доказательства, либо активно их собирая |
| **Наблюдатель (Observer)** | Независимая третья сторона, ведущая запись того, как верификатор поступает с утверждением, — следящая, чтобы верификатор ни промолчал, ни отклонился от объявленной им политики |
| **Верификатор (Verifier)** | Алгоритмически выбранный участник, обрабатывающий транзакцию |
| **Представитель (Delegate)** | Человек, действующий от имени другого участника |
