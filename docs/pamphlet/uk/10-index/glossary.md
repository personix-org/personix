# Глосарій

| Термін | Українська | Значення |
|------|-------|---------|
| **Authority** | Авторитет | Довірений суб'єкт (особа, організація), який верифікує інформацію і ставить на неї свою репутацію. Може бути спеціалізованим (слідчий, юридичний, технічний). |
| **Claim** | Твердження | Загалом: будь-яке перевірне висловлювання. Тут: запис, опублікований у репутаційну мережу — твердження про подію, властивість чи відношення, криптографічно підписане й верифіковане. Наприклад, «я мешканець муніципалітету X» або «ця особа порушила договір». |
| **Compartmentalization** | Компартменталізація | Загалом: розділення інформації на ізольовані одиниці так, щоб розкриття однієї одиниці не компрометувало решту. Принцип, відомий зі спецслужб. Тут: паралельні DID-ідентичності в диктатурах — компрометація однієї не розкриває інших. |
| **Consistent Hash Ring** | Узгоджене хеш-кільце | Алгоритмічний механізм вибору верифікаторів — позиція на кільці визначається хешем DID-документа всередині соціального графа. Забезпечує недетермінований, проте перевірний вибір. |
| **DID** | DID (децентралізована ідентичність) | Цифрова ідентичність, яку ви створюєте й контролюєте самі, без центрального авторитету. Криптографічно підписана вашим приватним ключем — ніхто не може її відкликати чи підробити. |
| **DID Document** | DID-документ | Публічно доступний файл даних, що описує вашу DID-ідентичність — містить публічні ключі, мережеві адреси й метадані. Слугує для перевірки вашої особи в мережі. |
| **Due Diligence** | Належна перевірка (due diligence) | Загалом: глибока перевірка контрагента перед вступом у ділові чи правові відносини — вивчення його історії, фінансів, репутації та ризиків. Тут: у репутаційній мережі це відбувається швидше й автоматичніше завдяки доступності верифікованих записів. |
| **Economic Neutrality Principle** | Принцип економічної нейтральності | Чесна поведінка в мережі економічно близька до нуля — витрати на публікацію повертаються як винагороди за верифікацію. Нечесна поведінка — чистий збиток. |
| **Emergent** | Емерджентний | Той, що спонтанно виникає з взаємодій простіших частин, без того, щоб хтось його проєктував чи спрямовував. Зграя птахів летить у формації без плану — формація постає з простих правил, яких дотримується кожна особина. |
| **Emergent Social Contract** | Емерджентна суспільна угода | Правила поведінки, що виникають не згори (закон), а знизу — з повторюваних взаємодій і консенсусу всередині спільноти. |
| **ESR** | Electronic Spending Register | Запропонована система прозорого відстеження публічних видатків — кожен реалізований видаток держави зіставляється із запланованим платежем. Натхнена чеським EET, але обернена проти держави. |
| **Hash** | Хеш (відбиток) | Загалом: одностороння математична функція, що з будь-якого входу створює унікальний «відбиток» фіксованої довжини — наче відбиток пальця документа. Той самий вхід завжди дає той самий вихід, але з виходу неможливо вивести вхід. Тут: використовується для визначення позиції на хеш-кільці та для перевірки цілісності документа. |
| **Just-in-Time Funding** | Фінансування точно вчасно | Фінансування держави за умови прозорості — гроші течуть лише тоді, коли держава приймає ESR і зіставляє свої видатки. Важіль для примусу до співпраці. |
| **Meritocracy** | Меритократія | Загалом: система, де становище визначається дійсними заслугами та доведеною спроможністю, а не формальними титулами, зв'язками чи успадкованими привілеями. Тут: репутаційна мережа природно надає перевагу тим, хто доказово робить внесок у спільноту — їхній голос важить більше через послужний список, а не через посаду. |
| **Onion Gateway** | Onion gateway | Мережева адреса DID-ідентичності в onion-мережі. Відокремлена від DID-документа — її можна змінювати без втрати ідентичності (подібно до зміни IP-адреси за доменом). |
| **Onion Routing** | Onion routing (Tor) | Комунікаційний протокол, що забезпечує нецензуровність мережі. Повідомлення шифруються шарами — кожен вузол знімає один шар, але не знає повного шляху. |
| **Oracle Problem** | Проблема оракула | Загалом: як забезпечити, щоб дані, які входять до цифрової системи, вірно відповідали тому, що насправді сталося у фізичному світі. Термін походить зі сфери блокчейну. Тут: розв'язується через авторитети, які ставлять на кін свою репутацію як гарантію того, що цифровий запис відповідає фізичній реальності. |
| **Phenomenological** | Феноменологічний | Загалом: підхід, що вивчає явища такими, якими вони проявляються в безпосередньому досвіді, спостерігаючи, що з них випливає, без наперед заданих теорій. Тут: свобода, суспільна угода та норми поведінки є спостережуваними явищами — наслідками тисяч мікровзаємодій між людьми, а не принципами, визначеними згори. |
| **Policy** | Policy (політика) | Загалом: набір правил чи принципів, що керують поведінкою в даному контексті. Тут: кожен учасник DID-мережі декларує свою policy — як він реагує на конкретну поведінку інших, яких правил дотримується і які покарання вважає пропорційними. Сукупність policy утворює емерджентну суспільну угоду. |
| **Proxy** | Proxy (посередник) | Загалом: заступник чи посередник — система або суб'єкт, що діє від імені іншого. Тут використовується у двох контекстах: (1) ESR як proxy, що зіставляє публічні видатки із запланованими платежами; (2) спостерігачі як proxy між видавцем і верифікатором у трюку зі спостерігачем. |
| **Publisher** | Видавець | Учасник мережі, який створює й публікує запис (твердження про несправедливість, відшкодування тощо). Несе витрати на публікацію. |
| **Reputation-Based Social Network (RSN)** | Репутаційна мережа | Децентралізована соціальна мережа, де учасники обмінюються відгуками про поведінку в реальному світі. Записи дорого створювати, дешево читати. |
| **Reputation Signal** | Репутаційний сигнал | Окремий запис у мережі — позитивний (відшкодування шкоди, виконання зобов'язання) або негативний (несправедливість, порушення договору). Кумулятивно сигнали утворюють репутаційний профіль. |
| **Social Graph** | Соціальний граф | Мережа ваших контактів і контактів ваших контактів. Алгоритм шукає верифікаторів на налаштовуваній глибині (наприклад, 3 рівні). Жодного глобального блокчейну — мережа природно формує спільноти з перекриттями. |
| **Tax Allocation** | Алокація податків | Механізм, яким платник податків вирішує, куди йде частина його податків. Розподілюваний відсоток зростає рік за роком. |
| **Track Record** | Track record (послужний список) | Загалом: історія минулих результатів, успіхів і невдач особи чи організації. Тут: сума всіх минулих взаємодій даної DID-ідентичності в мережі — верифіковані твердження, прийняті й відхилені записи — з яких виводиться її репутація. |
| **Verifier** | Верифікатор | Учасник, алгоритмічно обраний для перевірки й публікації запису. Ставить своє добре ім'я на кін за правдивість інформації. |
