# Чотири інструменти, що підтримують один одного

Досі репутаційна DID-мережа могла здаватися корисною головно для справедливості та консенсусу. Я вірю, що вона могла б стабілізувати себе й витримати атаки — меритократично, на основі фактичних заслуг, а не формальних титулів. Але сама репутація не змусить державу поступитися. Змусить економіка й тиск, який через неї чиниться.

Ніщо не заважає нам використовувати DID-ідентичності як менеджерів додаткових інструментів, що сильно тиснуть на гроші. Не починайте з повної добровільності з боку громадян — задайте напрям, який держава не може зупинити. Перехід спирається на чотири конкретні інструменти, що підпирають спини один одному. Жоден із них недостатній сам собою.
