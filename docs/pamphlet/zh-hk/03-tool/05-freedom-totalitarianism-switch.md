# 自由—極權開關（以及委託）

DID 網絡中的一個簡單機制，能把整個系統推向更多自由或更多控制：一個 DID 在每個時段可以發佈的紀錄數量。當紀錄保持稀缺時，每一條都份量十足 — 那就是自由。當紀錄氾濫、連雞毛蒜皮的事都覆蓋時，那就是極權。你每發佈一條紀錄，都是在為方向作抉擇。網絡本身既不自由也不極權 — 它是中性的基礎設施。它會變成甚麼，取決於人們如何使用它。

在我自己的驗證政策裏，對我社交網絡中的一個一般 DID — 在社群內部 — 設定一個「發佈者每個時段可簽發的主張（泛指任何可驗證的陳述；此處指發佈到聲譽網絡的一條紀錄）的最大數量」是說得通的，超過這個數量，我才會把它們納入考量、才會認為它們的驗證請求切題。

我心裏有一個直覺的數字 — 每年低個位數。這種帶審查性質的取態，看起來或許相當孤立主義。但我可以正當地把申請人置於一個抉擇之前：從他已簽發的紀錄中挑一條，請驗證者撤銷它，也就是使它作廢 — 而在申請人恰好真的成了多宗互不相干的冤情受害者的情況下，這是一個相當咄咄逼人的要求，而我這樣做，肯定也會加深他被社群疏離的感受。

![THE FREEDOM-TOTALITARIANISM SWITCH](../../Info%20Graphics/v5/v5-06-prepinac-svoboda-totalita.webp)

因此，一個更有效的選項似乎是：把自己一部分「向聲譽網絡發佈資訊」的權利，委託給一個社群或一個權威，讓它按其內部規則、以互助的方式來決定如何分配這些權利。一個群體必須有能力照顧它認為處於弱勢的那些人。社群成員有權在任何時候，只要被委託的權利尚未被使用，就撤回自己的委託。

![DELEGATION OF THE RIGHT TO PUBLISH](../../Info%20Graphics/v5/v5-06c-delegace.webp)

> [!note] 自由 vs 極權
> 一個看管並限制所發佈紀錄數量的社會，會更自由；一個紀錄過剩的社會，則會傾向極權。人們可以設想把發佈紀錄的權利委託給別人。

> [!note] 文化適應
> 人們大體上都喜歡窺看彼此的碗裏有甚麼。跨越不同文明，我們在歷史經驗與人口密度上各不相同 — 因而在「文明與社群內部我們想窺看彼此碗裏東西的程度」上也各不相同。亞洲國家傾向於對社會自由持較嚴格的看法；歐美國家在某些方面則傾向較自由。無論這條類比多麼不精確，在去中心化聲譽社交網絡的脈絡裏可以說：各個社群的設定並不歧視，每個社群都可以按自己認為合適的方式，配置其內部的溝通。
>
> 儘管存在差異，仍會有一些為全球所公認的標準（隨機殺人對誰都沒好處）。其他設定會是社群特有的，還有一些甚至是個人特有的。好處在於，透過彼此溝通、透過觀察周遭的設定，可以尋求共識 — 從雙邊安排，到社群層面，再隨着時間，憑藉配置得最好的那些社群的經濟優勢，甚至上升到全球層面。
>
> 不過關於共識，下一章再細談。
