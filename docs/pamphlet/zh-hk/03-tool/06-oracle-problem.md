# 預言機問題 — 架接數碼與物理世界

「預言機問題」一詞近來最常與加密貨幣、區塊鏈和去中心化系統的世界聯繫在一起。一般而言：你如何確保進入數碼系統的數據，忠實地對應到物理世界中實際發生的事？系統本身無法驗證某人是否真的傷害了另一個人，或某份合約是否真的被違反 — 它只看得見數碼紀錄。

在這裏，我們透過權威來解決這個問題 — 這些實體以自己的聲譽作賭注，擔保數碼紀錄對應於物理現實。權威的聲譽越高，紀錄就越可信。
