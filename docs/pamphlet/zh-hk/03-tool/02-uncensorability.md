# 網絡為何不可審查

到目前為止，我們描述了網絡能做甚麼。現在，讓我們把焦點放在它為何無法被關停或審查。

網絡很可能會建立在 Tor 網絡與洋蔥路由（一種利用 Mixnet 原理來遮蔽網絡流量的方法）的原理之上 — 這是一種讓通訊穿過若干層加密的技術，其中沒有任何單一節點能同時知道發送者與接收者。中央機構無法越過你的肩膀窺看，因為根本沒有一個可供窺看的位置。

你可以與它抗爭，但你贏不了 — 除非你把整個國家拖進極權式的監控，深入到單個網絡數據包，以及每一件接入互聯網並在該聲譽網絡上通訊的硬件上的底層操作。而這恰恰是中央集權所面對的抉擇：要麼接受公民手上有一件你觸不到的工具，要麼以極權控制之名，把自己埋進經濟停滯的陰暗角落。

我們不要抱有幻想 — 即使是民主政體，在其爭奪中央集權的鬥爭中也會嘗試這樣做。他們寧願把人套上枷鎖，也不肯交出權力。
