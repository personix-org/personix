# 自願性、責任與自由

自願性是個人的：我自己替自己作決定。責任在我的決定影響到他人時產生 — 反饋隨即啟動。自由既非恩賜，亦非權利 — 它是自願性與朝向責任的壓力之間、成千上萬次雙邊互動在整個社會中取平均之後所得的一種現象學[^phenomenological]結果。網絡並不規定這個平均 — 它是從驗證者的價格信號、以及社群成員為自己設定的預先公佈的驗證政策中湧現[^emergent]出來的。

一個處於社群中的個人對自由有多少偏好，取決於他對「自己願意吞下多少他強加於他人之物」的感受。對那些不言自明、且對所有人都有益的事情，並不存在道德兩難 — 謀殺是錯的。然後有一些情況，選項轉移到「被允許的特權」這個位置上：先證明你的技能，我們才讓你上路，這樣你撞死我們的機會就小一些。最後還有一些事情，個人會說 — 這對我不值得，我不會禁止我的鄰居燒樹葉，因為我自己也燒，或者因為我做着別的一些限制他舒適的事情，而他反過來也可能想禁止我這樣做。如果歷史上我們是把自由的界線劃在「他人自由開始之處」，那麼建立在去中心化身份之上的聲譽社交網絡，在這一點上做得比中心化的代議民主更好 — 在代議民主裏，例如那一層享有特權的民選代表，試圖讓自己豁免於對私人通訊的監控，卻毫不猶豫地把這種監控強加於他們的選民身上，還動用各式各樣暗地裏的藉口與操弄。

[^phenomenological]: **現象學的（Phenomenological，源自希臘文 *phainómenon* — 顯現之物）** — 一般而言：一種把現象當作它們在直接經驗中呈現的樣子來考察的取徑，透過觀察由現象所引出的結果，而不預設底層微觀世界的解釋理論。此處：自由不是一條自上而下定義的抽象原則，而是一種被觀察到的現象 — 是人與人之間成千上萬次微互動的結果，從我們實際上如何彼此相待中湧現出來。

[^emergent]: **湧現的（Emergent，源自拉丁文 *emergere* — 浮現）** 意指「從較簡單部分的互動中自發產生，而無人設計或指揮」。一群鳥即使沒有哪一隻鳥對隊形有計劃，也能列隊飛行 — 隊形是從每一隻個體所遵循的簡單規則中湧現出來的。同樣，在聲譽網絡裏，沒有人設計整體的行為規則 — 它們是從成千上萬個個別決定中湧現出來的。
