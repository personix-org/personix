# Personix — 不妥協的變革

### 一個不可審查、不可腐化的去中心化聲譽網絡

> [!note] 副標題的含義
> 四個詞承載了整個構想。**不可審查** — 工具與網絡無法被國家、互聯網服務供應商或任何外部權威噤聲，審查它們的代價是天文數字。**不可腐化** — 網絡內部的人也無法被暗中收買，因為每個行為者的行為都可以公開對照他所宣示的政策，所以行賄是一種可被證明的言行不一，因而等於聲譽自殺。**去中心化** — 沒有任何單一節點、公司或司法管轄區能被攻陷,從而拖垮整個系統。**聲譽網絡** — 在其中流動的價值不是金錢、不是選票、也不是權限，而是社群之間因彼此說真話而慢慢賺取、也可能失去的信用。這四項特性合起來，描繪了國家信任壟斷最起碼可行的繼任者。
