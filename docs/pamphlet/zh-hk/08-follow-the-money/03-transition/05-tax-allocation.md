# 公民稅款分配 — 決定的份量

第三件工具，讓納稅人對「自己的錢流向何處」有直接的影響力。在第一輪，無論 ESR 揭示了甚麼，國家都照樣收到它的錢。到第二輪它就不再如此了 — 第一輪得出的分析，以及由此而生的措施，接手掌控。已繳稅款中的一小部分百分比，可以由繳款人自己來分配 — 前提是他的 DID 符合聲譽上的要求（公民身份、居留身份、社群所承認的成年／行為能力）。可分配的百分比逐年增長。潛在地呈指數增長。從今天的百分之五，到十年內的數十個百分點。

原始的 ESR 數據，自然地引導着納稅人的決定。質量低劣的紀錄，充當一個建議削減的警示信號。任何人都可以創建紀錄；官員則不得不去配對。沒有這一點，稅制就不會給國家送去任何錢 — 既不進國庫，也不進其他預算章節。政治鬥爭從投票箱，轉移到日復一日對一枚枚具體銅板的分配上。
