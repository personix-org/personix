# 沒有身份證的公民身份

隨着過渡到 DID 基礎設施，國家簽發的身份證失去了它壟斷性的用途。你不需要身份證 — 你有一系列 DID 身份，其中一些帶有一條主張，例如你是捷克人、某個市鎮的居民、某所學校的畢業生。這條主張是可驗證的、永久的，並且獨立於國家行政。

一個技術實現的問題浮現出來：市場上誰會承接起「在國家控制之外驗證現有公民」的工作，以便把有意者遷移進一個帶有相應主張的 DID？最有可能的是，會湧現出一些專門作身份驗證的自由市場權威 — 公證人、本地社群、僱主。他們以自己的聲譽作賭注，擔保某個 DID 確實屬於聲稱擁有它的那個人。公民身份 — 也就是對某一種社群看法的歸屬 — 被從中央記錄的需要中解放出來。透過聲譽網絡的連結，所嵌入的數據會被連接並二度、三度、四度地驗證，如此下去。

其後果是直覺的，卻在中心化系統裏無解。今天，政治領導層 — 着眼於更容易連任 — 可以把集中的問題輸入社群的地界：不顧吸納能力以及現有社群的意願接收來自其他文明圈的移民，透過一種壓力去改變原有的社群，而社群在這種壓力下根本來不及同化來自其他文明圈的到來者。在一個 DID 網絡裏，一個透過腐敗被接納的移民，無法確定社群會繼續把他當作自己人。社群的成員在客觀上不必忍受一個陌生人穿着社群的制服來到他們家門口，還拿他打算在屋裏執行的措施的合法性來威脅他們（因為一則社交媒體帖子而沒收孩子的手機）。有了去中心化的聲譽，社會的大多數不必對此逆來順受 — 因為對一個社群的歸屬，不是由一名官員來決定的，而是由社群本身，透過它的聲譽信號來決定的。

在國家職權範圍內的事務上，一張選票的份量，將來可以與「對簡單稅制的貢獻紀錄」嚴格掛鈎。再結合合適的 DID 主張（例如「此人是捷克公民」），外國國民便可以被排除在選舉之外 — 人口登記冊只不過搬到了這裏而已。
