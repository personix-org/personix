# 簡單的稅制 — 入門的誘餌

第一件工具，是一套建立在 DID 基礎設施之上的、簡單而透明的稅制。對所有收入採用單一的比例稅率。沒有例外，沒有免稅期，沒有企業扣減，沒有優惠。每一筆繳款都可審計地連結到繳付它的那個 DID。交叉核對輕而易舉。

稅率的設定，對一部分納稅人而言，會比舊制度略為有利 — 那就是入門的誘餌。稅負會逐年下降，制度會變得越來越吸引人，遷移也會加快步伐。這套制度既是紀錄的保管者，又是徵收者 — 沒有中間人，沒有不透明。
