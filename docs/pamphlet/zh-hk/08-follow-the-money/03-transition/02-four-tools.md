# 四件彼此支撐的工具

到目前為止，DID 聲譽網絡可能看起來主要在司法與共識方面有用。我相信它能夠穩定自身、頂住攻擊 — 以賢能制的方式，建基於實際的功績，而非形式上的頭銜。但單靠聲譽，並不會逼國家讓步。逼它讓步的，是經濟，以及透過經濟施加的壓力。

沒有甚麼能阻止我們把 DID 身份用作額外工具的管理者，來狠狠地壓在金錢上。不要從公民的完全自願開始 — 先設定一個國家無法阻止的方向。這場過渡建基於四件互相撐着對方後背的具體工具。沒有任何一件單憑自己就足夠。
