# 詞彙表

| 詞彙 | 繁體中文 | 意思 |
|------|-------|---------|
| **Authority** | 權威 | 一個受信任的實體（個人、組織），驗證資訊並以自己的聲譽為之背書。可以是專門化的（調查、法律、技術）。 |
| **Claim** | 主張 | 一般而言：任何可驗證的陳述。此處：發佈到聲譽網絡的一條紀錄 — 一項關於某事件、屬性或關係的斷言，經密碼學簽署並驗證。例如「我是市鎮 X 的居民」或「此人違反了一份合約」。 |
| **Compartmentalization** | 區隔化 | 一般而言：把資訊分隔成互相隔離的單元，使暴露一個單元不會危及其他單元。一條為情報機構所熟知的原則。此處：獨裁政權下的並行 DID 身份 — 攻破其一，不會暴露其餘。 |
| **Consistent Hash Ring** | 一致性雜湊環 | 一種選取驗證者的演算法機制 — 環上的位置由社交圖譜內 DID 文件的雜湊決定。確保一種既非確定性、又可驗證的選取。 |
| **DID** | DID（去中心化身份） | 一種你自己創建並掌控的數碼身份，沒有中央權威。以你的私鑰作密碼學簽署 — 沒有人能撤銷它或偽造它。 |
| **DID Document** | DID 文件 | 一份公開可得、描述你 DID 身份的數據檔案 — 包含公鑰、網絡地址與元數據。用於在網絡中驗證你的身份。 |
| **Due Diligence** | 盡職調查 | 一般而言：在進入商業或法律關係之前，對對手方進行深入的核查 — 查核其歷史、財務、聲譽與風險。此處：在聲譽網絡裏，因已驗證紀錄的可得性，它進行得更快、更自動化。 |
| **Economic Neutrality Principle** | 經濟中性原則 | 網絡中的誠實行為，在經濟上接近於零 — 發佈成本會作為驗證報酬回流。不誠實的行為則是淨損失。 |
| **Emergent** | 湧現的 | 從較簡單部分的互動中自發產生，而無人設計或指揮。一群鳥沒有計劃也能列隊飛行 — 隊形從每一隻個體所遵循的簡單規則中湧現。 |
| **Emergent Social Contract** | 湧現的社會契約 | 一些行為規則，不是自上而下（法律）產生，而是自下而上 — 從社群內部反覆的互動與共識中產生。 |
| **ESR** | 電子支出登記 | 一套用以透明追蹤公共支出的擬議制度 — 國家每一筆已實現的支出，都與一條計劃付款相配對。靈感來自捷克的 EET，卻反過來對準國家。 |
| **Hash** | 雜湊（指紋） | 一般而言：一種單向數學函數，能從任何輸入產出一個獨一無二、定長的「指紋」 — 就像文件的指紋。同一輸入總產出同一輸出，但無法從輸出反推輸入。此處：用來決定雜湊環上的位置，並驗證文件的完整性。 |
| **Just-in-Time Funding** | 即時撥款 | 以透明度為條件的國家撥款 — 只有當國家接受 ESR 並配對其支出時，錢才會流動。一根迫使合作的槓桿。 |
| **Meritocracy** | 賢能制 | 一般而言：一種以實際功績與經證明的能力、而非以形式頭銜、關係或世襲特權來決定地位的制度。此處：聲譽網絡自然地偏袒那些對社群有可證明貢獻的人 — 他們的聲音因往績而非因職位而更有份量。 |
| **Onion Gateway** | 洋蔥閘道 | 一個 DID 身份在洋蔥網絡上的網絡地址。與 DID 文件分開 — 它可以在不喪失身份的情況下更改（類似更改一個域名背後的 IP 地址）。 |
| **Onion Routing** | 洋蔥路由（Tor） | 一種確保網絡不可審查性的通訊協議。訊息被分層加密 — 每個節點剝去一層，但不知道完整的路徑。 |
| **Oracle Problem** | 預言機問題 | 一般而言：如何確保進入數碼系統的數據，忠實地對應到物理世界中實際發生的事。此詞源自區塊鏈領域。此處：透過權威來應對，他們以自己的聲譽作賭注，擔保一條數碼紀錄對應於物理現實。 |
| **Phenomenological** | 現象學的 | 一般而言：一種把現象當作它們在直接經驗中呈現的樣子來研究的取徑，透過觀察由它們引出的結果，而不預設既有的理論。此處：自由、社會契約與行為規範都是被觀察到的現象 — 是人與人之間成千上萬次微互動的結果，而非自上而下定義的原則。 |
| **Policy** | 政策 | 一般而言：一套管轄特定脈絡中行為的規則或原則。此處：DID 網絡中每一個參與者都宣示自己的政策 — 他如何回應他人的特定行為、他遵循哪些規則、他認為哪些懲罰合乎比例。政策的總和構成湧現的社會契約。 |
| **Proxy** | 代理 | 一般而言：一個替身或中介 — 一個代另一方行事的系統或實體。此處用於兩種脈絡：（1）ESR 作為配對公共支出與計劃付款的代理；（2）觀察者作為觀察者把戲中發佈者與驗證者之間的代理。 |
| **Publisher** | 發佈者 | 一個創建並發佈紀錄（關於一樁不公、一次彌補等等的主張）的網絡參與者。承擔發佈的成本。 |
| **Reputation-Based Social Network (RSN)** | 聲譽網絡 | 一個去中心化的社交網絡，參與者在其中交換關於現實世界行為的反饋。紀錄創建起來昂貴，讀取起來便宜。 |
| **Reputation Signal** | 聲譽信號 | 網絡中的一條個別紀錄 — 正面的（傷害的彌補、義務的履行）或負面的（不公、違約）。信號累積起來，構成一份聲譽檔案。 |
| **Social Graph** | 社交圖譜 | 你的聯絡人以及你聯絡人的聯絡人所構成的網絡。演算法在一個可配置的深度（例如 3 層）內搜尋驗證者。沒有全球性的區塊鏈 — 網絡自然地形成有所重疊的社群。 |
| **Tax Allocation** | 稅款分配 | 一種機制，讓納稅人決定自己一部分稅款流向何處。可分配的百分比逐年增長。 |
| **Track Record** | 往績 | 一般而言：一個人或組織過往結果、成功與失敗的歷史。此處：某個 DID 身份在網絡中所有過往互動的總和 — 已驗證的主張、被接受與被拒絕的紀錄 — 其聲譽即由此推導而來。 |
| **Verifier** | 驗證者 | 一個經演算法選出、負責驗證並發佈一條紀錄的參與者。以自己的好名聲為資訊的真實性作賭注。 |
