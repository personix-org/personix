# 權威

權威扮演雙重角色：它既可以是**審計者**（在一條主張被發佈之前，驗證證據的質素），也可以是**擔保者**（以自己的聲譽為一條主張的真實性作賭注）。無論哪一種，它都在加強簽發者的主張。這兩項服務是可分離的 — 一個權威可以只提供其中一項、另一項，或同時提供兩項。基本假設是：權威所提供的大部分服務，都可以在自由市場的基礎上交付。即使在那些難以想像可以私有化的領域也是如此，例如司法 — 在那裏，各種專門服務（調查、證據評估，一直到今天由中心化軍隊提供的服務，如戰略規劃、標準化訓練、採購與庫存管理等等）都可以由市場行為者高效地交付。幾乎沒有甚麼東西，在重組之後不能藉着自由市場的激勵而變得更有效率。

> [!warning] 權威、簽發者與觀察者，絕不能是自己案件的驗證者。
> 演算法式的驗證者選取，保障了獨立性。沒有人可以驗證自己的主張，或一條自己有直接利害關係的主張。這是整個 DID 社群都有利益去維護的基本規則之一。

> [!note] 作為隱身觀察者的權威
> 一個聲譽卓著的權威 — 想像一位生意完全繫於其往績的公證人 — 可以在主要功能（審計者／擔保者）之外，再提供第三項功能：在驗證過程中充當隱身觀察者的角色。他為所提交的主張保存一份帶時間戳的紀錄，使驗證者無法悄悄把它丟棄。觀察者角色的機制，會在講「觀察者」角色的那一節裏進一步描述。
