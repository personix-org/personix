# 主體

發佈到聲譽網絡的資訊所關乎的那些人，就是資訊的承載者，或者你也可以叫他們主體。聲譽網絡中的激勵是這樣設定的：主體有充分理由按自己的規則正確、公道地行事，並被社群推向某種恪守規則的黃金中庸。他們甚至有動機做得比自己所宣示的規則更講道德 — 預先宣示的政策，並不排除社群達成共識、追溯性地施加某種評估或措施。從這個角度看，聲譽網絡對法律秩序的替代方案，正如人們所料，更多地是由規則的精神、而非規則的字面所驅動的。
