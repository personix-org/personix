# 角色概覽

在講網絡及其基本特性的那一章裏，我們已經簡略觸及過其中一些角色。現在是時候更詳細地再看它們一次，並補上那些讓網絡更為穩健所需的其他角色。每一筆驗證交易都涉及若干角色 — 讓我們看看它們如何運作。

> [!note] 驗證交易中的角色
> 每一筆驗證最多涉及六個不同的角色，概括於下表。它們全都可以在去中心化聲譽網絡中擁有自己的 DID。

| 角色 | 說明 |
| --------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Issuer（簽發者）** | 把資訊發佈到網絡的人 — 主張某件事發生了（一個 DID 被創建、編輯或解散，一條主張，某個 DID 的政策，等等） |
| **Subject（主體）** | 資訊所關乎的人 — 主張的對象 |
| **Authority（權威）** | 一個受信任的實體，透過調查主張、審閱所呈交的證據或主動蒐集證據，以自己的名聲為主張的質素作賭注 |
| **Observer（觀察者）** | 一個獨立的第三方，紀錄驗證者如何處理主張 — 確保驗證者既不保持沉默，也不偏離他所宣示的政策 |
| **Verifier（驗證者）** | 一個由演算法選出、負責處理交易的參與者 |
| **Delegate（受託人）** | 一個代另一名參與者行事的人 |
