# 驗證者

任何 DID 都可以充當驗證者，無論是直接充當，還是透過委託給第三個 DID 的驗證權來充當。為了讓我 — 或我的受託人 — 能夠驗證，我應當在網絡上可達（在線）。並非人人都願意作出這樣的承諾，這正是為何一個 DID 的紀錄裏，可以按優先次序列出一些替代者，在它離線期間代它履行這項功能。

網絡中每一個活躍的 DID，都公開宣示自己的政策。透過該政策所定義的規則，它在驗證過程中判斷對手方的聲譽，以及簽發者已標記待發佈到聲譽網絡的那條主張的內容與形式。政策的一部分，是用來計算驗證服務費用的計算公式。這一切就位之後，在統計上大量流經網絡的主張之中，我等待網絡的演算法把我抽到簽發者那一邊，並在某一次迭代中把我指派為所簽發資訊的驗證者。簽發者可以事先計算一個行為正確的驗證者會如何反應，但無法迴避實際去接觸他（或他的替代者）；與被選中的驗證者進行的那次迭代，即使簽發者事先知道通不過，也必須由簽發者實際完成。

我們怎麼知道簽發者是在正確的一組候選驗證者 DID 上運行驗證者選取演算法的？每一個 DID 在公開宣示其政策的同時，也會發佈其在聲譽網絡中社交網絡的當前識別碼清單。如果一個簽發者把自己的社交網絡界定為一個只會附和並強化其自身觀點的社交泡泡，那麼透過它發佈的資訊，將很難被其他社群更廣泛地接收。我不惜高昂代價把一條激進主張塞進網絡，並不意味着在判斷對手方聲譽時，我會賦予它任何份量。有些主張是我的社群逼我納入考量的（施加於犯錯者的刑罰與限制）；另一些則完全由我自己決定 — 是否納入某項資訊，其經濟價值由我自己來判定。
