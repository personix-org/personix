# 簽發者

我們之前已經見過簽發者。當某人受了冤屈，或想把自己的一項成就廣而告之時，正是那個由 DID 所代表的人，觸發了把該資訊放進網絡的過程 — 因為他對此有首要的利害關係（動機要麼是渴望得到滿足，要麼是希望改善自己的公眾形象）。

> [!note] 正面主張
> 關於我自己的正面主張，我可以作為它的主體兼簽發者保留起來，留待我想使用它們的場合（一張文憑、一份服務證明等等）。這正是正面主張與負面主張的分別所在：分享一條已驗證的負面主張，符合整個社群的利益，而分享一條正面主張，則符合其持有人的利益。
