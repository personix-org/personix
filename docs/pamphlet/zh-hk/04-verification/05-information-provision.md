# 提供關於你自己的資訊

當兩個互不相識的 DID 主體進入一段經濟關係時，我們可以代對方向自己的社群簽署一份請求，要求它提供關於我們的資訊。然而，這是一種對「社群是甚麼」的十分天真的觀念。社群不是封閉的集合 — 單一個 DID 可以同時是多個社群的參與者。

從某個特定參與者的視角看，社群更像是一種現象學上的現象，體現在他的社交網絡之中；它不是那種總是值得明確劃界的東西。一條村的居民可以構成一個社群，但一個只在週末去那裏的人，也可能在同一條村裏屬於另一個社群。一個社群也可以是一支足球隊，連同它的球迷、職員以及所有相關人士的家庭。一個民族，或一個國家的公民，同樣可以構成一個或多個社群。從不同的角度看一個 DID，可以得出對社群不同的（而且往往很直覺的）看法。

因此，處在邊界上的 DID 是社群之間的橋樑，而且 — 正如現實生活中一樣 — 它們在提供關於其他社群成員的資訊方面扮演一定角色，無論是業餘層面，還是專業層面，例如一個專門連接人與人、並匯集關於高風險 DID 資訊的權威。

DID 網絡中的某些類型的資訊，很適合無條件地相互交換（暴力犯罪、詐騙等等）。然而另一些類型的資訊，一個社群可能會當作限於社群內部使用的東西（相當於公民身份、為社群提供的服務等等）。這類資訊能否傳播，取決於社群成員所宣示的政策。

一個社群在自己的圈子內守護它的私隱，作為回報，則在無條件的基礎上交換互利的資訊。
