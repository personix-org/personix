# 共識與驗證過程

要就「一個社會平均而言應當持守並執行哪些規則」建立共識，以下這套機制能派上用場。作為一名 DID 參與者，我宣示我所認購並將據以生活的規則，並把它們發佈出來。（可以把它看作那些在我看來構成我理想世界的章程與規約 — 一個我不覺得受限、反而覺得安全的世界。）

我可以事先估計我的 DID 聯絡人會如何反應 — 並評估在普通的社交或商業互動中，若這些互動假設性地發生，我會被誰、以多大力度加以制裁。

決定性的評估發生在你向另一個 DID 索取資訊、或請他驗證一條你想發佈到聲譽網絡的主張（或向某個權威請求一項服務，等等）之時。它的結果應當與你自己在乾跑（dry run）中對照對手方所宣示的政策所作的評估一模一樣 — 如果不一樣，那麼對手方那一邊就有問題：他們在試圖玩一場不誠實的遊戲。

結果要麼是接受，並附上一個驗證的報價（在驗證者或權威服務的情況下），要麼是拒絕。對「偏離評估者政策」的制裁與獎勵，都折入這個報價之中。請求者隨後決定是接受條件，還是走向分配演算法中的下一輪驗證 — 重複這個過程，直到滿意為止，或直到經濟上不值得再繼續為止。

> [!note] 社交圖譜
> 聲譽網絡首先是一個社交網絡。你添加聯絡人 — 那些同意連接的人。他們有聯絡人，而那些聯絡人又有聯絡人。演算法在一個可配置的深度內搜尋驗證者（例如三層：你的直接聯絡人、他們的聯絡人，再往外一層）。不需要全球性的區塊鏈 — 網絡會自然而然地形成社群，並與其他社群有所重疊。
>
> 演算法是非確定性的：它把你的主張文件做雜湊，把雜湊映射到這個圈子內已知身份組成的環上的一個位置，並選取最近的那一個作為候選驗證者。你無法預測或影響誰將驗證你的主張。

每一位驗證者的拒絕，都會擴大你的文件並增加它的處理成本 — 那是第一條成本渠道（文件增長）。每一位新的驗證者，都會依據數據量、你的聲譽，以及你主張的內容偏離其所宣示驗證政策的程度來收費 — 那是第二條成本渠道（風險溢價）。而每一次迭代都耗費時間與能量 — 那是第三條成本渠道。

> [!note] 驗證者依次檢查甚麼
> 一旦被選中，驗證者大致按四個有序步驟來評估一條主張 — 最便宜的過濾器在前，昂貴的內容檢查在後：
>
> 1. **政策把關。** 這類主張是否落在驗證者公開驗證的範圍之內？若否，請求即被直接拒絕。
> 2. **權威信任。** 為該主張背書的權威，在驗證者自己宣示的政策下是否足夠受信任？一個低於驗證者信任門檻的權威，無論主張內容如何，都構成拒絕的理由。
> 3. **簽發者聲譽。** 簽發者是否達到驗證者為這類主張所宣示的聲譽門檻？低聲譽可能提高費用，也可能觸發拒絕。
> 4. **內容檢查。** 只有在前三道關卡都通過之後，驗證者才會評估主張本身 — 簽名、內部一致性、形式正確性，以及它偏離驗證者政策的程度。為這最後一步所收的費用，反映的是實際承擔的風險。
>
> 驗證者會發佈管轄上述每一道關卡的政策，因此這些步驟並非任由他自由裁量 — 他受制於自己已經宣示過的東西。偏離已發佈的政策本身，就是一條可以針對他發佈的主張，而他要用自己的聲譽為此付出代價。

結果就是：發佈一條可信而有用的主張，成本幾乎為零。發佈一條激進的主張，成本更高。發佈一個謊言，則變得貴到令人卻步 — 你必須一位驗證者接一位驗證者地迭代下去，而每一位拒絕你的人都在增加成本。市場為你的主張定價，而這個價格告訴你，相對於你所置身的那些社群，你站在甚麼位置。

僅僅宣示你遵守某條規則，而現實中你並不遵守，是不夠的。在那種情況下，你的 DID 就要冒着被發佈一條負面紀錄、揭穿其虛偽的風險 — 這會把你變成對其他所有人的風險。其結果應當是：規則更少，但被更一致地遵守，並清理掉那片連法律專業人士都幾乎理不清的法律與規例叢林。

> [!note] 共識 vs 問責
> 要讓網絡充當有價值的資訊來源，一個 DID 不應太過激進 — 否則其他人會拒絕它。社會壓力會尋求均衡，而試圖破壞這種均衡的舉動很可能會受到懲罰。

> [!warning] 票數並不等於一把聲音的份量
> Juraj Karpiš 說「金錢是善行的記憶」。我要補上一句：聲譽是惡行的記憶。
>
> 由此可見，從賢能制的角度看，凡是貢獻更多而又沒有壞聲譽的人，理應在社群中擁有更大的聲音份量。透過雙邊關係的鏡頭來看：當我掂量該遷就哪些共識壓力時，最大的份量歸於那些讓我獲得最大經濟收益的關係。十個與我沒有實際交易往來的人，對我的影響，遠遠比不上一個長期的生意夥伴。這一範式不限於商業 — 它延伸到社會、政治及其他關係。
