# نظرة عامة على الأدوار

لمسنا بالفعل بإيجاز بعض هذه الأدوار في فصل الشبكة وخصائصها الأساسية. وقد آن الأوان للنظر إليها مجددًا بمزيد من التفصيل وإضافة الأدوار الأخرى التي نحتاجها لجعل الشبكة أكثر متانة. تتضمن كل معاملة تحقق عدة أدوار — لنرَ كيف تتصرف.

> [!note] الأدوار في معاملة التحقق
> يتضمن كل تحقق ما يصل إلى ستة أدوار متمايزة، ملخّصة في الجدول أدناه. ويمكن لكلٍّ منها أن يملك هويته اللامركزية الخاصة في شبكة السمعة اللامركزية.

| الدور | الوصف |
| --------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **المُصدِر** | الشخص الذي ينشر المعلومات في الشبكة — يدّعي أن شيئًا قد حدث (أُنشئت هوية لامركزية، أو حُرّرت، أو حُلّت، أو ادعاء، أو سياسة هوية لامركزية معيّنة، إلخ) |
| **الموضوع** | الشخص الذي تدور المعلومات حوله — المخاطَب بالادعاء |
| **السلطة** | كيان موثوق يراهن باسمه على جودة الادعاء بالتحقيق فيه، إما بمراجعة الأدلة المقدَّمة أو بجمعها بنشاط |
| **المراقب** | طرف ثالث مستقل يحتفظ بسجل لكيفية تعامل المحقّق مع الادعاء — يضمن ألا يلزم المحقّق الصمت ولا ينحرف عن السياسة التي أعلنها |
| **المحقّق** | مشارك مختار خوارزميًا يعالج المعاملة |
| **المفوَّض** | شخص يتصرف نيابةً عن مشارك آخر |
