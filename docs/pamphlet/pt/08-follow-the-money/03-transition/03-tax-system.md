# Sistema Fiscal Simples — a Isca de Entrada

A primeira ferramenta é um sistema fiscal simples e transparente, construído sobre a infraestrutura DID. Uma única taxa proporcional sobre todos os rendimentos. Sem exceções, sem isenções fiscais, sem deduções empresariais, sem incentivos. Cada pagamento está auditavelmente ligado à DID que o pagou. O cruzamento de dados é trivial.

A taxa seria fixada de forma algo mais favorável do que no sistema antigo para uma parte dos contribuintes — é essa a isca para a entrada. A carga fiscal declinaria ano após ano, o sistema tornar-se-ia cada vez mais atraente, e a migração ganharia ritmo. O sistema é, ao mesmo tempo, o guardador dos registos e o cobrador — sem intermediário, sem opacidade.
