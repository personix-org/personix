# Oracle problēma — tilts starp digitālo un fizisko pasauli

Termins “oracle problēma” pēdējā laikā visbiežāk saistīts ar kriptovalūtu, blokķēžu un decentralizētu sistēmu pasauli. Vispārīgi: kā nodrošināt, ka dati, kas ienāk digitālā sistēmā, uzticami atbilst tam, kas patiešām noticis fiziskajā pasaulē? Pati sistēma nevar pārbaudīt, vai kāds patiešām nodarīja pāri kādam citam vai vai līgums tiešām tika pārkāpts — tā redz tikai digitālus ierakstus.

Šeit mēs to risinām caur autoritātēm — subjektiem, kas liek uz spēles savu reputāciju par to, ka digitālais ieraksts atbilst fiziskajai realitātei. Jo augstāka autoritātes reputācija, jo ticamāks ieraksts.
