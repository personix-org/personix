# Glosārijs

| Termins | Latviešu | Nozīme |
|------|-------|---------|
| **Authority** | Autoritāte | Uzticams subjekts (cilvēks, organizācija), kas verificē informāciju un liek uz spēles savu reputāciju par to. Var būt specializēts (izmeklēšanas, juridisks, tehnisks). |
| **Claim** | Apgalvojums | Vispārīgi: jebkurš pārbaudāms izteikums. Šeit: reputācijas tīklā publicēts ieraksts — apgalvojums par notikumu, īpašību vai attiecībām, kas ir kriptogrāfiski parakstīts un verificēts. Piem., “Es esmu X pašvaldības iedzīvotājs” vai “šis cilvēks pārkāpa līgumu”. |
| **Compartmentalization** | Kompartmentalizācija | Vispārīgi: informācijas nodalīšana izolētās vienībās tā, lai vienas vienības atklāšana neapdraud pārējās. Princips, kas pazīstams no izlūkdienestiem. Šeit: paralēlas DID identitātes diktatūrās — vienas kompromitēšana neatklāj pārējās. |
| **Consistent Hash Ring** | Hash ring | Algoritmisks mehānisms verificētāju atlasei — pozīciju uz gredzena nosaka DID dokumenta jaucējkods sociālajā grafā. Nodrošina nedeterministisku, tomēr pārbaudāmu atlasi. |
| **DID** | DID (decentralizētā identitāte) | Digitāla identitāte, ko tu izveido un kontrolē pats, bez centrālas autoritātes. Kriptogrāfiski parakstīta ar tavu privāto atslēgu — neviens to nevar atsaukt vai viltot. |
| **DID Document** | DID dokuments | Publiski pieejams datu fails, kas apraksta tavu DID identitāti — satur publiskās atslēgas, tīkla adreses un metadatus. Tiek izmantots tavas identitātes verificēšanai tīklā. |
| **Due Diligence** | Due diligence | Vispārīgi: padziļināta otras puses pārbaude pirms iesaistīšanās biznesa vai juridiskās attiecībās — tās vēstures, finanšu, reputācijas un risku pārbaude. Šeit: reputācijas tīklā tā notiek ātrāk un automātiskāk, pateicoties pārbaudītu ierakstu pieejamībai. |
| **Economic Neutrality Principle** | Ekonomiskās neitralitātes princips | Godīga uzvedība tīklā ir ekonomiski tuvu nullei — publicēšanas izmaksas tiek atgrieztas kā verifikācijas atlīdzības. Negodīga uzvedība ir tīri zaudējumi. |
| **Emergent** | Emerģents | Spontāni radies no vienkāršāku daļu mijiedarbības, nevienam to nedizainējot vai nevadot. Putnu bars lido formējumā bez plāna — formējums emerģē no vienkāršiem noteikumiem, ko ievēro katrs atsevišķais. |
| **Emergent Social Contract** | Emerģentais sabiedriskais līgums | Uzvedības noteikumi, kas rodas nevis no augšas (likums), bet no apakšas — no atkārtotas mijiedarbības un konsensa kopienas iekšienē. |
| **ESR** | Elektroniskais tēriņu reģistrs | Piedāvāta sistēma caurskatāmai publisko izdevumu izsekošanai — katrs realizētais valsts izdevums tiek saskaņots ar plānoto maksājumu. Iedvesmots no čehu EET, bet vērsts pret valsti. |
| **Hash** | Hash (jaucējkods) | Vispārīgi: vienvirziena matemātiska funkcija, kas no jebkuras ievades rada unikālu fiksēta garuma “nospiedumu” — līdzīgi dokumenta pirkstu nospiedumam. Viena un tā pati ievade vienmēr dod vienu un to pašu izvadi, bet ievadi no izvades atvasināt nevar. Šeit: izmanto pozīcijas noteikšanai uz hash ring un dokumenta integritātes pārbaudei. |
| **Just-in-Time Funding** | Tieši laikā finansējums | Valsts finansējums, kas atkarīgs no caurskatāmības — nauda plūst tikai tad, kad valsts pieņem ESR un saskaņo savus izdevumus. Svira, lai piespiestu sadarbību. |
| **Meritocracy** | Meritokrātija | Vispārīgi: sistēma, kurā stāvokli nosaka faktiski nopelni un pierādīta spēja, nevis formāli tituli, sakari vai mantotas privilēģijas. Šeit: reputācijas tīkls dabiski dod priekšroku tiem, kas pierādāmi dod ieguldījumu kopienā — viņu balsij ir lielāks svars track record dēļ, nevis amata dēļ. |
| **Onion Gateway** | Onion gateway | DID identitātes tīkla adrese onion tīklā. Atsevišķa no DID dokumenta — to var mainīt, nezaudējot identitāti (līdzīgi kā mainot IP adresi aiz domēna). |
| **Onion Routing** | Onion routing (Tor) | Komunikācijas protokols, kas nodrošina tīkla necenzējamību. Ziņas tiek šifrētas slāņos — katrs mezgls noņem vienu slāni, bet nezina pilno ceļu. |
| **Oracle Problem** | Oracle problēma | Vispārīgi: kā nodrošināt, ka dati, kas ienāk digitālā sistēmā, uzticami atbilst tam, kas patiešām noticis fiziskajā pasaulē. Termins cēlies no blokķēžu jomas. Šeit: risināts caur autoritātēm, kas liek uz spēles savu reputāciju kā garantiju, ka digitālais ieraksts atbilst fiziskajai realitātei. |
| **Phenomenological** | Fenomenoloģisks | Vispārīgi: pieeja, kas pēta parādības tā, kā tās izpaužas tiešā pieredzē, novērojot, kas no tām izriet, bez iepriekš dotām teorijām. Šeit: brīvība, sabiedriskais līgums un uzvedības normas ir novērotas parādības — tūkstošiem mikromijiedarbību starp cilvēkiem sekas, nevis no augšas definēti principi. |
| **Policy** | Policy (politika) | Vispārīgi: noteikumu vai principu kopums, kas pārvalda uzvedību attiecīgajā kontekstā. Šeit: katrs DID tīkla dalībnieks deklarē savu politiku — kā viņš reaģē uz citu konkrētu uzvedību, kurus noteikumus ievēro un kurus sodus uzskata par samērīgiem. Politiku kopums veido emerģento sabiedrisko līgumu. |
| **Proxy** | Proxy | Vispārīgi: aizstājējs vai starpnieks — sistēma vai subjekts, kas rīkojas cita vārdā. Šeit izmantots divos kontekstos: (1) ESR kā proxy, kas saskaņo publiskos izdevumus ar plānotiem maksājumiem; (2) novērotāji kā proxy starp publicētāju un verificētāju novērotāja trikā. |
| **Publisher** | Publicētājs | Tīkla dalībnieks, kas rada un publicē ierakstu (apgalvojumu par netaisnību, novēršanu utt.). Nes publicēšanas izmaksas. |
| **Reputation-Based Social Network (RSN)** | Reputācijas tīkls | Decentralizēts sociāls tīkls, kurā dalībnieki apmainās ar atgriezenisko saiti par uzvedību reālajā pasaulē. Ierakstu izveide ir dārga, lasīšana lēta. |
| **Reputation Signal** | Reputācijas signāls | Atsevišķs ieraksts tīklā — pozitīvs (kaitējuma novēršana, saistību izpilde) vai negatīvs (netaisnība, līguma pārkāpums). Kumulatīvi signāli veido reputācijas profilu. |
| **Social Graph** | Sociālais grafs | Tavu kontaktpersonu un tavu kontaktpersonu kontaktpersonu tīkls. Algoritms meklē verificētājus konfigurējamā dziļumā (piemēram, 3 līmeņi). Nav globālas blokķēdes — tīkls dabiski veido kopienas ar pārklāšanos. |
| **Tax Allocation** | Nodokļu alokācija | Mehānisms, ar kuru nodokļu maksātājs izlemj, kur aiziet daļa viņa nodokļu. Alocējamais procents pieaug gadu no gada. |
| **Track Record** | Track record | Vispārīgi: cilvēka vai organizācijas pagātnes rezultātu, panākumu un neveiksmju vēsture. Šeit: visu attiecīgās DID identitātes pagātnes mijiedarbību tīklā summa — pārbaudīti apgalvojumi, pieņemti un noraidīti ieraksti — no kuras tiek atvasināta tās reputācija. |
| **Verifier** | Verificētājs | Dalībnieks, kas algoritmiski izvēlēts verificēt un publicēt ierakstu. Liek uz spēles savu labo vārdu par informācijas patiesumu. |
