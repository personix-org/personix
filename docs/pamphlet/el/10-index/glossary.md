# Γλωσσάρι

| Όρος | Ελληνικά | Σημασία |
|------|-------|---------|
| **Authority** | Αρχή | Μια έμπιστη οντότητα (πρόσωπο, οργανισμός) που επαληθεύει πληροφορίες και θέτει σε αυτές τη φήμη της. Μπορεί να είναι εξειδικευμένη (ερευνητική, νομική, τεχνική). |
| **Claim** | Ισχυρισμός | Γενικά: οποιαδήποτε επαληθεύσιμη δήλωση. Εδώ: μια εγγραφή που δημοσιεύεται στο δίκτυο φήμης — ένας ισχυρισμός για ένα γεγονός, μια ιδιότητα, ή μια σχέση που είναι κρυπτογραφικά υπογεγραμμένος και επαληθευμένος. Π.χ., «Είμαι κάτοικος του δήμου X» ή «αυτό το πρόσωπο παραβίασε ένα συμβόλαιο». |
| **Compartmentalization** | Στεγανοποίηση | Γενικά: ο διαχωρισμός της πληροφορίας σε απομονωμένες μονάδες ώστε η έκθεση μιας μονάδας να μην θέτει σε κίνδυνο τις άλλες. Μια αρχή γνωστή από τις μυστικές υπηρεσίες. Εδώ: παράλληλες ταυτότητες DID σε δικτατορίες — η αποκάλυψη μιας δεν αποκαλύπτει τις άλλες. |
| **Consistent Hash Ring** | Δακτύλιος συνεπούς κατακερματισμού | Ένας αλγοριθμικός μηχανισμός για την επιλογή επαληθευτών — μια θέση στον δακτύλιο καθορίζεται από το hash του εγγράφου DID εντός του κοινωνικού γράφου. Εξασφαλίζει μια μη ντετερμινιστική αλλά επαληθεύσιμη επιλογή. |
| **DID** | DID (Αποκεντρωμένη ταυτότητα) | Μια ψηφιακή ταυτότητα που δημιουργείς και ελέγχεις εσύ ο ίδιος, χωρίς κεντρική αρχή. Κρυπτογραφικά υπογεγραμμένη με το ιδιωτικό σου κλειδί — κανείς δεν μπορεί να την ανακαλέσει ή να την πλαστογραφήσει. |
| **DID Document** | Έγγραφο DID | Ένα δημόσια διαθέσιμο αρχείο δεδομένων που περιγράφει την ταυτότητά σου DID — περιέχει δημόσια κλειδιά, διευθύνσεις δικτύου, και μεταδεδομένα. Χρησιμοποιείται για την επαλήθευση της ταυτότητάς σου στο δίκτυο. |
| **Due Diligence** | Δέουσα επιμέλεια | Γενικά: εις βάθος έλεγχος ενός αντισυμβαλλομένου πριν από την είσοδο σε μια επιχειρηματική ή νομική σχέση — έλεγχος του ιστορικού, των οικονομικών, της φήμης και των κινδύνων του. Εδώ: στο δίκτυο φήμης, συμβαίνει πιο γρήγορα και πιο αυτόματα χάρη στη διαθεσιμότητα επαληθευμένων εγγραφών. |
| **Economic Neutrality Principle** | Αρχή οικονομικής ουδετερότητας | Η έντιμη συμπεριφορά στο δίκτυο είναι οικονομικά κοντά στο μηδέν — το κόστος δημοσίευσης επιστρέφεται ως ανταμοιβές επαλήθευσης. Η ανέντιμη συμπεριφορά είναι καθαρή απώλεια. |
| **Emergent** | Αναδυόμενος | Προκύπτει αυθόρμητα από τις αλληλεπιδράσεις απλούστερων μερών, χωρίς κανείς να το σχεδιάζει ή να το κατευθύνει. Ένα σμήνος πουλιών πετά σε σχηματισμό χωρίς σχέδιο — ο σχηματισμός αναδύεται από απλούς κανόνες που ακολουθεί το κάθε άτομο. |
| **Emergent Social Contract** | Αναδυόμενο κοινωνικό συμβόλαιο | Κανόνες συμπεριφοράς που προκύπτουν όχι από ψηλά (νόμος) αλλά από κάτω — από επαναλαμβανόμενες αλληλεπιδράσεις και συναίνεση εντός μιας κοινότητας. |
| **ESR** | Ηλεκτρονικό Μητρώο Δαπανών | Ένα προτεινόμενο σύστημα για τη διαφανή παρακολούθηση των δημόσιων δαπανών — κάθε πραγματοποιημένη κρατική δαπάνη αντιστοιχίζεται με μια προγραμματισμένη πληρωμή. Εμπνευσμένο από την τσεχική EET, αλλά στραμμένο εναντίον του κράτους. |
| **Hash** | Hash (αποτύπωμα) | Γενικά: μια μονόδρομη μαθηματική συνάρτηση που παράγει ένα μοναδικό «αποτύπωμα» σταθερού μήκους από οποιαδήποτε είσοδο — σαν δακτυλικό αποτύπωμα του εγγράφου. Η ίδια είσοδος παράγει πάντα την ίδια έξοδο, αλλά η είσοδος δεν μπορεί να συναχθεί από την έξοδο. Εδώ: χρησιμοποιείται για τον καθορισμό μιας θέσης στον δακτύλιο κατακερματισμού και για την επαλήθευση της ακεραιότητας του εγγράφου. |
| **Just-in-Time Funding** | Χρηματοδότηση just-in-time | Κρατική χρηματοδότηση υπό την προϋπόθεση της διαφάνειας — το χρήμα ρέει μόνο όταν το κράτος αποδέχεται το ESR και αντιστοιχίζει τις δαπάνες του. Ένας μοχλός για τον εξαναγκασμό συνεργασίας. |
| **Meritocracy** | Αξιοκρατία | Γενικά: ένα σύστημα όπου η θέση καθορίζεται από την πραγματική αξία και την αποδεδειγμένη ικανότητα, όχι από τυπικούς τίτλους, διασυνδέσεις, ή κληρονομημένο προνόμιο. Εδώ: το δίκτυο φήμης ευνοεί φυσικά εκείνους που αποδεδειγμένα συνεισφέρουν στην κοινότητα — η φωνή τους φέρει μεγαλύτερο βάρος λόγω του track record, όχι λόγω αξιώματος. |
| **Onion Gateway** | Onion gateway | Η διεύθυνση δικτύου μιας ταυτότητας DID στο δίκτυο onion. Ξεχωριστή από το έγγραφο DID — μπορεί να αλλάξει χωρίς απώλεια της ταυτότητας (παρόμοια με την αλλαγή της διεύθυνσης IP πίσω από ένα domain). |
| **Onion Routing** | Onion routing (Tor) | Ένα πρωτόκολλο επικοινωνίας που εξασφαλίζει τη μη λογοκρισιμότητα του δικτύου. Τα μηνύματα κρυπτογραφούνται σε στρώματα — κάθε κόμβος αφαιρεί ένα στρώμα αλλά δεν γνωρίζει την πλήρη διαδρομή. |
| **Oracle Problem** | Πρόβλημα του χρησμού | Γενικά: πώς να εξασφαλίσεις ότι τα δεδομένα που εισέρχονται σε ένα ψηφιακό σύστημα αντιστοιχούν πιστά σε αυτό που πραγματικά συνέβη στον φυσικό κόσμο. Ο όρος προέρχεται από τον χώρο του blockchain. Εδώ: αντιμετωπίζεται μέσα από αρχές που θέτουν τη φήμη τους σε κίνδυνο ως εγγύηση ότι μια ψηφιακή εγγραφή αντιστοιχεί στη φυσική πραγματικότητα. |
| **Phenomenological** | Φαινομενολογικός | Γενικά: μια προσέγγιση που μελετά τα φαινόμενα όπως εκδηλώνονται στην άμεση εμπειρία, παρατηρώντας τι απορρέει από αυτά, χωρίς εκ των προτέρων δεδομένες θεωρίες. Εδώ: η ελευθερία, το κοινωνικό συμβόλαιο, και οι κανόνες συμπεριφοράς είναι παρατηρούμενα φαινόμενα — συνέπειες χιλιάδων μικρο-αλληλεπιδράσεων μεταξύ των ανθρώπων, όχι αρχές που ορίζονται από ψηλά. |
| **Policy** | Policy (πολιτική) | Γενικά: ένα σύνολο κανόνων ή αρχών που διέπουν τη συμπεριφορά σε ένα δεδομένο πλαίσιο. Εδώ: κάθε συμμετέχων στο δίκτυο DID δηλώνει την πολιτική του — πώς αντιδρά σε συγκεκριμένη συμπεριφορά των άλλων, ποιους κανόνες ακολουθεί, και ποιες ποινές θεωρεί αναλογικές. Το άθροισμα των πολιτικών σχηματίζει το αναδυόμενο κοινωνικό συμβόλαιο. |
| **Proxy** | Proxy | Γενικά: ένας αντικαταστάτης ή ενδιάμεσος — ένα σύστημα ή οντότητα που ενεργεί για λογαριασμό ενός άλλου. Χρησιμοποιείται εδώ σε δύο πλαίσια: (1) το ESR ως proxy που αντιστοιχίζει τις δημόσιες δαπάνες με τις προγραμματισμένες πληρωμές· (2) οι παρατηρητές ως proxy μεταξύ δημοσιευτή και επαληθευτή στο κόλπο του παρατηρητή. |
| **Publisher** | Δημοσιευτής | Ένας συμμετέχων του δικτύου που δημιουργεί και δημοσιεύει μια εγγραφή (έναν ισχυρισμό για μια αδικία, μια αποκατάσταση, και ούτω καθεξής). Σηκώνει το κόστος της δημοσίευσης. |
| **Reputation-Based Social Network (RSN)** | Δίκτυο φήμης | Ένα αποκεντρωμένο κοινωνικό δίκτυο όπου οι συμμετέχοντες ανταλλάσσουν ανατροφοδότηση για τη συμπεριφορά στον πραγματικό κόσμο. Οι εγγραφές είναι δαπανηρές στη δημιουργία, φθηνές στην ανάγνωση. |
| **Reputation Signal** | Σήμα φήμης | Μια μεμονωμένη εγγραφή στο δίκτυο — θετική (αποκατάσταση βλάβης, εκπλήρωση υποχρέωσης) ή αρνητική (αδικία, παραβίαση συμβολαίου). Αθροιστικά, τα σήματα σχηματίζουν ένα προφίλ φήμης. |
| **Social Graph** | Κοινωνικός γράφος | Το δίκτυο των επαφών σου και των επαφών των επαφών σου. Ο αλγόριθμος αναζητά επαληθευτές σε ένα ρυθμιζόμενο βάθος (για παράδειγμα, 3 επίπεδα). Κανένα παγκόσμιο blockchain — το δίκτυο σχηματίζει φυσικά κοινότητες με επικαλύψεις. |
| **Tax Allocation** | Κατανομή φόρου | Ένας μηχανισμός με τον οποίο ο φορολογούμενος αποφασίζει πού πηγαίνει μέρος των φόρων του. Το κατανεμήσιμο ποσοστό αυξάνεται χρόνο με τον χρόνο. |
| **Track Record** | Track record | Γενικά: το ιστορικό των παρελθόντων αποτελεσμάτων, επιτυχιών και αποτυχιών ενός προσώπου ή οργανισμού. Εδώ: το άθροισμα όλων των παρελθουσών αλληλεπιδράσεων μιας δεδομένης ταυτότητας DID στο δίκτυο — επαληθευμένοι ισχυρισμοί, αποδεκτές και απορριφθείσες εγγραφές — από τα οποία προκύπτει η φήμη της. |
| **Verifier** | Επαληθευτής | Ένας συμμετέχων που επιλέγεται αλγοριθμικά για να επαληθεύσει και να δημοσιεύσει μια εγγραφή. Θέτει το καλό του όνομα στην αληθοφάνεια της πληροφορίας. |
