# Επισκόπηση Ρόλων

Θίξαμε ήδη σύντομα ορισμένους από αυτούς τους ρόλους στο κεφάλαιο για το δίκτυο και τις βασικές του ιδιότητες. Τώρα είναι η ώρα να τους δούμε ξανά με μεγαλύτερη λεπτομέρεια και να προσθέσουμε τους επιπλέον που χρειαζόμαστε για να κάνουμε το δίκτυο πιο ανθεκτικό. Κάθε συναλλαγή επαλήθευσης εμπλέκει αρκετούς ρόλους — ας δούμε πώς συμπεριφέρονται.

> [!note] Ρόλοι σε μια Συναλλαγή Επαλήθευσης
> Κάθε επαλήθευση εμπλέκει έως έξι διακριτούς ρόλους, που συνοψίζονται στον παρακάτω πίνακα. Όλοι τους μπορούν να έχουν τη δική τους DID στο αποκεντρωμένο δίκτυο φήμης.

| Ρόλος | Περιγραφή |
| --------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Εκδότης (Issuer)** | Το πρόσωπο που δημοσιεύει πληροφορία στο δίκτυο — ισχυρισμούς ότι κάτι συνέβη (μια DID δημιουργήθηκε, τροποποιήθηκε ή διαλύθηκε, ένας ισχυρισμός, η πολιτική μιας δεδομένης DID, κ.λπ.) |
| **Υποκείμενο (Subject)** | Το πρόσωπο για το οποίο μιλάει η πληροφορία — ο αποδέκτης του ισχυρισμού |
| **Αρχή (Authority)** | Μια έμπιστη οντότητα που θέτει το όνομά της στην ποιότητα του ισχυρισμού ερευνώντας τον και είτε εξετάζοντας τις αποδείξεις που παρουσιάζονται είτε συγκεντρώνοντάς τες ενεργά |
| **Παρατηρητής (Observer)** | Ένα ανεξάρτητο τρίτο μέρος που κρατά αρχείο για το πώς ο επαληθευτής χειρίζεται τον ισχυρισμό — φροντίζοντας ώστε ο επαληθευτής ούτε να σιωπά ούτε να αποκλίνει από τη δηλωμένη πολιτική του |
| **Επαληθευτής (Verifier)** | Ένας αλγοριθμικά επιλεγμένος συμμετέχων που επεξεργάζεται τη συναλλαγή |
| **Αντιπρόσωπος (Delegate)** | Ένα πρόσωπο που ενεργεί για λογαριασμό ενός άλλου συμμετέχοντα |
