# Παροχή Πληροφοριών για τον Εαυτό Σου

Όταν δύο υποκείμενα DID που δεν γνωρίζονται μπαίνουν σε μια οικονομική σχέση, μπορούμε να υπογράψουμε ένα αίτημα προς την ίδια μας την κοινότητα για λογαριασμό της άλλης πλευράς, ζητώντας της να παρέχει πληροφορίες για εμάς. Αυτό, ωστόσο, είναι μια πολύ αφελής αντίληψη για το τι είναι οι κοινότητες. Δεν είναι κλειστά σύνολα — μια μεμονωμένη DID μπορεί να είναι συμμετέχων σε πολλαπλές κοινότητες.

Μια κοινότητα είναι περισσότερο ένα φαινομενολογικό φαινόμενο από τη σκοπιά ενός δεδομένου συμμετέχοντα, που εκδηλώνεται στο κοινωνικό του δίκτυο· δεν είναι κάτι που έχει πάντα νόημα να οριοθετηθεί ρητά. Οι κάτοικοι ενός χωριού μπορούν να σχηματίσουν μια κοινότητα, αλλά ένα πρόσωπο που έρχεται εκεί μόνο τα σαββατοκύριακα μπορεί επίσης να ανήκει σε μια άλλη κοινότητα στο ίδιο εκείνο χωριό. Μια κοινότητα μπορεί επίσης να είναι μια ποδοσφαιρική ομάδα μαζί με τους οπαδούς της, τους αξιωματούχους της και τις οικογένειες όλων των εμπλεκομένων. Ένα έθνος, ή οι πολίτες ενός κράτους, μπορούν επίσης να σχηματίσουν μια κοινότητα ή κοινότητες. Κοιτάζοντας μια DID από διαφορετικές γωνίες μπορεί να αποδώσει διαφορετικές (και συχνά διαισθητικές) όψεις κοινοτήτων.

Οι DID στα όρια είναι έτσι γέφυρες μεταξύ των κοινοτήτων, και — όπως ακριβώς στην πραγματική ζωή — παίζουν ρόλο στην παροχή πληροφοριών για μέλη άλλων κοινοτήτων, είτε σε ερασιτεχνικό επίπεδο είτε σε επαγγελματικό, όπως μια αρχή που εξειδικεύεται στη σύνδεση ανθρώπων και στη συνάθροιση πληροφοριών για επικίνδυνες DID.

Ορισμένα είδη πληροφορίας στο δίκτυο DID είναι κατάλληλα για άνευ όρων αμοιβαία ανταλλαγή (βίαιο έγκλημα, απάτη, κ.λπ.). Άλλα είδη πληροφορίας, ωστόσο, μια κοινότητα μπορεί να τα αντιμετωπίζει ως περιορισμένα σε χρήση εντός της κοινότητας (το αντίστοιχο της ιθαγένειας, υπηρεσίες που προσφέρθηκαν στην κοινότητα, κ.λπ.). Το αν μια τέτοια πληροφορία μπορεί να διαδοθεί εξαρτάται από τις δηλωμένες πολιτικές των μελών της κοινότητας.

Μια κοινότητα φυλάει την ιδιωτικότητά της εντός του δικού της κύκλου, και σε αντάλλαγμα ανταλλάσσει αμοιβαία επωφελείς πληροφορίες σε άνευ όρων βάση.
