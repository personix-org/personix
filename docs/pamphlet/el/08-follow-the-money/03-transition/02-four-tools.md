# Τέσσερα Εργαλεία που Στηρίζουν το Ένα το Άλλο

Μέχρι τώρα το δίκτυο φήμης DID μπορεί να φαινόταν χρήσιμο κυρίως για τη δικαιοσύνη και τη συναίνεση. Πιστεύω ότι θα μπορούσε να σταθεροποιήσει τον εαυτό του και να αντέξει επιθέσεις — αξιοκρατικά, με βάση την πραγματική αξία παρά τους τυπικούς τίτλους. Αλλά η φήμη από μόνη της δεν θα αναγκάσει το κράτος να υποχωρήσει. Θα το κάνει η οικονομία, και η πίεση που ασκείται μέσα από αυτήν.

Τίποτα δεν μας εμποδίζει να χρησιμοποιήσουμε τις ταυτότητες DID ως διαχειριστές πρόσθετων εργαλείων που πιέζουν σκληρά το χρήμα. Μην ξεκινάς με πλήρη εθελοντικότητα εκ μέρους των πολιτών — θέσε μια κατεύθυνση που το κράτος δεν μπορεί να σταματήσει. Η μετάβαση στηρίζεται σε τέσσερα συγκεκριμένα εργαλεία που καλύπτουν το ένα τα νώτα του άλλου. Κανένα τους δεν αρκεί από μόνο του.
