# Ο Διακόπτης Ελευθερίας-Ολοκληρωτισμού (και η Εκχώρηση)

Ένας απλός μηχανισμός μέσα στο δίκτυο DID μπορεί να μετατοπίσει ολόκληρο το σύστημα προς μεγαλύτερη ελευθερία ή μεγαλύτερο έλεγχο: ο αριθμός των εγγραφών που μπορεί να δημοσιεύσει μια DID ανά χρονική περίοδο. Όταν οι εγγραφές παραμένουν σπάνιες, καθεμία φέρει βάρος — αυτό είναι ελευθερία. Όταν οι εγγραφές είναι άφθονες και καλύπτουν ασημαντότητες, αυτό είναι ολοκληρωτισμός. Επιλέγεις την κατεύθυνση με κάθε εγγραφή που δημοσιεύεις. Το ίδιο το δίκτυο δεν είναι ούτε ελεύθερο ούτε ολοκληρωτικό — είναι ουδέτερη υποδομή. Αυτό που γίνεται καθορίζεται από το πώς το χρησιμοποιούν οι άνθρωποι.

Μέσα στη δική μου πολιτική επαλήθευσης, έχει νόημα να θέσω, για μια γενική DID στο κοινωνικό μου δίκτυο — εντός των κοινοτήτων — έναν μέγιστο αριθμό ισχυρισμών (οποιαδήποτε επαληθεύσιμη δήλωση εν γένει· εδώ: μια εγγραφή που δημοσιεύεται στο δίκτυο φήμης) που μπορεί να εκδώσει ένας δημοσιευτής ανά περίοδο ώστε να τους λαμβάνω υπόψη και να θεωρώ συναφή τα αιτήματα επαλήθευσής τους.

Κρατώ στο μυαλό μου έναν διαισθητικό αριθμό — χαμηλά μονοψήφια νούμερα τον χρόνο. Μια τέτοια λογοκριτική προσέγγιση μπορεί να φαίνεται μάλλον απομονωτική. Αλλά μπορώ νόμιμα να θέσω τον αιτούντα μπροστά σε μια επιλογή: να διαλέξει μία από τις ήδη εκδοθείσες εγγραφές του και να ζητήσει από τον επαληθευτή να την ανακαλέσει, δηλαδή να την ακυρώσει — που είναι μια αρκετά επιθετική απαίτηση σε μια κατάσταση όπου ο αιτών έχει, κατά σύμπτωση, πραγματικά γίνει θύμα πολλαπλών ανεξάρτητων αδικιών, και σίγουρα θα συνέβαλλα έτσι στο αίσθημα αποξένωσής του από την κοινότητα.

![THE FREEDOM-TOTALITARIANISM SWITCH](../../Info%20Graphics/v5/v5-06-prepinac-svoboda-totalita.webp)

Μια πιο αποτελεσματική επιλογή φαίνεται επομένως να είναι η δυνατότητα εκχώρησης μέρους των δικαιωμάτων κάποιου για δημοσίευση πληροφορίας στο δίκτυο φήμης υπέρ μιας κοινότητας ή μιας αρχής, η οποία στη συνέχεια — με τρόπο αλληλέγγυο, σύμφωνα με τους εσωτερικούς της κανόνες — αποφασίζει πώς να τα κατανείμει. Μια ομάδα πρέπει να μπορεί να φροντίζει εκείνους που θεωρεί μειονεκτούντες. Ένα μέλος της κοινότητας έχει το δικαίωμα ανά πάσα στιγμή, έως ότου χρησιμοποιηθεί το εκχωρημένο δικαίωμα, να ανακαλέσει την εκχώρησή του.

![DELEGATION OF THE RIGHT TO PUBLISH](../../Info%20Graphics/v5/v5-06c-delegace.webp)

> [!note] Ελευθερία έναντι ολοκληρωτισμού
> Μια κοινωνία που επαγρυπνεί και περιορίζει τον όγκο των δημοσιευμένων εγγραφών θα είναι πιο ελεύθερη· μια κοινωνία με πληθώρα εγγραφών θα τείνει προς τον ολοκληρωτισμό. Μπορεί κανείς να οραματιστεί την εκχώρηση του δικαιώματος δημοσίευσης εγγραφών σε κάποιον άλλον.

> [!note] Πολιτισμική Προσαρμογή
> Οι άνθρωποι γενικά χαίρονται να βλέπουν στο πιάτο ο ένας του άλλου. Σε όλους τους πολιτισμούς διαφέρουμε στην ιστορική εμπειρία και στην πυκνότητα πληθυσμού — και επομένως στο πόσο θέλουμε να βλέπουμε στο πιάτο ο ένας του άλλου εντός των πολιτισμών και των κοινοτήτων. Τα ασιατικά κράτη τείνουν προς μια αυστηρότερη θεώρηση της ελευθερίας στην κοινωνία· τα ευρωπαϊκά και τα αμερικανικά, σε ορισμένες πτυχές, προς μια πιο ελεύθερη. Όσο ανακριβής κι αν είναι αυτός ο παραλληλισμός, στο πλαίσιο ενός αποκεντρωμένου κοινωνικού δικτύου φήμης μπορεί να ειπωθεί ότι οι ρυθμίσεις των επιμέρους κοινοτήτων δεν εισάγουν διακρίσεις, και κάθε κοινότητα μπορεί να διαμορφώσει την επικοινωνία στο εσωτερικό της όπως κρίνει σκόπιμο.
>
Παρά τις διαφορές, θα υπάρχουν πρότυπα αναγνωρισμένα σε ολόκληρο τον πλανήτη (η τυχαία δολοφονία δεν είναι καλή για κανέναν). Άλλες ρυθμίσεις θα είναι ειδικές ανά κοινότητα, και άλλες ακόμη και προσωπικά ειδικές. Το πλεονέκτημα είναι ότι μέσα από την αμοιβαία επικοινωνία και την παρατήρηση των ρυθμίσεων του περιβάλλοντος κάποιου, μπορεί να αναζητηθεί συναίνεση — από διμερείς διευθετήσεις μέσω κοινοτικών και, με τον καιρό, χάρη στην οικονομική κυριαρχία των καλύτερα διαμορφωμένων κοινοτήτων, ακόμη και σε παγκόσμιο επίπεδο.
>
