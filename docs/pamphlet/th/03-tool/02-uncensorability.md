# เหตุใดเครือข่ายจึงปิดกั้นไม่ได้

จนถึงตอนนี้เราได้บรรยายไปแล้วว่าเครือข่ายทำอะไรได้บ้าง ทีนี้มาเพ่งความสนใจไปที่ว่าทำไมมันจึงไม่อาจถูกปิดหรือถูกปิดกั้นได้

เครือข่ายนี้น่าจะถูกสร้างขึ้นบนหลักการของเครือข่าย Tor และการกำหนดเส้นทางแบบหัวหอม (onion routing) — วิธีการปิดบังการรับส่งข้อมูลในเครือข่ายโดยใช้หลักการของ Mixnet — เทคโนโลยีที่การสื่อสารผ่านการเข้ารหัสหลายชั้น และไม่มีโหนดใดเพียงโหนดเดียวที่รู้ทั้งผู้ส่งและผู้รับในเวลาเดียวกัน สถาบันกลางไม่อาจชะเง้อมองข้ามไหล่ของคุณได้ เพราะไม่มีจุดใดให้มองจากตรงนั้นเลย

คุณสามารถต่อสู้กับมันได้ แต่คุณเอาชนะไม่ได้ — เว้นแต่คุณจะดำดิ่งทั้งประเทศลงสู่การสอดแนมแบบเผด็จการเบ็ดเสร็จในระดับแพ็กเก็ตเครือข่ายแต่ละหน่วยและการกระทำระดับล่างบนฮาร์ดแวร์ทุกชิ้นที่เชื่อมต่ออินเทอร์เน็ตและสื่อสารบนเครือข่ายชื่อเสียงนั้น และนั่นแหละคือทางเลือกที่ลัทธิรวมศูนย์ต้องเผชิญ คือ ยอมรับว่าพลเมืองมีเครื่องมือที่อยู่เหนือมือเอื้อมของคุณ หรือขุดหลุมฝังตัวเองลงไปในมุมมืดของภาวะเศรษฐกิจหยุดนิ่งในนามของการควบคุมแบบเบ็ดเสร็จ

อย่าให้เรามีภาพลวงตาเลย — แม้แต่ระบอบประชาธิปไตยก็จะพยายามทำเช่นนี้ในการต่อสู้เพื่อลัทธิรวมศูนย์ พวกเขายอมใส่ตรวนให้ผู้คนดีกว่าที่จะยอมสละอำนาจ
