# ความสมัครใจ ความรับผิดชอบ และเสรีภาพ

ความสมัครใจเป็นเรื่องของปัจเจก คือ ผมตัดสินใจด้วยตัวเอง ความรับผิดชอบเกิดขึ้นเมื่อการตัดสินใจของผมส่งผลต่อผู้อื่น — ข้อมูลป้อนกลับก็เริ่มทำงาน เสรีภาพไม่ใช่ทั้งของขวัญและสิทธิ — มันเป็นผลลัพธ์เชิงปรากฏการณ์วิทยา[^phenomenological] ของปฏิสัมพันธ์ทวิภาคีนับพันครั้งระหว่างความสมัครใจกับแรงกดดันสู่ความรับผิดชอบ ที่เฉลี่ยกันทั่วทั้งสังคม เครือข่ายไม่ได้เป็นผู้กำหนดค่าเฉลี่ยนี้ — มันผุดขึ้น[^emergent] มาจากสัญญาณราคาของผู้ตรวจสอบ และจากนโยบายการตรวจสอบที่ประกาศไว้ล่วงหน้าซึ่งสมาชิกชุมชนตั้งไว้ให้ตนเอง

ปัจเจกภายในชุมชนหนึ่งจะชอบเสรีภาพมากน้อยเพียงใด ขึ้นอยู่กับความรู้สึกของเขาว่าตัวเองยอมกลืนมากแค่ไหนของสิ่งที่ตนบังคับใช้กับผู้อื่น กับสิ่งที่เห็นได้ชัดเจนและเป็นประโยชน์ต่อทุกคน ก็ไม่มีปัญหาทางศีลธรรม — การฆ่าคนเป็นเรื่องผิด แล้วก็มีกรณีที่ทางเลือกเลื่อนไปอยู่ในฐานะอภิสิทธิ์ที่อนุญาต คือ พิสูจน์ทักษะของคุณมา แล้วเราจะให้คุณออกถนน จะได้มีโอกาสน้อยลงที่คุณจะฆ่าพวกเรา และท้ายที่สุดก็มีเรื่องที่ปัจเจกบอกว่า — มันไม่คุ้มสำหรับผม ผมจะไม่ห้ามเพื่อนบ้านเผาใบไม้ในเมื่อผมก็เผาเอง หรือเพราะผมทำอย่างอื่นที่จำกัดความสะดวกสบายของเขา แล้วเขาก็อาจอยากห้ามผมกลับบ้าง หากในประวัติศาสตร์เราขีดเส้นแบ่งของเสรีภาพไว้ตรงที่เสรีภาพของคนอื่นเริ่มต้น เครือข่ายสังคมด้านชื่อเสียงที่สร้างบนตัวตนแบบกระจายศูนย์ก็ทำหน้าที่นี้ได้ดีกว่าประชาธิปไตยแบบตัวแทนที่รวมศูนย์ — ที่ซึ่ง เช่น ชนชั้นอภิสิทธิ์ของผู้แทนที่ได้รับเลือกพยายามยกเว้นตัวเองจากการสอดแนมการสื่อสารส่วนบุคคล แต่ก็ไม่ลังเลที่จะบังคับใช้มันกับผู้เลือกตั้งของตน ด้วยข้ออ้างลับ ๆ ล่อ ๆ และการชักใยนานาชนิด

[^phenomenological]: **เชิงปรากฏการณ์วิทยา (Phenomenological)** (จากภาษากรีก *phainómenon* — สิ่งที่ปรากฏ) — โดยทั่วไป คือแนวทางที่พิจารณาปรากฏการณ์ตามที่มันแสดงตัวออกมาในประสบการณ์ตรง โดยสังเกตสิ่งที่ตามมาจากมัน โดยไม่มีทฤษฎีอธิบายที่กำหนดไว้ล่วงหน้าในโลกจุลภาคที่อยู่เบื้องล่าง ในที่นี้ เสรีภาพไม่ใช่หลักการนามธรรมที่นิยามจากเบื้องบน แต่เป็นปรากฏการณ์ที่สังเกตได้ — ผลพวงของปฏิสัมพันธ์เล็ก ๆ นับพันครั้งระหว่างผู้คน ซึ่งผุดขึ้นมาจากวิธีที่เราปฏิบัติต่อกันจริง ๆ

[^emergent]: **ผุดขึ้นเอง (Emergent)** (จากภาษาละติน *emergere* — โผล่ขึ้นมา) หมายถึง “เกิดขึ้นเองโดยธรรมชาติจากปฏิสัมพันธ์ของส่วนที่เรียบง่ายกว่า โดยไม่มีใครออกแบบหรือกำกับ” ฝูงนกบินเป็นรูปขบวนแม้ไม่มีนกตัวใดมีแผนของรูปขบวน — รูปขบวนผุดขึ้นมาจากกฎง่าย ๆ ของแต่ละตัว เช่นเดียวกัน ในเครือข่ายชื่อเสียง ไม่มีใครออกแบบกฎพฤติกรรมของทั้งระบบ — มันผุดขึ้นมาจากการตัดสินใจของปัจเจกนับพันครั้ง
