# สัญญาประชาคมที่ผุดขึ้นเอง — นโยบาย

จนถึงตอนนี้เราได้บรรยายไปแล้วว่าคำกล่าวอ้างถูกตรวจสอบอย่างไร และแต่ละบทบาทมีส่วนอย่างไร ทีนี้เราหันมาดูว่านโยบายของปัจเจกนับพันกลายเป็นสิ่งที่ทำงานเหมือนสัญญาประชาคมจริง ๆ ได้อย่างไร ไม่มีอะไรที่คล้ายกับความฝันของฝ่ายซ้ายเรื่องสัญญาประชาคมและความเป็นน้ำหนึ่งใจเดียวที่ถูกบังคับ

ผู้เข้าร่วมทุกคนประกาศนโยบาย (policy) ของตนเองตามศีลธรรมของตน — สิ่งที่เขาถือว่ายอมรับได้ และเขาตอบสนองอย่างไรต่อพฤติกรรมเฉพาะอย่างของผู้อื่น ผลรวมของนโยบายทั้งหมดทั่วเครือข่ายที่ DID หนึ่งรู้จัก (ชุมชน) ก่อให้เกิดจริยธรรมที่ผุดขึ้นเอง — บรรทัดฐานที่สังเกตได้ซึ่งไม่มีใครออกแบบ บรรทัดฐานที่ผุดขึ้นเหล่านี้ ซึ่งมีสัญญาณราคาทวิภาคีค้ำจุนอยู่ ก่อรูปเป็นสัญญาประชาคมที่วัดได้ ไม่ใช่โครงสร้างเชิงทฤษฎีที่ไม่มีใครลงนามตั้งแต่แรกเกิด แต่เป็นกติกาที่สังเกตได้เชิงประจักษ์ซึ่งมีพฤติกรรมจริงรองรับ

> [!note] สัญญาประชาคม
> ผู้คนถกเถียงกันว่า "สัญญาประชาคม" เป็นคำที่ขัดแย้งกันในตัวเองหรือไม่ ไม่มีใครลงนามอะไรเลย แต่มันกลับถูกยกมาอ้างเพื่อให้ความชอบธรรมแก่การกระทำทางนิติบัญญัติและบริหารในสังคมแบบรวมศูนย์
>
> การวิเคราะห์เชิงปรากฏการณ์วิทยาของปฏิสัมพันธ์ในเครือข่ายแบบกระจายศูนย์อาจเผยให้เห็นกติกาบางอย่างที่ผุดขึ้นเอง — ทั้งระดับสากลหรือระดับท้องถิ่น เราควรเรียกบรรทัดฐานที่ถูกยึดถือกันอย่างกว้างขวางเหล่านี้ว่าอะไร? สัญญาประชาคม? เช่นเดียวกับชุมชน สัญญาประชาคมของชุมชนหนึ่งไม่อาจถูกสังเกตและขีดเส้นแบ่งได้อย่างแม่นยำ — ทุกมุมมองที่มีต่อชุมชนย่อมให้สัญญาประชาคมที่แตกต่างกัน

> [!note] นโยบายที่ตั้งอยู่บนคุณค่า
> ในทำนองเดียวกัน การปฏิบัติต่อ "นโยบายที่ตั้งอยู่บนคุณค่า" ในฐานะรากฐานของการตัดสินใจก็ทำให้เข้าใจผิดได้ คุณค่านั้นเป็นเสมือนกลุ่มก้อนเชิงปรากฏการณ์วิทยาของกติกาที่มักถูกนิยมชมชอบในช่วงเวลาหนึ่งมากกว่า มันวิวัฒน์ไป และไม่คงที่ตลอดเวลา
