# การให้ข้อมูลเกี่ยวกับตัวคุณเอง

เมื่อผู้ถือ DID สองรายที่ไม่รู้จักกันเข้าสู่ความสัมพันธ์ทางเศรษฐกิจ เราสามารถลงนามคำร้องถึงชุมชนของเราเองในนามของอีกฝ่าย เพื่อขอให้ชุมชนให้ข้อมูลเกี่ยวกับเรา อย่างไรก็ตาม นี่เป็นความเข้าใจที่ไร้เดียงสาอย่างยิ่งเกี่ยวกับว่าชุมชนคืออะไร ชุมชนไม่ใช่เซตปิด — DID รายเดียวสามารถเป็นสมาชิกในหลายชุมชนได้

ชุมชนเป็นปรากฏการณ์เชิงปรากฏการณ์วิทยาจากมุมมองของผู้เข้าร่วมคนหนึ่งมากกว่า โดยแสดงตัวออกมาในเครือข่ายสังคมของเขา มันไม่ใช่สิ่งที่จะขีดเส้นแบ่งอย่างชัดแจ้งได้อย่างมีความหมายเสมอไป ชาวบ้านในหมู่บ้านหนึ่งอาจก่อรูปเป็นชุมชนได้ แต่คนที่มาที่นั่นเฉพาะวันหยุดสุดสัปดาห์ก็อาจสังกัดอีกชุมชนหนึ่งในหมู่บ้านเดียวกันนั้นได้เช่นกัน ชุมชนยังอาจเป็นทีมฟุตบอลพร้อมกับแฟน ๆ เจ้าหน้าที่ และครอบครัวของทุกคนที่เกี่ยวข้อง ชาติหนึ่ง หรือพลเมืองของรัฐหนึ่ง ก็อาจก่อรูปเป็นชุมชนหรือหลายชุมชนได้ การมอง DID จากมุมต่าง ๆ กันย่อมให้ทัศนะเกี่ยวกับชุมชนที่แตกต่างกัน (และมักเป็นไปตามสัญชาตญาณ)

DID ที่อยู่ตรงขอบเขตจึงเป็นสะพานเชื่อมระหว่างชุมชน และ — เช่นเดียวกับในชีวิตจริง — พวกมันมีบทบาทในการให้ข้อมูลเกี่ยวกับสมาชิกของชุมชนอื่น ไม่ว่าจะในระดับสมัครเล่นหรือระดับมืออาชีพ เช่น องค์กรที่เชื่อถือได้ซึ่งชำนาญเฉพาะทางในการเชื่อมโยงผู้คนและรวบรวมข้อมูลเกี่ยวกับ DID ที่มีความเสี่ยง

ข้อมูลบางประเภทในเครือข่าย DID เหมาะกับการแลกเปลี่ยนซึ่งกันและกันแบบไร้เงื่อนไข (อาชญากรรมที่ใช้ความรุนแรง การฉ้อโกง ฯลฯ) แต่ข้อมูลบางประเภท ชุมชนอาจถือว่าจำกัดไว้ให้ใช้ภายในชุมชนเท่านั้น (เทียบเท่ากับความเป็นพลเมือง บริการที่ให้แก่ชุมชน ฯลฯ) ข้อมูลเช่นนั้นจะเผยแพร่ได้หรือไม่ขึ้นอยู่กับนโยบายที่สมาชิกของชุมชนประกาศไว้

ชุมชนปกป้องความเป็นส่วนตัวของตนภายในวงของตนเอง และเป็นการตอบแทน ก็แลกเปลี่ยนข้อมูลที่เป็นประโยชน์ต่อกันบนพื้นฐานที่ไร้เงื่อนไข
