# ผู้ออก

เราได้พบผู้ออกมาก่อนแล้ว เมื่อมีใครถูกกระทำอย่างไม่เป็นธรรม หรืออยากประกาศความสำเร็จของตนเอง ก็เป็นบุคคลที่ DID นั้นเป็นตัวแทน ซึ่งเป็นผู้จุดชนวนกระบวนการนำข้อมูลนั้นเข้าสู่เครือข่าย — เพราะเขามีผลประโยชน์หลักในการทำเช่นนั้น (แรงจูงใจคือความปรารถนาที่จะได้รับการชดเชย หรือความต้องการปรับปรุงภาพลักษณ์ต่อสาธารณะ)

> [!note] คำกล่าวอ้างเชิงบวก
> คำกล่าวอ้างเชิงบวกเกี่ยวกับตัวเอง ผมสามารถเก็บไว้ได้ ในฐานะทั้งผู้เป็นเจ้าของเรื่องและผู้ออก สำหรับสถานการณ์ที่ผมอยากใช้มัน (ประกาศนียบัตร ใบรับรองการรับใช้ ฯลฯ) นี่คือจุดที่คำกล่าวอ้างเชิงบวกต่างจากเชิงลบ คือ การแบ่งปันคำกล่าวอ้างเชิงลบที่ผ่านการตรวจสอบเป็นประโยชน์ต่อทั้งชุมชน ในขณะที่คำกล่าวอ้างเชิงบวกเป็นประโยชน์ต่อผู้ถือมัน
