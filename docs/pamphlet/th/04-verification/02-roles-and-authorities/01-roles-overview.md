# ภาพรวมของบทบาท

เราได้แตะบทบาทเหล่านี้บางส่วนไปแล้วอย่างสังเขปในบทว่าด้วยเครือข่ายและคุณสมบัติพื้นฐานของมัน ตอนนี้ถึงเวลาที่จะมองมันอีกครั้งอย่างละเอียดยิ่งขึ้น และเพิ่มบทบาทอื่น ๆ ที่เราต้องการเพื่อทำให้เครือข่ายแข็งแกร่งขึ้น ทุกธุรกรรมการตรวจสอบเกี่ยวข้องกับบทบาทหลายอย่าง — มาดูกันว่าแต่ละบทบาทมีพฤติกรรมอย่างไร

> [!note] บทบาทในธุรกรรมการตรวจสอบ
> การตรวจสอบแต่ละครั้งเกี่ยวข้องกับบทบาทที่แตกต่างกันได้ถึงหกบทบาท ซึ่งสรุปไว้ในตารางด้านล่าง ทุกบทบาทสามารถมี DID ของตนเองในเครือข่ายชื่อเสียงแบบกระจายศูนย์ได้

| บทบาท | คำอธิบาย |
| --------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **ผู้ออก (Issuer)** | ผู้ที่เผยแพร่ข้อมูลสู่เครือข่าย — คำกล่าวอ้างว่ามีบางสิ่งเกิดขึ้น (มีการสร้าง แก้ไข หรือยุบ DID, คำกล่าวอ้าง, นโยบายของ DID หนึ่ง ฯลฯ) |
| **ผู้เป็นเจ้าของเรื่อง (Subject)** | ผู้ที่ข้อมูลนั้นเกี่ยวข้องด้วย — ผู้รับของคำกล่าวอ้าง |
| **องค์กรที่เชื่อถือได้ (Authority)** | หน่วยงานที่เชื่อถือได้ซึ่งนำชื่อของตนมาเดิมพันกับคุณภาพของคำกล่าวอ้าง โดยการสืบสวนมัน และไม่ทบทวนหลักฐานที่นำเสนอมาก็รวบรวมหลักฐานเชิงรุก |
| **ผู้สังเกตการณ์ (Observer)** | บุคคลที่สามที่เป็นอิสระซึ่งเก็บบันทึกว่าผู้ตรวจสอบจัดการกับคำกล่าวอ้างอย่างไร — เพื่อให้แน่ใจว่าผู้ตรวจสอบไม่นิ่งเงียบหรือเบี่ยงเบนจากนโยบายที่ตนประกาศไว้ |
| **ผู้ตรวจสอบ (Verifier)** | ผู้เข้าร่วมที่ถูกเลือกด้วยอัลกอริทึมซึ่งเป็นผู้ประมวลผลธุรกรรม |
| **ผู้รับมอบหมาย (Delegate)** | ผู้ที่กระทำการในนามของผู้เข้าร่วมอีกราย |
