# ผู้ตรวจสอบ

DID ใดก็ตามสามารถทำหน้าที่เป็นผู้ตรวจสอบได้ ไม่ว่าโดยตรงหรือผ่านสิทธิการตรวจสอบที่มอบหมายให้ DID รายที่สาม เพื่อให้ผม — หรือผู้รับมอบหมายของผม — สามารถตรวจสอบได้ ผมควรเข้าถึงได้บนเครือข่าย (ออนไลน์) ไม่ใช่ทุกคนจะอยากผูกมัดตัวเองกับสิ่งนั้น ซึ่งเป็นเหตุผลว่าทำไมบันทึก DID จึงสามารถระบุตัวสำรองตามลำดับความสำคัญ ที่จะปฏิบัติหน้าที่แทนในขณะที่มันออฟไลน์ได้

DID ทุกรายที่ทำงานอยู่ในเครือข่ายประกาศนโยบายของตนเองต่อสาธารณะ ผ่านกติกาที่นิยามไว้ในนโยบายนั้น มันตัดสิน — ระหว่างกระบวนการตรวจสอบ — ชื่อเสียงของคู่กรณี รวมถึงเนื้อหาและรูปแบบของคำกล่าวอ้างที่ผู้ออกได้ระบุไว้เพื่อเผยแพร่สู่เครือข่ายชื่อเสียง ส่วนหนึ่งของนโยบายคือสูตรการคำนวณที่ใช้คิดค่าธรรมเนียมบริการตรวจสอบ เมื่อสิ่งนั้นพร้อมแล้ว จากนั้นตลอดจำนวนคำกล่าวอ้างมหาศาลในเชิงสถิติที่ไหลผ่านเครือข่าย ผมก็รอให้อัลกอริทึมของเครือข่ายจับผมมาอยู่ฝั่งผู้ออก และมอบหมายให้ผมในรอบหนึ่ง ทำหน้าที่ตรวจสอบข้อมูลที่กำลังถูกออก ผู้ออกสามารถคำนวณล่วงหน้าได้ว่าผู้ตรวจสอบที่ประพฤติถูกต้องจะตอบสนองอย่างไร แต่ไม่อาจหลีกเลี่ยงการติดต่อเขา (หรือตัวสำรองของเขา) จริง ๆ ได้ การวนซ้ำกับผู้ตรวจสอบที่ถูกเลือกต้องถูกดำเนินการโดยผู้ออก แม้ในตอนที่รู้ล่วงหน้าว่ามันจะไม่ผ่าน

เรารู้ได้อย่างไรว่าผู้ออกรันอัลกอริทึมการเลือกผู้ตรวจสอบเหนือชุดของ DID ผู้สมัครเป็นผู้ตรวจสอบที่ถูกต้อง? พร้อมกับนโยบายที่ประกาศต่อสาธารณะ DID ทุกรายยังเผยแพร่รายชื่อตัวระบุปัจจุบันของเครือข่ายสังคมของตนภายในเครือข่ายชื่อเสียงด้วย หากผู้ออกนิยามเครือข่ายสังคมของตนเป็นฟองสบู่ทางสังคมที่เพียงสะท้อนและตอกย้ำมุมมองของตัวเอง ข้อมูลที่เผยแพร่ผ่านมันก็แทบจะไม่ถูกรับไว้อย่างกว้างขวางกว่านั้นโดยชุมชนอื่น การที่ผมสามารถผลักดันคำกล่าวอ้างสุดโต่งเข้าสู่เครือข่ายได้ด้วยต้นทุนสูง ก็ไม่ได้แปลว่าเมื่อตัดสินชื่อเสียงของคู่กรณี ผมจะให้น้ำหนักกับมัน คำกล่าวอ้างบางอย่างผมถูกชุมชนผลักดันให้นำมาพิจารณา (คำพิพากษาและข้อจำกัดที่กำหนดต่อผู้กระทำผิด) คำกล่าวอ้างอื่น ๆ ขึ้นอยู่กับผมทั้งหมด — ผมตัดสินใจด้วยตัวเองว่าคุณค่าทางเศรษฐกิจของการรวมหรือไม่รวมข้อมูลชิ้นหนึ่งเป็นเท่าใด
