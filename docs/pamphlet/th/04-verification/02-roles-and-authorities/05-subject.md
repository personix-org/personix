# ผู้ถูกกล่าวถึง

ผู้ที่ข้อมูลซึ่งถูกเผยแพร่เข้าสู่เครือข่ายชื่อเสียงกล่าวถึงนั้น คือผู้แบกรับข้อมูลนั้น หรือถ้าจะเรียกว่า ผู้ถูกกล่าวถึง (subject) ก็ได้ แรงจูงใจในเครือข่ายชื่อเสียงถูกวางไว้ให้ผู้ถูกกล่าวถึงมีเหตุผลทุกประการที่จะประพฤติอย่างถูกต้องและเป็นธรรมตามกติกาของตนเอง และถูกชุมชนผลักดันไปสู่ทางสายกลางอันงดงามของการรักษากติกา พวกเขายังมีแรงจูงใจที่จะประพฤติอย่างมีศีลธรรมเหนือกว่าที่กติกาซึ่งประกาศไว้กำหนดด้วยซ้ำ — นโยบายที่ประกาศไว้ล่วงหน้าไม่ได้ปิดกั้นชุมชนจากการบรรลุฉันทามติเพื่อนำการประเมินหรือมาตรการบางอย่างมาใช้ย้อนหลัง จากมุมนี้ ทางเลือกแบบเครือข่ายชื่อเสียงที่มาแทนระเบียบทางกฎหมายจึงถูกขับเคลื่อนด้วยเจตนารมณ์ของกติกามากกว่าตัวอักษรของมัน อย่างที่ควรจะเป็น
