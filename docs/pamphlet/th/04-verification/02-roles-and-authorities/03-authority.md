# องค์กรที่เชื่อถือได้

องค์กรที่เชื่อถือได้มีบทบาทคู่ คือ มันเป็น **ผู้ตรวจสอบบัญชี (auditor)** ได้ (ตรวจสอบคุณภาพของหลักฐานก่อนที่คำกล่าวอ้างจะถูกเผยแพร่) หรือเป็น **ผู้ค้ำประกัน (guarantor)** ได้ (นำชื่อเสียงของตนมาเดิมพันกับความเป็นจริงของคำกล่าวอ้าง) ไม่ว่ากรณีใด มันก็เสริมกำลังคำกล่าวอ้างของผู้ออก บริการทั้งสองนี้แยกจากกันได้ — องค์กรที่เชื่อถือได้อาจเสนอบริการอย่างใดอย่างหนึ่ง อีกอย่างหนึ่ง หรือทั้งสองอย่างพร้อมกัน สมมติฐานที่ใช้คือ บริการส่วนใหญ่ที่องค์กรที่เชื่อถือได้จัดหาให้สามารถส่งมอบได้บนพื้นฐานตลาดเสรี สิ่งนี้เป็นจริงแม้ในสาขาที่ยากจะจินตนาการว่าจะแปรรูปได้ เช่น กระบวนการยุติธรรม ซึ่งบริการเฉพาะทาง — การสืบสวน การประเมินหลักฐาน ไปจนถึงบริการที่ปัจจุบันจัดหาโดยกองทัพรวมศูนย์ (การวางแผนยุทธศาสตร์ การฝึกอบรมมาตรฐาน การจัดซื้อจัดหาและการจัดการคลังสำรอง ฯลฯ) — สามารถส่งมอบได้อย่างมีประสิทธิภาพโดยผู้เล่นในตลาด แทบไม่มีอะไรเลยที่หลังจากปรับโครงสร้างแล้วจะไม่สามารถทำให้มีประสิทธิภาพยิ่งขึ้นได้ด้วยแรงจูงใจของตลาดเสรี

> [!warning] องค์กรที่เชื่อถือได้ ผู้ออก และผู้สังเกตการณ์ จะต้องไม่มีวันเป็นผู้ตรวจสอบกรณีของตนเองเด็ดขาด
> การเลือกผู้ตรวจสอบด้วยอัลกอริทึมรับประกันความเป็นอิสระ ไม่มีใครสามารถตรวจสอบคำกล่าวอ้างของตนเอง หรือคำกล่าวอ้างที่ตนมีผลประโยชน์โดยตรงได้ นี่คือหนึ่งในกติกาพื้นฐานที่ชุมชน DID ทั้งหมดมีผลประโยชน์ในการยึดถือไว้

ภาพต่อไปนี้แสดงมุมมองที่เสริมกันของขอบเขตกิจกรรมที่องค์กรที่เชื่อถือได้ครอบคลุม (คำว่า "องค์กรที่เชื่อถือได้ (authority)" อ่านสลับกับ "ผู้ให้บริการ (service provider)" ได้)

> [!note] องค์กรที่เชื่อถือได้ในฐานะผู้สังเกตการณ์นิรนาม
> องค์กรที่เชื่อถือได้ที่มีชื่อเสียง — ลองนึกถึงโนตารีที่ธุรกิจของเขาขึ้นอยู่กับประวัติผลงานเพียงอย่างเดียว — สามารถเสนอบทบาทที่สามควบคู่กับหน้าที่หลัก (ผู้ตรวจสอบบัญชี / ผู้ค้ำประกัน) ได้ คือ บทบาทผู้สังเกตการณ์นิรนามระหว่างการตรวจสอบ เขาเก็บบันทึกที่ประทับเวลาของคำกล่าวอ้างที่ส่งเข้ามา เพื่อไม่ให้ผู้ตรวจสอบแอบทิ้งมันไปอย่างเงียบ ๆ ได้ กลไกของบทบาทผู้สังเกตการณ์ได้บรรยายไว้เพิ่มเติมในหัวข้อว่าด้วยบทบาทผู้สังเกตการณ์
