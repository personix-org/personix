# Personix — การเปลี่ยนแปลงที่ไม่ประนีประนอม

### เครือข่ายชื่อเสียงแบบกระจายศูนย์ที่ปิดกั้นไม่ได้และซื้อไม่ได้

> [!note] คำบรรยายใต้ชื่อเรื่องหมายความว่าอย่างไร
> สี่คำนี้บรรจุข้อเสนอทั้งหมดไว้ **ปิดกั้นไม่ได้ (Uncensorable)** — เครื่องมือและเครือข่ายไม่อาจถูกทำให้เงียบโดยรัฐ ผู้ให้บริการอินเทอร์เน็ต หรืออำนาจภายนอกใด ต้นทุนของการปิดกั้นมันสูงมหาศาล **ซื้อไม่ได้ (Incorruptible)** — มนุษย์ที่อยู่ภายในเครือข่ายก็ไม่อาจถูกติดสินบนอย่างเงียบ ๆ ได้เช่นกัน เพราะพฤติกรรมของผู้กระทำแต่ละคนสามารถนำไปเทียบกับนโยบายที่ตนประกาศไว้ต่อสาธารณะได้ ดังนั้นการรับสินบนจึงเป็นความไม่สอดคล้องที่พิสูจน์ได้ และเท่ากับเป็นการฆ่าตัวตายทางชื่อเสียง **กระจายศูนย์ (Decentralized)** — ไม่มีโหนด บริษัท หรือเขตอำนาจศาลใดเพียงหนึ่งเดียวที่ถูกยึดครองแล้วล้มทั้งระบบลงได้ **เครือข่ายชื่อเสียง (Reputation network)** — คุณค่าที่ไหลเวียนผ่านมันไม่ใช่เงิน ไม่ใช่คะแนนเสียง ไม่ใช่การอนุญาต แต่เป็นเครดิตที่ค่อย ๆ สั่งสม หามาได้ยาก และเสียไปได้ ซึ่งชุมชนต่างมอบให้กันเพื่อแลกกับการพูดความจริง เมื่อรวมกันแล้ว คุณสมบัติสี่ประการนี้บรรยายถึงผู้สืบทอดต่อจากการผูกขาดความไว้วางใจของรัฐในรูปแบบที่เล็กที่สุดเท่าที่จะทำงานได้จริง
