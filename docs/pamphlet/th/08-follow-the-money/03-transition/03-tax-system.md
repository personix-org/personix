# ระบบภาษีที่เรียบง่าย — เหยื่อล่อทางเข้า

เครื่องมือแรกคือระบบภาษีที่เรียบง่ายและโปร่งใสซึ่งสร้างบนโครงสร้างพื้นฐาน DID อัตราตามสัดส่วนอัตราเดียวบนรายได้ทั้งหมด ไม่มีข้อยกเว้น ไม่มีการยกเว้นภาษีชั่วคราว ไม่มีการหักลดหย่อนของบริษัท ไม่มีสิ่งจูงใจ ทุกการชำระเงินถูกเชื่อมโยงอย่างตรวจสอบได้กับ DID ที่จ่ายมัน การตรวจสอบไขว้กันเป็นเรื่องง่ายดาย

อัตราจะถูกกำหนดให้เอื้อประโยชน์มากกว่าในระบบเก่าอยู่บ้างสำหรับผู้เสียภาษีส่วนหนึ่ง — นั่นคือเหยื่อล่อให้เข้ามา ภาระภาษีจะลดลงปีต่อปี ระบบจะน่าดึงดูดยิ่งขึ้นเรื่อย ๆ และการอพยพย้ายเข้าก็จะเร่งจังหวะขึ้น ระบบนี้เป็นทั้งผู้เก็บบันทึกและผู้จัดเก็บในคราวเดียว — ไม่มีคนกลาง ไม่มีความทึบแสง
