# ความเป็นพลเมืองโดยไม่ต้องมีบัตรประชาชน

ด้วยการเปลี่ยนผ่านไปสู่โครงสร้างพื้นฐาน DID บัตรประจำตัวประชาชนที่รัฐออกให้ก็สูญเสียจุดประสงค์ในการผูกขาดของมัน คุณไม่จำเป็นต้องมีบัตรประชาชน — คุณมีตัวตน DID หลากหลาย และบางส่วนของมันก็แบกคำกล่าวอ้างว่าคุณเป็น เช่น คนเช็ก ผู้อยู่อาศัยในเทศบาลหนึ่ง ผู้สำเร็จการศึกษาจากโรงเรียนหนึ่ง คำกล่าวอ้างนั้นตรวจสอบได้ ถาวร และเป็นอิสระจากการปกครองของรัฐ

คำถามด้านการนำไปปฏิบัติทางเทคนิคเปิดขึ้น คือ ใครในตลาดจะรับหน้าที่ตรวจสอบพลเมืองที่มีอยู่นอกการควบคุมของรัฐ เพื่อย้ายผู้ที่สนใจเข้าสู่ DID ที่แบกคำกล่าวอ้างอันเหมาะสม? มีแนวโน้มมากที่สุดว่า องค์กรที่เชื่อถือได้แบบตลาดเสรีซึ่งชำนาญเฉพาะทางในการตรวจสอบตัวตนจะผุดขึ้นมา — โนตารี ชุมชนท้องถิ่น นายจ้าง พวกเขานำชื่อเสียงของตนมาเดิมพันกับข้อเท็จจริงที่ว่า DID หนึ่ง ๆ เป็นของบุคคลที่อ้างว่าเป็นเจ้าของอย่างแท้จริง ความเป็นพลเมือง — นั่นคือ การสังกัดทัศนะหนึ่งของชุมชน — ก็ถูกปลดปล่อยจากความจำเป็นในการเก็บบันทึกแบบรวมศูนย์ ด้วยการเชื่อมโยงผ่านเครือข่ายชื่อเสียง ข้อมูลที่ฝังอยู่ก็ถูกเชื่อมต่อและตรวจสอบยืนยันเป็นครั้งที่สอง สาม สี่ และเรื่อยไป

ผลที่ตามมานั้นเป็นไปตามสัญชาตญาณ แต่แก้ไม่ได้ในระบบแบบรวมศูนย์ ทุกวันนี้ ผู้นำทางการเมือง — โดยมองไปที่การได้รับเลือกตั้งใหม่ที่ง่ายขึ้น — สามารถนำเข้าปัญหาที่กระจุกตัวเข้าสู่อาณาเขตของชุมชน คือ รับผู้อพยพจากวงอารยธรรมอื่นโดยไม่คำนึงถึงขีดความสามารถในการรองรับและความเต็มใจของชุมชนที่มีอยู่เดิม เปลี่ยนแปลงชุมชนดั้งเดิมผ่านแรงกดดันที่ทำให้พวกเขาไม่อาจตามทันการหลอมรวมผู้มาใหม่จากวงอารยธรรมอื่น ในเครือข่าย DID ผู้อพยพที่ถูกรับเข้ามาอย่างทุจริตไม่อาจแน่ใจได้ว่าชุมชนจะยังคงถือว่าเขาเป็นพวกเดียวกันต่อไป สมาชิกของชุมชนไม่จำเป็นต้องทนโดยปราศจากเหตุผลกับคนแปลกหน้าที่มาเคาะประตูบ้านในเครื่องแบบของชุมชนและข่มขู่พวกเขาด้วยความชอบด้วยกฎหมายของมาตรการที่เขาตั้งใจจะดำเนินการในบ้าน (การยึดโทรศัพท์ของเด็กเพราะโพสต์บนโซเชียลมีเดีย) ด้วยชื่อเสียงแบบกระจายศูนย์ คนส่วนใหญ่ในสังคมไม่จำเป็นต้องยอมจำนนต่อสิ่งนี้ — เพราะการสังกัดชุมชนไม่ได้ถูกตัดสินโดยเจ้าหน้าที่ แต่โดยตัวชุมชนเอง ผ่านสัญญาณชื่อเสียงของมัน

น้ำหนักของคะแนนเสียงเลือกตั้งในเรื่องที่อยู่ในอำนาจของรัฐ ในอนาคตอาจถูกทำให้สัมพันธ์อย่างเข้มงวดกับบันทึกการมีส่วนร่วมในระบบภาษีที่เรียบง่าย เมื่อผนวกกับคำกล่าวอ้าง DID ที่เหมาะสม (เช่น "บุคคลนี้เป็นพลเมืองเช็ก") คนต่างชาติก็สามารถถูกกันออกจากการเลือกตั้งได้ — ทะเบียนราษฎรก็เพียงย้ายมาที่นี่
