# สี่เครื่องมือที่หนุนกันและกัน

จนถึงตอนนี้ เครือข่ายชื่อเสียง DID อาจดูมีประโยชน์หลัก ๆ สำหรับความยุติธรรมและฉันทามติ ผมเชื่อว่ามันสามารถทำให้ตัวเองมีเสถียรภาพและทนต่อการโจมตีได้ — อย่างเป็นระบบคุณธรรมนิยม บนพื้นฐานของคุณความดีความชอบที่แท้จริงมากกว่าตำแหน่งที่เป็นทางการ แต่ชื่อเสียงเพียงลำพังจะไม่บังคับให้รัฐยอมถอย เศรษฐศาสตร์ต่างหากที่จะทำได้ และแรงกดดันที่กระทำผ่านมัน

ไม่มีอะไรหยุดเราจากการใช้ตัวตน DID เป็นผู้จัดการเครื่องมือเพิ่มเติมที่กดดันเงินอย่างหนัก อย่าเริ่มด้วยความสมัครใจเต็มที่ในส่วนของพลเมือง — จงกำหนดทิศทางที่รัฐหยุดไม่ได้ การเปลี่ยนผ่านตั้งอยู่บนเครื่องมือเฉพาะสี่อย่างที่ค้ำหลังให้กันและกัน ไม่มีอันใดเพียงพอด้วยตัวมันเองเลย
