# อภิธานศัพท์

| ศัพท์ | ไทย | ความหมาย |
|------|-------|---------|
| **Authority** | องค์กรที่เชื่อถือได้ | หน่วยที่ไว้วางใจได้ (บุคคล องค์กร) ซึ่งตรวจสอบข้อมูลและนำชื่อเสียงของตนมาเดิมพันกับมัน อาจเป็นแบบเฉพาะทาง (ด้านการสืบสวน กฎหมาย เทคนิค) |
| **Claim** | คำกล่าวอ้าง | โดยทั่วไป คือ คำกล่าวใด ๆ ที่ตรวจสอบได้ ในที่นี้ คือ บันทึกที่เผยแพร่สู่เครือข่ายชื่อเสียง — การยืนยันเกี่ยวกับเหตุการณ์ คุณสมบัติ หรือความสัมพันธ์ ที่ถูกลงนามเชิงวิทยาการเข้ารหัสและตรวจสอบแล้ว เช่น "ผมเป็นผู้อยู่อาศัยในเทศบาล X" หรือ "บุคคลนี้ผิดสัญญา" |
| **Compartmentalization** | การแยกส่วน | โดยทั่วไป คือ การแยกข้อมูลออกเป็นหน่วยที่โดดเดี่ยว เพื่อว่าการเปิดเผยหน่วยหนึ่งจะไม่ทำให้หน่วยอื่นเสียหาย เป็นหลักการที่รู้จักกันจากหน่วยข่าวกรอง ในที่นี้ คือ ตัวตน DID คู่ขนานในระบอบเผด็จการ — การเจาะได้ตัวหนึ่งไม่เผยตัวอื่น |
| **Consistent Hash Ring** | วงแฮช | กลไกเชิงอัลกอริทึมสำหรับเลือกผู้ตรวจสอบ — ตำแหน่งบนวงถูกกำหนดโดยแฮชของเอกสาร DID ภายในกราฟสังคม รับประกันการเลือกที่ไม่กำหนดตายตัวแต่ตรวจสอบได้ |
| **DID** | DID (ตัวตนแบบกระจายศูนย์) | ตัวตนดิจิทัลที่คุณสร้างและควบคุมด้วยตนเอง โดยไม่ต้องมีอำนาจส่วนกลาง ถูกลงนามเชิงวิทยาการเข้ารหัสด้วยกุญแจส่วนตัวของคุณ — ไม่มีใครเพิกถอนหรือปลอมแปลงมันได้ |
| **DID Document** | เอกสาร DID | ไฟล์ข้อมูลที่เข้าถึงได้สาธารณะซึ่งอธิบายตัวตน DID ของคุณ — บรรจุกุญแจสาธารณะ ที่อยู่ในเครือข่าย และเมทาดาตา ใช้เพื่อตรวจสอบตัวตนของคุณในเครือข่าย |
| **Due Diligence** | การตรวจสอบสถานะ | โดยทั่วไป คือ การตรวจสอบคู่สัญญาอย่างละเอียดก่อนเข้าสู่ความสัมพันธ์ทางธุรกิจหรือกฎหมาย — ตรวจประวัติ การเงิน ชื่อเสียง และความเสี่ยงของเขา ในที่นี้ คือ ในเครือข่ายชื่อเสียง มันเกิดขึ้นเร็วกว่าและอัตโนมัติกว่า ด้วยความพร้อมของบันทึกที่ตรวจสอบแล้ว |
| **Economic Neutrality Principle** | หลักความเป็นกลางทางเศรษฐกิจ | พฤติกรรมที่ซื่อสัตย์ในเครือข่ายมีมูลค่าทางเศรษฐกิจใกล้ศูนย์ — ต้นทุนการเผยแพร่ถูกคืนกลับมาในรูปรางวัลการตรวจสอบ พฤติกรรมที่ไม่ซื่อสัตย์คือการขาดทุนสุทธิ |
| **Emergent** | ผุดขึ้นเอง | เกิดขึ้นเองโดยธรรมชาติจากปฏิสัมพันธ์ของส่วนที่เรียบง่ายกว่า โดยไม่มีใครออกแบบหรือกำกับ ฝูงนกบินเป็นรูปขบวนโดยไม่มีแผน — รูปขบวนผุดขึ้นมาจากกฎง่าย ๆ ที่แต่ละตัวปฏิบัติตาม |
| **Emergent Social Contract** | สัญญาประชาคมที่ผุดขึ้นเอง | กติกาพฤติกรรมที่เกิดขึ้นไม่ใช่จากเบื้องบน (กฎหมาย) แต่จากเบื้องล่าง — จากปฏิสัมพันธ์ที่เกิดซ้ำและฉันทามติภายในชุมชน |
| **ESR** | ทะเบียนการใช้จ่ายอิเล็กทรอนิกส์ | ระบบที่เสนอสำหรับการติดตามรายจ่ายสาธารณะอย่างโปร่งใส — ทุกรายจ่ายของรัฐที่เกิดขึ้นจริงถูกจับคู่กับการชำระเงินที่วางแผนไว้ ได้แรงบันดาลใจจาก EET ของเช็ก แต่หันมาใช้กับรัฐ |
| **Hash** | แฮช (ลายพิมพ์) | โดยทั่วไป คือ ฟังก์ชันคณิตศาสตร์ทางเดียวที่สร้าง "ลายพิมพ์" ที่มีความยาวคงที่และไม่ซ้ำจากอินพุตใด ๆ — เหมือนลายนิ้วมือของเอกสาร อินพุตเดิมให้เอาต์พุตเดิมเสมอ แต่ไม่อาจอนุมานอินพุตกลับจากเอาต์พุตได้ ในที่นี้ ใช้เพื่อกำหนดตำแหน่งบนวงแฮชและตรวจสอบความครบถ้วนของเอกสาร |
| **Just-in-Time Funding** | การจัดสรรเงินทุนแบบทันเวลาพอดี | การจัดสรรเงินทุนของรัฐโดยมีเงื่อนไขเป็นความโปร่งใส — เงินไหลก็ต่อเมื่อรัฐยอมรับ ESR และจับคู่รายจ่ายของตน คานงัดสำหรับบีบให้เกิดความร่วมมือ |
| **Meritocracy** | คุณธรรมนิยม | โดยทั่วไป คือ ระบบที่สถานะถูกกำหนดโดยคุณความดีความชอบที่แท้จริงและความสามารถที่พิสูจน์แล้ว ไม่ใช่ตำแหน่งที่เป็นทางการ เส้นสาย หรืออภิสิทธิ์ที่สืบทอดมา ในที่นี้ คือ เครือข่ายชื่อเสียงเอื้อประโยชน์โดยธรรมชาติต่อผู้ที่มีส่วนช่วยชุมชนอย่างพิสูจน์ได้ — เสียงของเขามีน้ำหนักมากกว่าเพราะประวัติผลงาน ไม่ใช่เพราะตำแหน่ง |
| **Onion Gateway** | เกตเวย์หัวหอม | ที่อยู่ในเครือข่ายของตัวตน DID บนเครือข่ายหัวหอม (onion) แยกจากเอกสาร DID — สามารถเปลี่ยนได้โดยไม่สูญเสียตัวตน (คล้ายการเปลี่ยนที่อยู่ IP ที่อยู่เบื้องหลังโดเมน) |
| **Onion Routing** | การกำหนดเส้นทางแบบหัวหอม (Tor) | โปรโตคอลการสื่อสารที่รับประกันการปิดกั้นไม่ได้ของเครือข่าย ข้อความถูกเข้ารหัสเป็นชั้น ๆ — แต่ละโหนดถอดออกหนึ่งชั้นแต่ไม่รู้เส้นทางทั้งหมด |
| **Oracle Problem** | ปัญหาออราเคิล | โดยทั่วไป คือ จะทำให้แน่ใจได้อย่างไรว่าข้อมูลที่เข้าสู่ระบบดิจิทัลสอดคล้องอย่างซื่อตรงกับสิ่งที่เกิดขึ้นจริงในโลกกายภาพ ศัพท์นี้มีต้นกำเนิดจากแวดวงบล็อกเชน ในที่นี้ คือ แก้ไขผ่านองค์กรที่เชื่อถือได้ซึ่งนำชื่อเสียงของตนมาเดิมพันเป็นหลักประกันว่าบันทึกดิจิทัลสอดคล้องกับความเป็นจริงทางกายภาพ |
| **Phenomenological** | เชิงปรากฏการณ์วิทยา | โดยทั่วไป คือ แนวทางที่ศึกษาปรากฏการณ์ตามที่มันแสดงตัวออกมาในประสบการณ์ตรง โดยสังเกตสิ่งที่ตามมาจากมัน โดยไม่มีทฤษฎีที่กำหนดไว้ล่วงหน้า ในที่นี้ คือ เสรีภาพ สัญญาประชาคม และบรรทัดฐานพฤติกรรม เป็นปรากฏการณ์ที่สังเกตได้ — ผลพวงของปฏิสัมพันธ์เล็ก ๆ นับพันครั้งระหว่างผู้คน ไม่ใช่หลักการที่นิยามจากเบื้องบน |
| **Policy** | นโยบาย | โดยทั่วไป คือ ชุดกติกาหรือหลักการที่กำกับพฤติกรรมในบริบทหนึ่ง ในที่นี้ คือ ผู้เข้าร่วมทุกคนในเครือข่าย DID ประกาศนโยบายของตน — เขาตอบสนองต่อพฤติกรรมเฉพาะอย่างของผู้อื่นอย่างไร ยึดกติกาข้อใด และถือว่าบทลงโทษใดได้สัดส่วน ผลรวมของนโยบายก่อรูปเป็นสัญญาประชาคมที่ผุดขึ้นเอง |
| **Proxy** | ตัวแทน | โดยทั่วไป คือ ตัวแทนหรือตัวกลาง — ระบบหรือหน่วยที่กระทำการแทนอีกฝ่าย ในที่นี้ใช้ในสองบริบท คือ (1) ESR ในฐานะตัวแทนที่จับคู่รายจ่ายสาธารณะกับการชำระเงินที่วางแผนไว้ (2) ผู้สังเกตการณ์ในฐานะตัวแทนระหว่างผู้ออกกับผู้ตรวจสอบในกลลวงผู้สังเกตการณ์ |
| **Publisher** | ผู้ออก | ผู้เข้าร่วมเครือข่ายที่สร้างและเผยแพร่บันทึก (คำกล่าวอ้างเกี่ยวกับความอยุติธรรม การเยียวยา และอื่น ๆ) แบกรับต้นทุนของการเผยแพร่ |
| **Reputation-Based Social Network (RSN)** | เครือข่ายสังคมด้านชื่อเสียง | เครือข่ายสังคมแบบกระจายศูนย์ที่ผู้เข้าร่วมแลกเปลี่ยนข้อมูลป้อนกลับเกี่ยวกับพฤติกรรมในโลกจริง บันทึกสร้างขึ้นด้วยต้นทุนสูง อ่านได้ในราคาถูก |
| **Reputation Signal** | สัญญาณชื่อเสียง | บันทึกรายบุคคลในเครือข่าย — เชิงบวก (การเยียวยาความเสียหาย การทำตามพันธะ) หรือเชิงลบ (ความอยุติธรรม การผิดสัญญา) เมื่อสั่งสมกัน สัญญาณก่อรูปเป็นโปรไฟล์ชื่อเสียง |
| **Social Graph** | กราฟสังคม | เครือข่ายของผู้ติดต่อของคุณและผู้ติดต่อของผู้ติดต่อของคุณ อัลกอริทึมค้นหาผู้ตรวจสอบที่ระดับความลึกที่กำหนดค่าได้ (เช่น 3 ระดับ) ไม่มีบล็อกเชนสากล — เครือข่ายก่อรูปเป็นชุมชนที่มีการซ้อนทับกันโดยธรรมชาติ |
| **Tax Allocation** | การจัดสรรภาษี | กลไกที่ผู้เสียภาษีตัดสินใจว่าภาษีส่วนหนึ่งของตนจะไปที่ใด สัดส่วนที่จัดสรรได้เติบโตขึ้นปีต่อปี |
| **Track Record** | ประวัติผลงาน | โดยทั่วไป คือ ประวัติผลลัพธ์ ความสำเร็จ และความล้มเหลวในอดีตของบุคคลหรือองค์กร ในที่นี้ คือ ผลรวมของปฏิสัมพันธ์ในอดีตทั้งหมดของตัวตน DID หนึ่งในเครือข่าย — คำกล่าวอ้างที่ตรวจสอบแล้ว บันทึกที่ยอมรับและปฏิเสธ — ซึ่งชื่อเสียงของมันถูกอนุมานมาจากสิ่งเหล่านี้ |
| **Verifier** | ผู้ตรวจสอบ | ผู้เข้าร่วมที่ถูกเลือกเชิงอัลกอริทึมให้ตรวจสอบและเผยแพร่บันทึก นำชื่อเสียงของตนมาเดิมพันกับความจริงของข้อมูล |
