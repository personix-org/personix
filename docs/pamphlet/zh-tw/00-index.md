# Personix — 絕不妥協的變革

### 一個不可審查且不可腐化的去中心化聲譽網路

> [!note] 副標題的意涵
> 四個詞承載了整個提案。**不可審查**——這些工具與網路無法被國家、網路服務供應商或任何外部權威所噤聲；審查它們的代價高得離譜。**不可腐化**——網路內部的人也無法被悄悄收買；每個行為者的行為都能公開對照其宣告的政策，因此賄賂會成為一種可被證明的不一致，也就等於聲譽上的自殺。**去中心化**——沒有任何單一節點、公司或司法管轄區能被攻陷，進而讓整個體系崩潰。**聲譽網路**——在其中流動的價值不是金錢、不是選票、不是權限，而是社群因彼此說出真相而相互授予、緩慢累積、可能失去的信用。這四項特性合在一起,描繪出足以取代國家對信任壟斷的最小可行後繼者。
