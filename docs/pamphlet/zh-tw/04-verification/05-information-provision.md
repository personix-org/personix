# 提供關於你自己的資訊

當兩個彼此不認識的 DID 主體進入一段經濟關係時，我們可以代表對方，向我們自己的社群簽署一份請求，要它提供關於我們的資訊。然而，這是對「社群是什麼」極其天真的想像。它們不是封閉的集合——單一個 DID 可以是多個社群的參與者。

從某個特定參與者的角度看，社群更像是一種現象學現象，透過他的社群網路顯現出來；它並不是那種總是值得被明確劃定的東西。一座村莊的居民可以形成一個社群，但一個只在週末才來到那裡的人，也可能屬於同一座村莊裡的另一個社群。一支足球隊連同它的球迷、職員，以及所有相關者的家庭，也可以是一個社群。一個民族，或一個國家的公民，也可以形成一個或多個社群。從不同角度看待一個 DID，可以得出對社群不同（而且往往很直覺）的看法。

因此，位於邊界上的各個 DID 就是社群之間的橋樑——而且，就跟現實生活中一樣——它們在提供關於其他社群成員之資訊上扮演角色，無論是業餘層次，還是專業層次，例如某個專門連結人群、並彙整關於高風險 DID 之資訊的權威機構。

DID 網路中某些類型的資訊，很適合無條件地相互交換（暴力犯罪、詐欺等等）。然而，另一些類型的資訊，社群可能會把它視為僅限社群內部使用（相當於公民身分、對社群提供的服務等等）。這類資訊能否被散布，取決於社群成員所宣告的政策。

社群在自己的圈子內守護自己的隱私，而作為回報，則以無條件的基礎交換互惠的資訊。
