# 簽發者

我們先前已經見過簽發者。當某人受了委屈，或想廣播自己的某項成就時，正是由該 DID 所代表的那個人，觸發把該資訊放進網路的流程——因為他對此有首要的利害關係（動機要嘛是渴望得到滿足感，要嘛是希望改善自己的公眾形象）。

> [!note] 正面聲明
> 關於我自己的正面聲明，我可以同時作為它的主體與簽發者留在手上，以備在我想用到它們的情境下使用（一張文憑、一份服務完成的證明，等等）。這正是正面聲明與負面聲明不同之處：分享一筆經驗證的負面聲明，符合整個社群的利益，而分享一筆正面聲明，則符合其持有者的利益。
