# 驗證者

任何 DID 都能擔任驗證者，可以直接擔任，也可以透過把驗證權委託給第三個 DID 來擔任。為了讓我——或我的受託者——能夠驗證，我應該在網路上可被觸及（在線）。不是每個人都願意做出這樣的承諾，這正是為什麼一筆 DID 紀錄可以依優先順序列出一些替補者，在它離線時代它履行這項功能。

每一個在網路中活躍的 DID，都公開宣告自己的政策。透過該政策所定義的規則，它在驗證流程中判斷對方的聲譽，以及發行者已標記要發布到聲譽網路之主張的內容與形式。政策的一部分是用來計算驗證服務費用的計算公式。一旦這些就位，那麼在統計上大量流經網路的主張中，我便等待網路的演算法把我抽到發行者這一側，並在某次迭代中指派我去驗證正被發行的資訊。發行者可以事先算出一個行為正確的驗證者會如何反應，卻無法迴避實際去聯絡他（或他的替補者）；即使發行者事先知道通不過，與被選中之驗證者的那次迭代仍得由發行者執行。

我們怎麼知道發行者是在正確的候選驗證者 DID 集合上跑驗證者選取演算法的？除了公開宣告的政策之外，每個 DID 也會發布它在聲譽網路中之社群網路的當前識別碼清單。如果一個發行者把自己的社群網路界定為一個只會回聲、只會強化其自身觀點的社群同溫層，那麼透過它發布的資訊，就很難被其他社群更廣泛地接收。我設法以高昂代價把一筆激進的主張推進網路，並不意味著在判斷對方聲譽時，我會賦予它任何份量。有些主張是我的社群逼我納入考量的（對犯錯者所施加的刑罰與限制）；另一些則完全由我決定——某筆資訊納入或排除的經濟價值，我自己說了算。
