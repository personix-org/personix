# 主體

那些被發布到聲譽網路之資訊所涉及的人，就是它的承載者，或者你也可以說，它的主體。聲譽網路中的誘因是這樣設置的：主體有充分的理由依自己的規則正確而公道地行事，並被社群推向某種「守規則的黃金中庸」。他們甚至有誘因表現得比自己宣告的規則所要求的更合乎道德——預先宣告的政策，並不排除社群達成共識、追溯性地套用某種評估或措施。從這個角度看，聲譽網路作為法律秩序之替代方案，正如人們所預期的，更多是由規則的精神、而非其字面所驅動。
