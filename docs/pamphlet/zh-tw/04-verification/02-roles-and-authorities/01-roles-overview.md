# 角色總覽

在談網路及其基本性質的那一章裡，我們已經簡略觸及其中一些角色。現在正是時候更仔細地再看它們一遍，並補上為了讓網路更穩健所需的其他角色。每一筆驗證交易都牽涉數個角色——讓我們看看它們如何行事。

> [!note] 驗證交易中的角色
> 每一筆驗證最多牽涉六個不同的角色，彙整於下表。它們全都能在去中心化聲譽網路裡擁有自己的 DID。

| 角色 | 說明 |
| --------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **發行者** | 把資訊發布到網路的人——主張某件事發生了（一個 DID 被建立、編輯或解除，一筆主張，某個 DID 的政策，等等） |
| **主體** | 資訊所談論的人——主張的收件對象 |
| **權威機構** | 一個受信任的實體，透過調查一筆主張、並審視所呈之證據或主動蒐集證據，以自己的名聲為該主張的品質背書 |
| **觀察者** | 一個獨立的第三方，記錄驗證者如何處理該主張——確保驗證者既不保持沉默、也不偏離自己宣告過的政策 |
| **驗證者** | 一個以演算法選出的參與者，負責處理該筆交易 |
| **受託者** | 代表另一個參與者行事的人 |
