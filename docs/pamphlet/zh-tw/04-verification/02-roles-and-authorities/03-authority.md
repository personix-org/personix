# 權威機構

權威機構扮演雙重角色：它可以是**稽核者**（在一筆主張被發布前驗證證據的品質），也可以是**擔保者**（以自己的聲譽為一筆主張的真實性背書）。無論哪一種，它都強化了發行者的主張。這兩種服務是可分離的——一個權威機構可以只提供其中一種、另一種，或兩者兼供。工作假設是：權威機構所提供的多數服務，都能在自由市場的基礎上交付。這一點即使在難以想像會被私有化的領域也成立，例如司法，其中各種專門服務——調查、證據評估，一直到今日由中央化軍隊所提供的服務（戰略規劃、標準化訓練、採購與庫存管理，等等）——都能由市場行為者有效率地交付。幾乎沒有什麼是在重整之後，無法藉由自由市場的誘因變得更有效率的。

> [!warning] 權威機構、發行者與觀察者，絕不能是自己案件的驗證者。
> 驗證者的演算法選取保證了獨立性。沒有人能驗證自己的主張，或驗證一筆自己有直接利害關係的主張。這是整個 DID 社群都有興趣維護的基本規則之一。

> [!note] 作為隱名觀察者的權威機構
> 一個有聲望的權威機構——想想一位生意完全仰賴過往紀錄的公證人——可以在主要功能（稽核者／擔保者）之外，額外提供第三種：在驗證期間擔任隱名觀察者的角色。他們保存一份帶時間戳記的所提交主張紀錄，好讓驗證者無法悄悄把它丟掉。觀察者角色的機制，在論觀察者角色的段落中會有進一步的描述。
