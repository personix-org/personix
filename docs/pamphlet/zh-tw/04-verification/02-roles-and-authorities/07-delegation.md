# 委託

文明把它的經濟成長建立在分工與專業化的能力之上。世界在它全部的絢爛中是複雜的，而我們把它連同全部複雜性一併掌握的機會近乎於零。自然的出路是把一大批支撐舒適生活的活動委託給專門的供應商，他們替我們省下時間、能量與金錢，並讓我們反過來得以專業化——提供我們最擅長、或市場在我們身上評價最高的服務。

同樣的委託邏輯延伸進聲譽網路。在〈自由—極權開關（以及委託）〉那一章，我們闡述了藉由限制「在特定時間窗口內可發布到網路的主張數量」來保障自由社會的原則（簡化地想，就是每年低個位數的發布權，好讓社會維持最大程度的自由）。這個原則可以擴充到多個維度。我們不必只有一個數字——我們可以有好幾個上限，套用於不同類型的主張。標記別人偽善所用的數字，可以和商業往來中不當行為所用的不同；而比方說，像更改密碼這種 DID 文件的變動，社群大概根本不會在意，諸如此類。這一切都取決於社群在演化的時間裡，如何界定什麼才符合它「在目標自由度與究責度之間找到正確平衡」的利益。

為什麼社群授予我的發布權數量應該夠小？以一筆負面主張標記一個 DID（主體），會摧毀花了很長時間才建立起來的聲譽，而且損害會持續。一個被摧毀的聲譽，會因每一次進一步或重複的冒犯，面對來自社群、逐級升高的一連串制裁，一直到把破壞性實體徹底剷除（極端情況）。一套指數式升高的懲罰梯度，並不需要大量的主張，只要它們有可驗證的證據支撐。這在和平的穩態下成立，也就是社會未被災難（外部或內部）撼動的時候。

對於發生機率極低的事件，統計頻率套用在一個個人身上時起伏很大。套用在整個社群的人口上則不然。這正是「把自己的發布權委託給專門的彙整型權威機構」的價值所在，這些機構——很像損失發生時的相互保險——動用你的權利、代你行使它。讓我們少一點抽象，給幾個例子：
- 偵測並打擊組織犯罪
- 執行商業協議
- 管理各種特權（教育證明、資產的取得／處分，等等）
- 諸如此類

> [!note] 「發布權」實際上如何運作
> 受託者的圖示為求清楚，把發布權畫成實體代幣，但系統裡並不存在這樣的物件。實際發生的是這樣：你想要繼續保持良好關係的那些人——你的社群——他們的政策，會彙整成一條湧現的規則，規定他們每年會把你的幾筆主張當成相關的來接受，超過就開始把你當雜訊處理。這個上限之所以存在，是為了讓網路不被瑣碎的「萬一……怎麼辦」主張淹沒，並維持社群所想要的那般自由（透過限制數量來保全訊號）。
>
> 你的社群允許你讀什麼，你就讀什麼。這裡有一個範圍，依你最看重哪些人而有一些彈性。接著你在那個額度之內決定——你自己要發布幾筆主張，又要委託幾筆給專業服務，讓它們只在事件落入其職掌範圍時代你發布。正是這一點讓你保持良好關係，卻不必為發生在你身上的每一件小事都提交一筆主張。
>
> 圖示裡的「代幣」是這個「讀取—決定」循環的視覺替身，而非字面上的實物。

在聲譽網路裡，能夠撤銷已委託的發布權是值得的。只要受託者尚未使用被委託的權利，這隨時都能做到。
