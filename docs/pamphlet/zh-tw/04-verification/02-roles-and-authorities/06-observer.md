# 觀察者

觀察者角色消除了驗證者「彎折規則」的誘因。在驗證者不喜歡發行者或權威機構之請求的情況下，他們大可乾脆保持沉默——不回應、卡住演算法的接續。觀察者——或一組觀察者——以自己的聲譽擔保，記錄下驗證者是如何被查詢的。如果驗證者在宣告過的政策明明另有規定的情況下仍保持沉默，他們就會被判定違反協定。

![觀察者——為驗證者留下紀錄](../../../Info%20Graphics/v5/v5-08g-role-observer.webp)

## 機制：時間戳記與挑戰碼

在你把一筆主張送給驗證者之前，你先讓它繞經觀察者——你信任的人，或是收取小額費用的專門觀察者服務供應商。每一位觀察者收到你的提交，為它蓋上時間戳記，簽署他們看見它送出，並產生一個挑戰碼——他們簽章的一個密碼學雜湊。這些碼會附加到你的請求上。驗證者看得見它們，卻完全不知道觀察者是誰，甚至不知道這些碼是不是真的。於是觀察者就充當發行者與驗證者之間的代理，握有一份「主張已被提交、以及它包含了什麼」的獨立紀錄。他們可以有零到 N 個。

當驗證者誠實行事時——依其宣告的政策接受或拒絕——這些碼始終不透明。沒有人被暴露。

但如果驗證者在政策明明是配合的情況下卻保持沉默，或以與其所發布內容相矛盾的方式回應，你就握有原始的觀察者簽章。你可以把它們發布出來，作為「主張已被提交、且驗證者未遵循協定」的代理證詞。任何人都能驗證這些簽章與挑戰碼相符。

## 妙處所在：你根本不需要真的觀察者

而這裡是最優雅的部分：**你根本完全不需要真的觀察者。**你可以產生一些看起來與挑戰碼一模一樣的隨機數。驗證者分辨不出差別——他們只能擲骰子，賭要不要拿自己的聲譽去冒險。在他們收到的每一個請求背後，都可能有一位受人敬重的觀察者正隱名盯著——也可能純粹是雜訊。驗證者不知道。而那份不確定性，正是這個機制。

維持誠實壓力的成本：幾乎為零（隨機數是免費的）。而不誠實對驗證者的潛在代價：災難性的。即使實際上根本沒有人在看，誠實的行為也受到激勵。

這套系統之所以奏效，是因為每個人都有一點偏執。不確定性比監控更便宜。

![讓驗證者保持誠實的那記虛張聲勢](../../../Info%20Graphics/v5/v5-09-trik-s-pozorovateli.webp)

> [!note] 單次迭代中的多位驗證者
> 一條可強化驗證者可用性的伴隨規則，可以是一種演算法擴充，讓單次迭代回傳的不只是一位、而是一組候選驗證者。
