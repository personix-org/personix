# 共識與驗證流程

要對「一個社會平均而言應當維護並執行哪些規則」建立共識，以下機制能有所幫助。身為一個 DID 參與者，我宣告我所訂閱、並將據以生活的規則，並把它們發布出來。（可以把它想成在我看來構成我理想世界的那些章程與規約——一個我不覺得受限、反而覺得安全的世界。）

我可以事先估計我的 DID 聯絡人會如何反應——並評估在假設會發生的一般社交或商業互動中，我會被制裁得多重、被誰制裁。

決定性的評估發生在你向另一個 DID 索取資訊、或請他驗證一筆主張（或向某個權威機構請求服務，諸如此類）——也就是你想發布到聲譽網路的主張——的時候。結果應該會跟你自己針對對方所宣告之政策、以空跑方式進行評估時得到的一樣——如果不一樣，那麼對方那邊就有問題：他們正試圖玩一場不誠實的遊戲。

其結果要嘛是接受、並附上一個驗證報價（在驗證者或權威機構服務的情況下），要嘛是拒絕。對「偏離評估者政策」的制裁與獎金，都被折算進報價之中。請求者接著決定要接受這些條件，還是進入分配演算法的下一輪驗證——重複這個流程，直到滿意為止，或直到經濟上再繼續已無意義為止。

> [!note] 社會圖譜
> 聲譽網路首先是一個社群網路。你加入聯絡人——那些同意建立連結的人。他們有聯絡人，那些聯絡人又有聯絡人。演算法在一個可設定的深度內尋找驗證者（例如三層：你的直接聯絡人、他們的聯絡人，再往外一層）。不需要全球性的區塊鏈——網路自然形成一個個社群，並與其他社群有所重疊。
>
> 演算法是非決定性的：它對你的主張文件取雜湊，把該雜湊映射到這個圈子內已知身分所構成之環上的某個位置，並選出最鄰近的那一個作為候選驗證者。你無法預測或影響誰會來驗證你的主張。

每一位驗證者的拒絕都會使你的文件變大、並增加其處理成本——這是第一個成本管道（文件成長）。每一位新的驗證者都會依資料量、你的聲譽，以及你主張的內容偏離其宣告之驗證政策的程度來收費——這是第二個成本管道（風險溢價）。而每一次迭代都花費時間與能量——第三個成本管道。

> [!note] 驗證者依序檢查什麼
> 一旦被選中，驗證者會以大致四個有序步驟評估一筆主張——最便宜的過濾先做，昂貴的內容檢查最後做：
>
> 1. **政策閘門。** 這類主張是否落在驗證者公開驗證的範圍之內？若否，請求會被當場拒絕。
> 2. **權威信任。** 為該主張背書的權威機構，在驗證者自己宣告的政策下是否夠受信任？一個低於驗證者信任門檻的權威機構，無論主張內容為何，都構成拒絕的理由。
> 3. **發行者聲譽。** 發行者是否達到驗證者針對這類主張所宣告的聲譽門檻？聲譽偏低可能提高費用，也可能觸發拒絕。
> 4. **內容檢查。** 唯有在前三道閘門都通過後，驗證者才評估主張本身——簽章、內部一致性、形式正確性，以及它偏離驗證者政策的程度。針對這最後一步所收的費用，反映了實際承擔的風險。
>
> 驗證者會發布規範上述每一道閘門的政策，因此這些步驟並非由他任意裁量——他受制於自己早已宣告過的內容。偏離已發布的政策，本身就是一筆可對他發布的主張，而他得用自己的聲譽為此付出代價。

其結果是：發布一筆可信而有用的主張，幾乎不花什麼。發布一筆激進的主張，成本較高。發布一則謊言則變得貴到令人卻步——你必須一位又一位地迭代驗證者，而每一位拒絕你的驗證者都會增添成本。市場為你的主張定價，而這個價格告訴你，你相對於自己活動所在的社群站在什麼位置。

僅僅宣告你遵守某條規則、實際上卻不遵守，是不夠的。在那種情況下，你的 DID 就冒著被發布一筆負面紀錄、揭穿其偽善的風險——這會把你變成所有其他人的風險。結果應該是規則更少、但被更一貫地遵守，並清理掉那座連法律專業人士都幾乎無法穿行的法律與規章叢林。

> [!note] 共識對比究責
> 為了讓網路能作為有價值的資訊來源，一個 DID 不該太過激進——否則其他人會拒絕它。社會壓力會尋求均衡，而試圖破壞它的舉動很可能會受到懲罰。

> [!warning] 票數不等於一個聲音的份量
> Juraj Karpiš 說「金錢是善行的記憶」。我要補上一句：聲譽是惡行的記憶。
>
> 由此推論，就功績制而言，貢獻較多且沒有壞聲譽的人，理應在社群中擁有較大的聲音份量。從雙邊關係的角度來看：當我權衡該迎合哪些共識壓力時，份量最重的是那些讓我獲得最大經濟利益的關係。十個和我沒有實際交易往來的人，對我的影響遠不及一個長期的商業夥伴。這個典範不限於商業——它延伸到社會、政治與其他關係。
