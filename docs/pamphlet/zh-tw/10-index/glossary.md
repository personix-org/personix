# 詞彙表

| 詞條 | 捷克文 | 意義 |
|------|-------|---------|
| **權威機構（Authority）** | Autorita | 一個受信任的實體（個人、組織），驗證資訊並以自己的聲譽為它背書。可以是專門的（偵查、法律、技術）。 |
| **主張（Claim）** | Tvrzení | 一般而言：任何可驗證的陳述。此處：一筆發布到聲譽網路的紀錄——關於某事件、屬性或關係的斷言，並以密碼學方式簽署與驗證。例如「我是市鎮 X 的居民」或「此人違反了一份契約」。 |
| **區隔化（Compartmentalization）** | Compartmentalizace | 一般而言：把資訊分隔成彼此孤立的單元，好讓其中一個單元被暴露不至於危及其他單元。這是情報機構所熟知的原則。此處：獨裁政權下的並行 DID 身分——其中一個被攻破並不會洩漏其他身分。 |
| **一致性雜湊環（Consistent Hash Ring）** | Hash ring | 一種用來選取驗證者的演算法機制——環上的位置由社會圖譜內 DID 文件的雜湊所決定。確保一種非決定性、卻可驗證的選取。 |
| **DID** | DID (Decentralizovaná identita) | 一種由你自己建立、自己掌控的數位身分，沒有中央權威。以你的私鑰做密碼學簽署——沒有人能撤銷它或偽造它。 |
| **DID 文件（DID Document）** | DID dokument | 一份公開可得的資料檔，描述你的 DID 身分——包含公鑰、網路位址與中繼資料。用來在網路中驗證你的身分。 |
| **盡職調查（Due Diligence）** | Due diligence | 一般而言：在進入商業或法律關係之前，對對方進行深入的查核——檢視其歷史、財務、聲譽與風險。此處：在聲譽網路裡，由於有經驗證的紀錄可得，它進行得更快、更自動。 |
| **經濟中性原則（Economic Neutrality Principle）** | Princip ekonomické neutrality | 網路中的誠實行為，在經濟上接近於零——發布成本會以驗證報酬的形式回流。不誠實的行為則是淨損失。 |
| **湧現的（Emergent）** | Emergentní | 從較簡單部分的互動中自發生成，無人設計或指揮。一群鳥沒有計畫也能排成隊形飛行——陣形從每一隻個體所遵循的簡單規則中湧現。 |
| **湧現的社會契約（Emergent Social Contract）** | Emergentní společenská smlouva | 各種行為規則，不是從上面（法律）產生，而是從下面產生——從社群內部反覆的互動與共識中產生。 |
| **ESR** | Electronic Spending Register | 一套所提議的、用於透明追蹤公共支出的系統——國家每一筆已實現的支出，都與一筆計畫付款相配對。靈感來自捷克的 EET，但反過來對付國家。 |
| **雜湊（Hash）** | Hash (otisk) | 一般而言：一種單向數學函式，能從任何輸入產生一個獨一無二、固定長度的「指紋」——就像文件的指紋。相同的輸入永遠產生相同的輸出，但無法從輸出反推出輸入。此處：用來決定雜湊環上的位置，並驗證文件的完整性。 |
| **即時撥款（Just-in-Time Funding）** | Just-in-time financování | 以透明為條件的國家撥款——只有在國家接受 ESR 並把其支出加以配對時，錢才流動。一根用來逼出合作的槓桿。 |
| **功績制（Meritocracy）** | Meritokracie | 一般而言：一種以實際功績與經證明之能力、而非形式頭銜、人脈或世襲特權來決定地位的體制。此處：聲譽網路自然偏好那些對社群有可證明貢獻的人——他們的聲音之所以更有份量，是因為過往紀錄，而非因為職位。 |
| **洋蔥閘道（Onion Gateway）** | Onion gateway | 一個 DID 身分在洋蔥網路上的網路位址。與 DID 文件分開——它可以在不喪失身分的情況下更改（類似於更改一個網域背後的 IP 位址）。 |
| **洋蔥路由（Onion Routing，Tor）** | Onion routing (Tor) | 一種確保網路不可審查性的通訊協定。訊息被分層加密——每個節點剝除一層，卻不知道完整的路徑。 |
| **預言機問題（Oracle Problem）** | Oracle problém | 一般而言：如何確保進入數位系統的資料，忠實對應到實體世界裡實際發生的事。此詞源自區塊鏈領域。此處：透過權威機構來處理，他們押上自己的聲譽作為擔保，保證數位紀錄對應於實體現實。 |
| **現象學的（Phenomenological）** | Fenomenologický | 一般而言：一種把現象當作它們在直接經驗中顯現的樣子來研究、透過觀察由它們所引出的結果、而不預設既定理論的取徑。此處：自由、社會契約與行為規範都是被觀察到的現象——是人與人之間數以千計的微互動所導致的結果，而非自上而下界定的原則。 |
| **政策（Policy）** | Policy (politika) | 一般而言：一套在特定脈絡下規範行為的規則或原則。此處：DID 網路中每個參與者都宣告自己的政策——他如何回應他人的特定行為、遵循哪些規則、認為哪些懲罰是合乎比例的。政策的總合形成湧現的社會契約。 |
| **代理（Proxy）** | Proxy | 一般而言：一個替身或中介——代表另一方行事的系統或實體。此處用於兩個脈絡：（1）ESR 作為一個把公共支出與計畫付款相配對的代理；（2）觀察者妙招中，觀察者作為發布者與驗證者之間的代理。 |
| **發布者（Publisher）** | Vydavatel | 一個建立並發布一筆紀錄（關於不公、補救等等的一筆主張）的網路參與者。承擔發布的成本。 |
| **以聲譽為基礎的社群網路（RSN）** | Reputační síť | 一個去中心化的社群網路，參與者在其中交換關於現實世界行為的回饋。紀錄建立起來昂貴、讀取起來便宜。 |
| **聲譽訊號（Reputation Signal）** | Reputační signál | 網路中的一筆個別紀錄——正面的（傷害的補救、義務的履行）或負面的（不公、違約）。這些訊號累積起來形成一份聲譽檔案。 |
| **社會圖譜（Social Graph）** | Sociální graf | 你的聯絡人、以及你聯絡人的聯絡人所構成的網路。演算法在一個可設定的深度（例如 3 層）尋找驗證者。沒有全球性的區塊鏈——網路自然形成一個個有所重疊的社群。 |
| **稅款分配（Tax Allocation）** | Alokace daní | 一種讓納稅人決定其部分稅款流向何處的機制。可分配的百分比逐年成長。 |
| **過往紀錄（Track Record）** | Track record | 一般而言：一個人或組織過去成果、成功與失敗的歷史。此處：某個 DID 身分在網路中一切過往互動的總和——經驗證的主張、被接受與被拒絕的紀錄——其聲譽即由此推導而來。 |
| **驗證者（Verifier）** | Ověřovatel | 一個以演算法被選出、去驗證並發布一筆紀錄的參與者。以自己的好名聲為資訊的真實性背書。 |
