# 沒有身分證的公民身分

隨著向 DID 基礎設施過渡，國家核發的身分證失去了它壟斷性的用途。你不需要身分證——你有一系列 DID 身分，其中一些帶有一筆主張，例如你是捷克人、你是某個特定市鎮的居民、你是某所特定學校的畢業生。這筆主張可驗證、永久，且獨立於國家行政。

一個技術實作的問題於是打開：市場上誰會接下「在國家控制之外驗證既有公民」的工作，好把有意願者遷移到一個帶有適當主張的 DID 裡？最可能的是，各種專門從事身分驗證的自由市場權威機構會冒出來——公證人、在地社群、雇主。他們以自己的聲譽擔保某個特定 DID 確實屬於聲稱擁有它的那個人。公民身分——也就是歸屬於某種對社群的特定看法——從中央紀錄保管的需要中解放出來。透過聲譽網路的連結，內嵌的資料被連結並第二次、第三次、第四次地驗證，依此類推。

其後果很直覺，卻在中央化系統裡無解。今天，政治領導層——著眼於較容易的連任——可以把集中的問題進口到社群的領地裡：不顧吸納容量與既有社群的意願，接納來自其他文明圈的移民，在一種壓力下改變原有的社群，使其跟不上同化來自其他文明圈之新到者的速度。在一個 DID 網路裡，一個以腐敗方式被放進來的移民，無法確定社群會繼續把他視為自己人。社群的成員在客觀上不必忍受一個陌生人穿著社群的制服來到他們門前，還以他打算在屋裡執行之措施的合法性威脅他們（因為一則社群媒體貼文而沒收孩子的手機）。有了去中心化的聲譽，社會的多數不必聽任於此——因為歸屬於一個社群，不是由某個官員決定的，而是由社群自己、透過它的聲譽訊號決定的。

在國家職掌範圍內之事務上，一張選票的份量，未來可以與「對簡單稅制之貢獻」的紀錄嚴格相關。搭配合適的 DID 主張（例如「此人是捷克公民」），外國國民便能被排除於選舉之外——人口登記就這麼直接搬到這裡來。
