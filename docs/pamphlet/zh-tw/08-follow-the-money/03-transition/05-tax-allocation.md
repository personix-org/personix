# 公民稅款分配——決定的份量

第三件工具讓納稅人對「自己的錢流向何處」擁有直接的影響力。在第一輪，無論 ESR 揭露了什麼，國家都收到了它的錢。在第二輪它不再如此——第一輪的分析，以及由此而生的措施接手了。已繳稅款的一小部分百分比，可以由繳款人自己來分配——前提是他的 DID 符合聲譽上的要求（公民身分、居留、社群承認的成年／行為能力）。可分配的百分比逐年成長。可能是指數式地成長。從今天的百分之五，到十年內的數十個百分比。

原始的 ESR 資料自然地引導納稅人的決定。低品質的紀錄，作為建議刪減的一個警示訊號發揮作用。任何人都能建立紀錄；官員必須去配對它們。少了這個，稅制就不會送給國家任何錢——既不進國庫，也不進其他預算科目。政治的角力，從投票箱移到日復一日對具體錢幣的分配上。
