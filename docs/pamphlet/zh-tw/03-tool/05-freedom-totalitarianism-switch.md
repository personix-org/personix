# 自由—極權開關（以及委託）

DID 網路內部一個簡單的機制，就能把整個系統推向更大的自由或更大的控制：一個 DID 在每段時間內可發布的紀錄數量。當紀錄維持稀少時，每一筆都有份量——那是自由。當紀錄氾濫、連瑣事都涵蓋時，那就是極權主義。你發布的每一筆紀錄，都在選擇方向。網路本身既不自由也不極權——它是中性的基礎設施。它會變成什麼，取決於人們如何使用它。

在我自己的驗證政策裡，為我社群網路中——各社群內部——的一個一般性 DID，設定一個「發布者每段時間可發行的最大主張數量」（主張是指任何一般性的可驗證陳述；此處指發布到聲譽網路的一筆紀錄），好讓我把它們納入考量、並認為其驗證請求具相關性，是合理的。

我心裡有一個直覺的數字——每年低個位數。這種帶審查意味的做法，看起來或許相當孤立主義。但我可以正當地讓申請者面臨一個抉擇：從他已發行的紀錄中挑一筆，請求驗證者撤銷它、也就是使它失效——在申請者恰巧真的成為多起獨立冤屈之受害者的情況下，這是個相當激進的要求，而我肯定會因此加深他被社群疏離的感受。

![自由—極權開關](../../Info%20Graphics/v5/v5-06-prepinac-svoboda-totalita.webp)

因此，一個更有效的選項似乎是：能把自己「向聲譽網路發布資訊」的部分權利委託給一個社群或一個權威機構，後者再依其內部規則、以團結互助的方式決定如何分配這些權利。一個群體必須能照顧它認為處於弱勢的成員。社群成員有權在任何時候——只要被委託的權利尚未被使用——撤銷其委託。

![發布權的委託](../../Info%20Graphics/v5/v5-06c-delegace.webp)

> [!note] 自由對比極權
> 一個看管並限制已發布紀錄數量的社會，會更自由；一個紀錄過剩的社會，會傾向極權主義。人們可以設想把發布紀錄的權利委託給別人。

> [!note] 文化調適
> 人們一般都愛看別人碗裡的東西。在各個文明之間，我們在歷史經驗與人口密度上有所不同——因此在「我們想在文明與社群內部看多少別人碗裡的東西」上也有所不同。亞洲國家傾向於對社會中的自由採取較嚴格的觀點；歐美國家在某些面向上則傾向於較自由的觀點。無論這個類比多麼不精確，在去中心化聲譽社群網路的脈絡下可以說，各個社群的設定並不歧視，每個社群都能按自己認為合適的方式，配置其內部的溝通。
>
> 儘管有這些差異，仍會有一些跨全球通行的標準（隨機殺人對誰都不好）。其他設定會是社群特有的，還有一些甚至是個人特有的。好處在於，透過彼此溝通、並觀察周遭的設定，可以尋求共識——從雙邊安排，到社群層次的安排，再到隨時間、憑藉配置最佳之社群的經濟主導地位，甚至上升到全球層級。
>
> 不過關於共識，下一章再詳談。
