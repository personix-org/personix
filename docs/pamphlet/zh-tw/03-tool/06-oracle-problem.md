# 預言機問題——搭起數位與實體世界之間的橋

「預言機問題」一詞近來最常與加密貨幣、區塊鏈和去中心化系統的世界連在一起。一般而言：你要如何確保進入數位系統的資料，忠實對應到實體世界裡實際發生的事？系統本身無法驗證某人是否真的傷害了另一人，或某份契約是否真的被違反——它只看得見數位紀錄。

在這裡，我們透過權威機構來解決這個問題——這些實體以自己的聲譽擔保「數位紀錄對應於實體現實」。權威機構的聲譽越高，紀錄就越可信。
