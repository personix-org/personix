# 自願性、責任與自由

自願性是個人的：我為自己做決定。當我的決定影響到他人時，責任便隨之而生——回饋機制啟動。自由既不是禮物，也不是權利——它是自願性與朝向責任之壓力之間、數以千計的雙邊互動、在整個社會層面取平均後的一個現象學[^phenomenological]結果。網路並不指定這個平均值——它從驗證者的價格訊號、以及社群成員為自己設定的預先公告之驗證政策中湧現[^emergent]出來。

一個社群裡的個人對自由抱有何種偏好，取決於他對「自己願意吞下多少自己加諸他人之物」的感受。對於那些不言自明、對眾人皆有益的事，並無道德兩難——殺人是錯的。接著有一些情況，選項會移入「被允許之特權」的位置：證明你的技能，我們才讓你上路，這樣你撞死我們的機會才小一點。最後還有一些事，個人會說——這對我不值得，既然我自己也燒葉子，我就不會禁止鄰居燒葉子；或者因為我做了別的、限制到他們舒適的事，他們反過來也可能想禁止我。如果歷史上我們把自由的邊界劃在別人自由開始的地方，那麼一個建立在去中心化身分之上的聲譽社群網路，會比中央化的代議民主更好地實現這一點——在後者中，例如，享有特權的民意代表階層試圖讓自己豁免於對個人通訊的監控，卻毫不猶豫地把它強加於自己的選民身上，還動用各種檯面下的藉口與操弄。

[^phenomenological]: **現象學的（phenomenological，源自希臘語 *phainómenon*——顯現之物）**——一般而言：一種把現象當作它們在直接經驗中呈現的樣子來檢視的取徑，透過觀察由它們所引出的結果，而不預設底層微觀世界中既定的解釋理論。此處：自由不是一條自上而下界定的抽象原則，而是一個被觀察到的現象——是人與人之間數以千計的微互動所導致的結果，從我們實際如何對待彼此中湧現而來。

[^emergent]: **湧現的（emergent，源自拉丁語 *emergere*——浮現）**意指「從較簡單部分的互動中自發生成，無人設計或指揮」。一群鳥即使沒有哪隻鳥擁有陣形的計畫，也能排成隊形飛行——陣形從每一隻個體的簡單規則中湧現。同樣地，在聲譽網路裡，沒有人設計整體的行為規則——它們從數以千計的個別決策中湧現而來。
