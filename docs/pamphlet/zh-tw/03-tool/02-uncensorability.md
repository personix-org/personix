# 為何這個網路不可審查

到目前為止，我們描述了這個網路能做什麼。現在讓我們聚焦於它為何無法被關閉或審查。

這個網路很可能會建立在 Tor 網路與洋蔥路由（一種以 Mixnet 原理遮蔽網路流量的方式）的原則之上——這是一種通訊會穿越數層加密、且沒有任何單一節點會同時知道發送者與接收者的技術。中央機構無法越過你的肩膀窺看，因為根本沒有可以窺看的地方。

你可以與它對抗，但你贏不了——除非你把整個國家推進到對每個網路封包、對每一件連上網際網路並在該聲譽網路上通訊的硬體之底層操作進行極權式監控的地步。而這正是中央集權所面臨的抉擇：要嘛接受公民握有一件你力所不及的工具，要嘛以極權控制之名，把自己挖進經濟停滯的黑暗角落。

我們別抱幻想——即使是民主政體，在爭奪中央集權的鬥爭中也會嘗試這麼做。他們寧可給人們戴上枷鎖，也不願交出權力。
