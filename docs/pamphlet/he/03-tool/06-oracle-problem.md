# בעיית האורקל — גישור בין העולם הדיגיטלי לפיזי

המונח "בעיית האורקל" נקשר בעת האחרונה לרוב לעולם מטבעות הקריפטו, הבלוקצ'יין והמערכות המבוזרות. באופן כללי: כיצד מבטיחים שנתונים הנכנסים למערכת דיגיטלית תואמים בנאמנות למה שקרה בפועל בעולם הפיזי? המערכת עצמה אינה יכולה לאמת אם מישהו אכן פגע במישהו אחר, או אם חוזה אכן הופר — היא רואה רק רשומות דיגיטליות.

כאן אנו פותרים זאת באמצעות רשויות — ישויות המעמידות את מוניטינן על כך שהרשומה הדיגיטלית תואמת למציאות הפיזית. ככל שמוניטין הרשות גבוה יותר, כך הרשומה אמינה יותר.
