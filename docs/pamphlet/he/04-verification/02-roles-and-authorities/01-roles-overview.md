# סקירת התפקידים

כבר נגענו בקצרה בכמה מהתפקידים הללו בפרק על הרשת ותכונותיה הבסיסיות. כעת הגיע הזמן להביט בהם שוב ביתר פירוט ולהוסיף את הנוספים הדרושים לנו כדי להפוך את הרשת לחסונה יותר. כל עסקת אימות מערבת כמה תפקידים — הבה נראה כיצד הם מתנהגים.

> [!note] תפקידים בעסקת אימות
> כל אימות מערב עד שישה תפקידים נבדלים, המסוכמים בטבלה שלהלן. לכולם יכול להיות DID משלהם ברשת המוניטין המבוזרת.

| תפקיד | תיאור |
| --------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **מנפיק** | האדם המפרסם מידע לרשת — טוען שמשהו קרה (DID נוצר, נערך או פורק, טענה, המדיניות של DID נתון וכדומה) |
| **נושא** | האדם שהמידע נוגע לו — נמען הטענה |
| **רשות** | ישות מהימנה המעמידה את שמה על איכות הטענה על ידי חקירתה ובחינת הראיות שהוצגו או איסופן באופן פעיל |
| **משקיף** | צד שלישי בלתי תלוי השומר תיעוד של האופן שבו המְאַמֵּת מטפל בטענה — ומוודא שהמְאַמֵּת אינו שותק ואינו סוטה מהמדיניות שהצהיר עליה |
| **מְאַמֵּת** | משתתף שנבחר אלגוריתמית ומעבד את העסקה |
| **מיופה כוח** | אדם הפועל בשם משתתף אחר |
