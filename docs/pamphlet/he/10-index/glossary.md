# מילון מונחים

| מונח | עברית | משמעות |
|------|-------|---------|
| **Authority** | רשות | ישות מהימנה (אדם, ארגון) המאמתת מידע ומעמידה את מוניטינה עליו. יכולה להיות מתמחה (חוקרת, משפטית, טכנית). |
| **Claim** | טענה | באופן כללי: כל אמירה בת-אימות. כאן: רשומה המפורסמת לרשת המוניטין — טענה על אירוע, תכונה או יחס, החתומה קריפטוגרפית ומאומתת. למשל "אני תושב עירייה X" או "אדם זה הפר חוזה". |
| **Compartmentalization** | הפרדה לתאים | באופן כללי: הפרדת מידע ליחידות מבודדות כך שחשיפת יחידה אחת אינה מסכנת את האחרות. עיקרון המוכר משירותי מודיעין. כאן: זהויות DID מקבילות בדיקטטורות — חשיפת אחת אינה חושפת את האחרות. |
| **Consistent Hash Ring** | טבעת hash עקבית | מנגנון אלגוריתמי לבחירת מְאַמְּתִים — מיקום על הטבעת נקבע לפי ה-hash של מסמך ה-DID בתוך הגרף החברתי. מבטיח בחירה לא-דטרמיניסטית ובכל זאת בת-אימות. |
| **DID** | DID (זהות מבוזרת) | זהות דיגיטלית שאתה יוצר ושולט בה בעצמך, ללא סמכות מרכזית. חתומה קריפטוגרפית במפתח הפרטי שלך — איש אינו יכול לבטלה או לזייפה. |
| **DID Document** | מסמך DID | קובץ נתונים זמין לציבור המתאר את זהות ה-DID שלך — מכיל מפתחות ציבוריים, כתובות רשת ומטא-נתונים. משמש לאמת את זהותך ברשת. |
| **Due Diligence** | בדיקת נאותות | באופן כללי: בדיקה מעמיקה של צד שכנגד לפני כניסה ליחסים עסקיים או משפטיים — בחינת ההיסטוריה, הכספים, המוניטין והסיכונים שלו. כאן: ברשת המוניטין היא מתרחשת מהר ואוטומטית יותר הודות לזמינות רשומות מאומתות. |
| **Economic Neutrality Principle** | עקרון הניטרליות הכלכלית | התנהגות ישרה ברשת קרובה כלכלית לאפס — עלויות הפרסום חוזרות כתגמולי אימות. התנהגות לא ישרה היא הפסד נטו. |
| **Emergent** | מתהווה | מתעורר באופן ספונטני מאינטראקציות של חלקים פשוטים יותר, מבלי שמישהו מתכנן או מכוון אותו. להקת ציפורים עפה במבנה ללא תוכנית — המבנה מתהווה מכללים פשוטים שכל יחיד מקיים. |
| **Emergent Social Contract** | חוזה חברתי מתהווה | כללי התנהגות המתעוררים לא מלמעלה (חוק) אלא מלמטה — מאינטראקציות חוזרות וקונצנזוס בתוך קהילה. |
| **ESR** | מרשם הוצאות אלקטרוני | מערכת מוצעת למעקב שקוף אחר הוצאות ציבוריות — כל הוצאה ממומשת של המדינה מותאמת לתשלום מתוכנן. בהשראת ה-EET הצ'כי, אך מופנית נגד המדינה. |
| **Hash** | hash (טביעה) | באופן כללי: פונקציה מתמטית חד-כיוונית המפיקה "טביעת אצבע" ייחודית באורך קבוע מכל קלט — כמו טביעת אצבע של המסמך. אותו קלט מפיק תמיד אותו פלט, אך אי אפשר לגזור את הקלט מהפלט. כאן: משמש לקבוע מיקום על טבעת ה-hash ולאמת את שלמות המסמך. |
| **Just-in-Time Funding** | מימון בזמן אמת | מימון מדינה המותנה בשקיפות — הכסף זורם רק כאשר המדינה מקבלת את ה-ESR ומתאימה את הוצאותיה. מנוף לכפיית שיתוף פעולה. |
| **Meritocracy** | מריטוקרטיה | באופן כללי: מערכת שבה המעמד נקבע לפי ראוי בפועל ויכולת מוכחת, לא תארים פורמליים, קשרים או פריבילגיה תורשתית. כאן: רשת המוניטין מעדיפה באופן טבעי את מי שתורם בבירור לקהילה — קולו נושא משקל רב יותר בזכות הרקורד, לא בזכות תפקיד. |
| **Onion Gateway** | שער בצל (onion gateway) | כתובת הרשת של זהות DID ברשת הבצל. נפרדת ממסמך ה-DID — אפשר לשנותה מבלי לאבד את הזהות (בדומה לשינוי כתובת ה-IP מאחורי דומיין). |
| **Onion Routing** | ניתוב בצל (Tor) | פרוטוקול תקשורת המבטיח את אי-הניתנות לצנזורה של הרשת. הודעות מוצפנות בשכבות — כל צומת מסיר שכבה אחת אך אינו יודע את המסלול המלא. |
| **Oracle Problem** | בעיית האורקל | באופן כללי: כיצד להבטיח שנתונים הנכנסים למערכת דיגיטלית תואמים בנאמנות למה שקרה בפועל בעולם הפיזי. המונח מקורו בתחום הבלוקצ'יין. כאן: מטופל באמצעות רשויות המעמידות את מוניטינן כערובה לכך שרשומה דיגיטלית תואמת למציאות פיזית. |
| **Phenomenological** | פנומנולוגי | באופן כללי: גישה החוקרת תופעות כפי שהן מתבטאות בחוויה הישירה, על ידי התבוננות במה שנובע מהן, ללא תיאוריות נתונות מראש. כאן: החירות, החוזה החברתי ונורמות ההתנהגות הם תופעות נצפות — תוצאות של אלפי מיקרו-אינטראקציות בין בני אדם, לא עקרונות המוגדרים מלמעלה. |
| **Policy** | מדיניות (policy) | באופן כללי: מערך כללים או עקרונות המסדירים התנהגות בהקשר נתון. כאן: כל משתתף ברשת ה-DID מצהיר על מדיניותו — כיצד הוא מגיב להתנהגות ספציפית של אחרים, אילו כללים הוא מקיים, ואילו עונשים הוא רואה כמידתיים. צירוף המדיניויות מהווה את החוזה החברתי המתהווה. |
| **Proxy** | proxy (מתווך) | באופן כללי: ממלא-מקום או מתווך — מערכת או ישות הפועלת בשם אחר. משמש כאן בשני הקשרים: (1) ה-ESR כ-proxy המתאים הוצאות ציבוריות לתשלומים מתוכננים; (2) משקיפים כ-proxy בין המפרסם למְאַמֵּת בתעלול המשקיף. |
| **Publisher** | מפרסם | משתתף ברשת היוצר ומפרסם רשומה (טענה על עוול, תיקון וכן הלאה). נושא בעלות הפרסום. |
| **Reputation-Based Social Network (RSN)** | רשת מוניטין | רשת חברתית מבוזרת שבה משתתפים מחליפים משוב על התנהגות בעולם האמיתי. הרשומות יקרות ליצירה, זולות לקריאה. |
| **Reputation Signal** | אות מוניטין | רשומה בודדת ברשת — חיובית (תיקון נזק, מילוי התחייבות) או שלילית (עוול, הפרת חוזה). באופן מצטבר, האותות מהווים פרופיל מוניטין. |
| **Social Graph** | גרף חברתי | רשת אנשי הקשר שלך ואנשי הקשר של אנשי הקשר שלך. האלגוריתם מחפש מְאַמְּתִים בעומק ניתן להגדרה (למשל, 3 רמות). ללא בלוקצ'יין גלובלי — הרשת יוצרת באופן טבעי קהילות עם חפיפות. |
| **Tax Allocation** | הקצאת מס | מנגנון שבאמצעותו הנישום מחליט לאן הולך חלק ממסיו. האחוז בר-ההקצאה גדל משנה לשנה. |
| **Track Record** | track record | באופן כללי: היסטוריה של תוצאות, הצלחות וכישלונות של אדם או ארגון בעבר. כאן: סך כל האינטראקציות בעבר של זהות DID נתונה ברשת — טענות מאומתות, רשומות שהתקבלו ונדחו — שמהן נגזר מוניטינה. |
| **Verifier** | מְאַמֵּת | משתתף שנבחר אלגוריתמית לאמת ולפרסם רשומה. מעמיד את שמו הטוב על אמיתות המידע. |
