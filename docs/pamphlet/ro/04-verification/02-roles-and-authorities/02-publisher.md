# Emitentul

L-am întâlnit deja pe emitent. Când cineva este nedreptățit sau vrea să facă publică o realizare proprie, persoana reprezentată de DID este cea care declanșează procesul de introducere a acelei informații în rețea — pentru că ea are interesul primar s-o facă (motivația fiind fie dorința de satisfacție, fie dorința de a-și îmbunătăți imaginea publică).

> [!note] Afirmații pozitive
> Afirmațiile pozitive despre mine le pot păstra, ca subiect și emitent al lor deopotrivă, pentru situațiile în care vreau să le folosesc (o diplomă, un certificat pentru un serviciu prestat etc.). Aici se deosebește o afirmație pozitivă de una negativă: împărtășirea unei afirmații negative verificate este în interesul întregii comunități, pe când una pozitivă este în interesul purtătorului ei.
