# Informationen über dich selbst bereitstellen

Wenn zwei DID-Subjekte, die einander nicht kennen, in eine wirtschaftliche Beziehung treten, können wir im Namen der anderen Partei eine Anfrage an unsere eigene Gemeinschaft signieren und sie bitten, Informationen über uns bereitzustellen. Das ist jedoch eine sehr naive Vorstellung davon, was Gemeinschaften sind. Sie sind keine geschlossenen Mengen — eine einzelne DID kann Teilnehmer mehrerer Gemeinschaften sein.

Eine Gemeinschaft ist eher ein phänomenologisches Phänomen aus der Perspektive eines gegebenen Teilnehmers, das sich in seinem sozialen Netzwerk manifestiert; sie ist nicht etwas, das immer sinnvoll explizit abzugrenzen wäre. Die Bewohner eines Dorfes können eine Gemeinschaft bilden, doch ein Mensch, der nur am Wochenende dorthin kommt, kann in demselben Dorf auch einer anderen Gemeinschaft angehören. Eine Gemeinschaft kann auch eine Fußballmannschaft samt ihren Fans, ihren Funktionären und den Familien aller Beteiligten sein. Eine Nation oder die Bürger eines Staates können ebenfalls eine Gemeinschaft oder Gemeinschaften bilden. Eine DID aus verschiedenen Blickwinkeln zu betrachten, kann verschiedene (und oft intuitive) Sichtweisen auf Gemeinschaften ergeben.

DIDs an den Grenzen sind somit Brücken zwischen Gemeinschaften und spielen — genau wie im echten Leben — eine Rolle bei der Bereitstellung von Informationen über Mitglieder anderer Gemeinschaften, sei es auf Amateurniveau oder professionell, etwa eine Autorität, die sich auf das Zusammenbringen von Menschen und das Aggregieren von Informationen über riskante DIDs spezialisiert.

Manche Arten von Informationen im DID-Netzwerk eignen sich gut für einen bedingungslosen gegenseitigen Austausch (Gewaltverbrechen, Betrug usw.). Andere Arten von Informationen wiederum mag eine Gemeinschaft als auf die Verwendung innerhalb der Gemeinschaft beschränkt behandeln (das Äquivalent der Staatsbürgerschaft, für die Gemeinschaft erbrachte Dienste usw.). Ob sich solche Informationen verbreiten lassen, hängt von den erklärten Richtlinien der Mitglieder der Gemeinschaft ab.

Eine Gemeinschaft hütet ihre Privatsphäre im eigenen Kreis und tauscht im Gegenzug beiderseitig nützliche Informationen auf bedingungsloser Basis aus.
