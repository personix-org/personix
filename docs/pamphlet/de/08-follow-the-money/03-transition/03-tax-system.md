# Einfaches Steuersystem — der Köder zum Einstieg

Das erste Werkzeug ist ein einfaches, transparentes Steuersystem, das auf DID-Infrastruktur aufbaut. Ein einziger proportionaler Satz auf alle Einkünfte. Keine Ausnahmen, keine Steuerbefreiungen, keine Unternehmensabzüge, keine Anreize. Jede Zahlung ist prüfbar mit der DID verknüpft, die sie geleistet hat. Der Abgleich ist trivial.

Der Satz würde für einen Teil der Steuerzahler etwas günstiger angesetzt als im alten System — das ist der Köder für den Einstieg. Die Steuerlast würde Jahr für Jahr sinken, das System würde immer attraktiver, und die Migration würde an Tempo gewinnen. Das System ist zugleich Aufzeichnender und Einziehender — kein Mittelsmann, keine Intransparenz.
