# Glossar

| Begriff | Deutsch | Bedeutung |
|------|-------|---------|
| **Authority** | Autorität | Eine vertrauenswürdige Entität (Person, Organisation), die Informationen verifiziert und ihre Reputation darauf setzt. Kann spezialisiert sein (ermittelnd, juristisch, technisch). |
| **Claim** | Behauptung | Allgemein: jede überprüfbare Aussage. Hier: ein ins Reputationsnetzwerk veröffentlichter Eintrag — eine Behauptung über ein Ereignis, eine Eigenschaft oder eine Beziehung, die kryptografisch signiert und verifiziert ist. Z. B. „Ich bin Einwohner der Gemeinde X" oder „diese Person hat einen Vertrag gebrochen." |
| **Compartmentalization** | Abschottung | Allgemein: das Trennen von Informationen in isolierte Einheiten, sodass die Preisgabe einer Einheit die anderen nicht kompromittiert. Ein aus Geheimdiensten bekanntes Prinzip. Hier: parallele DID-Identitäten in Diktaturen — die Kompromittierung einer gibt die anderen nicht preis. |
| **Consistent Hash Ring** | Konsistenter Hash-Ring | Ein algorithmischer Mechanismus zur Auswahl von Verifizierern — eine Position auf dem Ring wird durch den Hash des DID-Dokuments innerhalb des sozialen Graphen bestimmt. Sichert eine nichtdeterministische und dennoch überprüfbare Auswahl. |
| **DID** | DID (Dezentrale Identität) | Eine digitale Identität, die du selbst erstellst und kontrollierst, ohne zentrale Autorität. Kryptografisch mit deinem privaten Schlüssel signiert — niemand kann sie widerrufen oder fälschen. |
| **DID Document** | DID-Dokument | Eine öffentlich verfügbare Datendatei, die deine DID-Identität beschreibt — enthält öffentliche Schlüssel, Netzwerkadressen und Metadaten. Dient dazu, deine Identität im Netzwerk zu verifizieren. |
| **Due Diligence** | Due Diligence | Allgemein: die eingehende Prüfung einer Gegenseite vor dem Eingehen einer geschäftlichen oder rechtlichen Beziehung — die Prüfung ihrer Historie, Finanzen, Reputation und Risiken. Hier: im Reputationsnetzwerk geschieht sie schneller und automatischer dank der Verfügbarkeit verifizierter Einträge. |
| **Economic Neutrality Principle** | Prinzip der ökonomischen Neutralität | Ehrliches Verhalten im Netzwerk liegt ökonomisch nahe null — die Veröffentlichungskosten kehren als Verifizierungsbelohnungen zurück. Unehrliches Verhalten ist ein Nettoverlust. |
| **Emergent** | Emergent | Spontan aus den Interaktionen einfacherer Teile entstehend, ohne dass es jemand entwirft oder lenkt. Ein Vogelschwarm fliegt ohne Plan in Formation — die Formation entsteht aus einfachen Regeln, denen jeder Einzelne folgt. |
| **Emergent Social Contract** | Emergenter Gesellschaftsvertrag | Verhaltensregeln, die nicht von oben (Gesetz), sondern von unten entstehen — aus wiederholten Interaktionen und Konsens innerhalb einer Gemeinschaft. |
| **ESR** | Elektronisches Ausgabenregister | Ein vorgeschlagenes System zur transparenten Verfolgung öffentlicher Ausgaben — jede realisierte Staatsausgabe wird mit einer geplanten Zahlung abgeglichen. Von der tschechischen EET inspiriert, aber gegen den Staat gewendet. |
| **Hash** | Hash (Fingerabdruck) | Allgemein: eine mathematische Einwegfunktion, die aus einer beliebigen Eingabe einen eindeutigen „Fingerabdruck" fester Länge erzeugt — wie ein Fingerabdruck des Dokuments. Dieselbe Eingabe erzeugt stets dieselbe Ausgabe, doch die Eingabe lässt sich nicht aus der Ausgabe ableiten. Hier: genutzt, um eine Position auf dem Hash-Ring zu bestimmen und die Integrität des Dokuments zu überprüfen. |
| **Just-in-Time Funding** | Just-in-time-Finanzierung | Staatsfinanzierung unter der Bedingung von Transparenz — Geld fließt nur, wenn der Staat das ESR akzeptiert und seine Ausgaben abgleicht. Ein Hebel, um Kooperation zu erzwingen. |
| **Meritocracy** | Meritokratie | Allgemein: ein System, in dem der Status durch tatsächlichen Verdienst und erwiesene Fähigkeit bestimmt wird, nicht durch formale Titel, Beziehungen oder ererbte Privilegien. Hier: das Reputationsnetzwerk begünstigt auf natürliche Weise jene, die nachweislich zur Gemeinschaft beitragen — ihre Stimme wiegt mehr aufgrund der Erfolgsbilanz, nicht aufgrund eines Amtes. |
| **Onion Gateway** | Onion Gateway | Die Netzwerkadresse einer DID-Identität im Onion-Netzwerk. Getrennt vom DID-Dokument — sie lässt sich ändern, ohne die Identität zu verlieren (ähnlich dem Ändern der IP-Adresse hinter einer Domain). |
| **Onion Routing** | Onion Routing (Tor) | Ein Kommunikationsprotokoll, das die Unzensierbarkeit des Netzwerks sichert. Nachrichten werden in Schichten verschlüsselt — jeder Knoten schält eine Schicht ab, kennt aber nicht den vollständigen Pfad. |
| **Oracle Problem** | Orakel-Problem | Allgemein: wie man sicherstellt, dass Daten, die in ein digitales System eintreten, dem entsprechen, was tatsächlich in der physischen Welt geschehen ist. Der Begriff stammt aus dem Blockchain-Bereich. Hier: gelöst über Autoritäten, die ihre Reputation als Garantie dafür einsetzen, dass ein digitaler Eintrag der physischen Realität entspricht. |
| **Phenomenological** | Phänomenologisch | Allgemein: ein Ansatz, der Phänomene so untersucht, wie sie sich in der unmittelbaren Erfahrung manifestieren, indem beobachtet wird, was aus ihnen folgt, ohne vorgegebene Theorien. Hier: Freiheit, der Gesellschaftsvertrag und Verhaltensnormen sind beobachtete Phänomene — Folgen Tausender Mikrointeraktionen zwischen Menschen, keine von oben definierten Prinzipien. |
| **Policy** | Policy (Richtlinie) | Allgemein: ein Satz von Regeln oder Prinzipien, die das Verhalten in einem gegebenen Kontext bestimmen. Hier: Jeder Teilnehmer im DID-Netzwerk erklärt seine Policy — wie er auf konkretes Verhalten anderer reagiert, welche Regeln er befolgt und welche Strafen er für verhältnismäßig hält. Die Gesamtheit der Richtlinien bildet den emergenten Gesellschaftsvertrag. |
| **Proxy** | Proxy | Allgemein: ein Stellvertreter oder Mittler — ein System oder eine Entität, die im Namen einer anderen handelt. Hier in zwei Kontexten verwendet: (1) ESR als Proxy, der öffentliche Ausgaben mit geplanten Zahlungen abgleicht; (2) Beobachter als Proxy zwischen Aussteller und Verifizierer im Beobachter-Trick. |
| **Publisher** | Aussteller | Ein Netzwerkteilnehmer, der einen Eintrag erstellt und veröffentlicht (eine Behauptung über ein Unrecht, eine Wiedergutmachung usw.). Trägt die Kosten der Veröffentlichung. |
| **Reputation-Based Social Network (RSN)** | Reputationsnetzwerk | Ein dezentrales soziales Netzwerk, in dem Teilnehmer Feedback über Verhalten in der realen Welt austauschen. Einträge sind teuer zu erstellen, günstig zu lesen. |
| **Reputation Signal** | Reputationssignal | Ein einzelner Eintrag im Netzwerk — positiv (Wiedergutmachung eines Schadens, Erfüllung einer Verpflichtung) oder negativ (Unrecht, Vertragsbruch). Kumulativ bilden Signale ein Reputationsprofil. |
| **Social Graph** | Sozialer Graph | Das Netzwerk deiner Kontakte und der Kontakte deiner Kontakte. Der Algorithmus sucht Verifizierer in einer konfigurierbaren Tiefe (zum Beispiel 3 Ebenen). Keine globale Blockchain — das Netzwerk bildet auf natürliche Weise Gemeinschaften mit Überlappungen. |
| **Tax Allocation** | Steuerzuweisung | Ein Mechanismus, durch den der Steuerzahler entscheidet, wohin ein Teil seiner Steuern geht. Der zuweisbare Prozentsatz wächst Jahr für Jahr. |
| **Track Record** | Track Record (Erfolgsbilanz) | Allgemein: die Historie vergangener Ergebnisse, Erfolge und Misserfolge einer Person oder Organisation. Hier: die Summe aller vergangenen Interaktionen einer gegebenen DID-Identität im Netzwerk — verifizierte Behauptungen, angenommene und abgelehnte Einträge —, aus der sich ihre Reputation ableitet. |
| **Verifier** | Verifizierer | Ein algorithmisch zur Verifizierung und Veröffentlichung eines Eintrags ausgewählter Teilnehmer. Setzt seinen guten Namen auf die Wahrhaftigkeit der Information. |
