# 用语集

| 术语 | 捷克语 | 含义 |
|------|-------|---------|
| **权威（Authority）** | Autorita | 一个可信实体(人、组织),它验证信息并把自己的声誉押在上面。可以是专门化的(调查、法律、技术)。 |
| **主张（Claim）** | Tvrzení | 一般而言:任何可验证的陈述。这里:发布到声誉网络的一条记录——一个关于事件、性质或关系的断言,经过密码学签名并被验证。例如"我是市镇 X 的居民"或"此人违反了一份合同"。 |
| **区隔化（Compartmentalization）** | Compartmentalizace | 一般而言:把信息分隔成彼此孤立的单元,使得暴露一个单元不会危及其他单元。这是情报机构所熟知的一条原则。这里:独裁统治下的并行 DID 身份——暴露一个不会牵出其他。 |
| **一致性哈希环（Consistent Hash Ring）** | Hash ring | 一种用于选择验证者的算法机制——环上的位置由社交图谱内 DID 文档的哈希决定。确保一种非确定性却可验证的选择。 |
| **DID** | DID (Decentralizovaná identita) | 一种由你自己创建并掌控、无需中心权威的数字身份。由你的私钥进行密码学签名——没有人能撤销它或伪造它。 |
| **DID 文档（DID Document）** | DID dokument | 一份公开可得的数据文件,描述你的 DID 身份——包含公钥、网络地址和元数据。用于在网络中验证你的身份。 |
| **尽职调查（Due Diligence）** | Due diligence | 一般而言:在进入商业或法律关系之前对对方的深入核验——检查其历史、财务、声誉和风险。这里:在声誉网络中,由于经过验证的记录随手可得,它进行得更快、更自动。 |
| **经济中性原则（Economic Neutrality Principle）** | Princip ekonomické neutrality | 网络中诚实的行为在经济上接近于零——发布成本以验证报酬的形式返还。不诚实的行为是净损失。 |
| **涌现的（Emergent）** | Emergentní | 从更简单部分的互动中自发地产生,而无人设计或指挥。一群鸟无需计划就成队形飞行——队形从每一只鸟所遵循的简单规则中涌现。 |
| **涌现的社会契约（Emergent Social Contract）** | Emergentní společenská smlouva | 一些行为规则,它们不是自上而下(法律)产生,而是自下而上——从一个共同体内部反复的互动与共识中——产生。 |
| **ESR** | Electronic Spending Register | 一套提议中的、用于透明追踪公共支出的系统——国家每一笔已实现的支出都与一条计划付款相匹配。受捷克 EET 启发,但反过来对准国家。 |
| **哈希（Hash）** | Hash (otisk) | 一般而言:一种单向数学函数,从任意输入产生一个唯一的、固定长度的"指纹"——就像文档的指纹。相同的输入总是产生相同的输出,但无法从输出推导出输入。这里:用于确定哈希环上的位置,以及验证文档的完整性。 |
| **即时资金供给（Just-in-Time Funding）** | Just-in-time financování | 以透明为条件的国家拨款——只有当国家接受 ESR 并对应其支出时,钱才流动。一根用来迫使合作的杠杆。 |
| **贤能政治（Meritocracy）** | Meritokracie | 一般而言:一种由实际功绩和已证明的能力、而非形式头衔、人脉或世袭特权来决定地位的体制。这里:声誉网络自然偏向那些明白地为共同体作贡献的人——他们的声音因履历、而非因职位而更有分量。 |
| **洋葱网关（Onion Gateway）** | Onion gateway | 一个 DID 身份在洋葱网络上的网络地址。与 DID 文档分开——它可以在不丢失身份的情况下更改(类似于更改域名背后的 IP 地址)。 |
| **洋葱路由（Onion Routing / Tor）** | Onion routing (Tor) | 一种确保网络不可审查性的通信协议。消息被逐层加密——每个节点剥去一层,却不知道完整的路径。 |
| **预言机问题（Oracle Problem）** | Oracle problém | 一般而言:如何确保进入数字系统的数据忠实地对应于物理世界里实际发生的事情。这一术语源自区块链领域。这里:通过把自己声誉押上、以担保"数字记录对应于物理现实"的权威来加以应对。 |
| **现象学的（Phenomenological）** | Fenomenologický | 一般而言:一种取向,它研究现象在直接经验中显现出来的样子,通过观察从中得出什么,而不预设既定理论。这里:自由、社会契约和行为规范都是被观察到的现象——是人与人之间成千上万次微观互动的结果,而非自上而下界定的原理。 |
| **政策（Policy）** | Policy (politika) | 一般而言:一套在给定语境中规范行为的规则或原理。这里:DID 网络中的每个参与者都宣告自己的政策——他们如何回应他人的具体行为、遵循哪些规则、认为哪些惩罚是成比例的。政策的总和构成涌现的社会契约。 |
| **代理（Proxy）** | Proxy | 一般而言:一个替身或中间人——代表另一方行事的系统或实体。这里在两个语境中使用:(1)作为把公共支出与计划付款相匹配之代理的 ESR;(2)在观察者把戏中作为发布者与验证者之间代理的观察者。 |
| **发布者（Publisher）** | Vydavatel | 创建并发布一条记录(关于一桩不公、一次补救等等的主张)的网络参与者。承担发布的成本。 |
| **基于声誉的社交网络（RSN）** | Reputační síť | 一种去中心化社交网络,参与者在其中交换关于现实世界行为的反馈。记录创建起来代价高,读取起来便宜。 |
| **声誉信号（Reputation Signal）** | Reputační signál | 网络中的一条个别记录——正面的(伤害的补救、义务的履行)或负面的(不公、违约)。累积起来,信号构成一份声誉档案。 |
| **社交图谱（Social Graph）** | Sociální graf | 你的联系人以及你联系人之联系人的网络。算法在一个可配置的深度(例如 3 层)搜索验证者。没有全球区块链——网络自然形成一个个有所重叠的共同体。 |
| **税收分配（Tax Allocation）** | Alokace daní | 一种机制,纳税人借此决定自己税款的一部分流向何处。可分配的百分比逐年增长。 |
| **履历（Track Record）** | Track record | 一般而言:一个人或组织过去的结果、成功与失败的历史。这里:某个 DID 身份在网络中过去所有互动的总和——已验证的主张、被接受和被拒绝的记录——其声誉即由此推导而来。 |
| **验证者（Verifier）** | Ověřovatel | 一个由算法选出、用来验证并发布一条记录的参与者。把自己的好名声押在信息的真实性上。 |
