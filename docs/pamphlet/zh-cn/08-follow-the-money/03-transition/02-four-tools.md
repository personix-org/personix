# 相互支撑的四件工具

到目前为止,DID 声誉网络看起来或许主要在正义与共识方面有用。我相信它能够稳定自身、经受住攻击——以贤能政治的方式,依据实际的功绩而非形式上的头衔。但仅凭声誉,不会迫使国家让步。经济会,以及通过它施加的压力会。

没有什么能阻止我们把 DID 身份用作更多工具的管理者,去狠狠地压住金钱。不要从公民一方的完全自愿开始——设定一个国家无法阻止的方向。这场过渡立足于四件相互撑腰的具体工具。它们没有一件单靠自己就足够。
