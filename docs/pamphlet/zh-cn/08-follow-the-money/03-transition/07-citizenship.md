# 无需身份证的公民身份

随着向 DID 基础设施的过渡,国家签发的身份证失去了它那垄断性的用途。你不需要一张身份证——你拥有一系列 DID 身份,其中一些带有一条主张,证明你比如说是捷克人、某个特定市镇的居民、某所特定学校的毕业生。这条主张是可验证的、永久的,并且独立于国家行政之外。

一个技术实现的问题随之打开:市场上谁来承担在国家控制之外去核验现有公民的工作,以便把有意愿者迁移到一个带有相应主张的 DID 里?最有可能的是,专门做身份核验的自由市场权威会涌现出来——公证人、地方共同体、雇主。他们把自己的声誉押在"某个 DID 确实属于声称拥有它的那个人"之上。公民身份——也就是对某种共同体视角的归属——从对中央记录保管的需要中被解放出来。通过在声誉网络中的连接,所嵌入的数据被第二次、第三次、第四次,以此类推地连接和校验。

其后果既直觉,又在集中式系统里无解。今天,政治领导层——着眼于更容易的连任——可以把集中的问题输入共同体的领土:接纳来自其他文明圈的移民,而不顾吸纳能力和既有共同体的意愿,在一种压力下改变原有的共同体,使其跟不上同化来自其他文明圈之新来者的速度。在一个 DID 网络里,一个通过腐败被接纳的移民,无法确定共同体会继续把他们视为自己人。共同体的成员客观上不必忍受一个陌生人穿着共同体的制服找上门来,拿他打算在屋里实施之措施的合法性来威胁他们(因为一条社交媒体帖子而没收孩子的手机)。有了去中心化的声誉,社会中的多数就不必对此逆来顺受——因为对一个共同体的归属,不是由一名官员来裁定,而是由共同体本身,通过它的声誉信号来裁定。

在国家职权范围内的事务上,一张选票的分量,未来可以与"对简单税制之贡献"的记录严格相关联。再结合合适的 DID 主张(例如"此人是捷克公民"),外国国民随后便可以被排除在选举之外——人口登记册干脆就搬到这里来。
