# 无需身份证的国籍

随着向 DID 基础设施的过渡,国家签发的身份证失去了它那垄断性的用途。你不需要一张身份证——你拥有一系列 DID 身份,其中一些带有一条声明,证明你比如说是捷克人、某个特定市镇的居民、某所特定学校的毕业生。这条声明是可验证的、永久的,并且独立于国家行政之外。

随之而来的是一个技术实现上的问题:在国家控制之外,市场上由谁来核验现有公民的身份,好让愿意的人迁移到带有相应声明的 DID 里?最有可能的是,专门做身份核验的自由市场权威机构会应运而生,比如公证人、地方社群、雇主。他们把自己的声誉押在一点上:某个 DID 确实属于声称拥有它的那个人。国籍,也就是对某个社群的归属,不再需要中央记录来保管。嵌入的数据通过声誉网络中的各种连接,被第二次、第三次、第四次地相互关联、反复校验。

其后果直观易懂,而在集中式系统里却无解。今天,政治领导层为了更容易连任,可以把集中产生的问题转嫁到社群的土地上。他们接纳来自其他文明圈的移民,不顾当地的吸纳能力,也不顾原有社群的意愿,结果社群在压力之下被改变,同化新来者的速度也跟不上。在 DID 网络里,一个靠腐败被接纳的移民,无法确定社群会继续把他当作自己人。社群的成员本来就不必容忍这样的事:一个陌生人穿着社群的制服找上门来,以自己打算在屋里实施的措施合法为由威胁他们(比如因为一条社交媒体帖子就没收孩子的手机)。有了去中心化的声誉,社会中的多数人就不必对此逆来顺受,因为一个人是否属于某个社群,不是由官员裁定,而是由社群自己通过声誉信号来裁定。

在国家职权范围内的事务上,一张选票的分量,未来可以与"对简单税制之贡献"的记录严格相关联。再结合合适的 DID 声明(例如"此人是捷克公民"),外国国民随后便可以被排除在选举之外——人口登记册干脆就搬到这里来。
