# 提供关于你自己的信息

当两个彼此不认识的 DID 主体进入一段经济关系时,我们可以代表对方向我们自己的共同体签署一份请求,请它提供关于我们的信息。然而,这是一种对"共同体是什么"非常天真的想法。共同体不是封闭的集合——单个 DID 可以是多个共同体的参与者。

从某个特定参与者的视角看,共同体更像是一种现象学的现象,显现在他们的社交网络之中;它并不是那种总是值得被明确勾勒出来的东西。一个村庄的居民可以构成一个共同体,但一个只在周末来这里的人,也可能在同一个村庄里属于另一个共同体。一个共同体也可以是一支足球队,连同它的球迷、职员以及所有相关人员的家庭。一个民族,或一个国家的公民,同样可以构成一个或多个共同体。从不同角度看一个 DID,可以得出对共同体不同(而且往往很直觉)的看法。

因此,处于边界上的各个 DID 就是共同体之间的桥梁——而且,正如现实生活中一样,它们在"提供关于其他共同体成员的信息"上扮演着角色,无论是在业余层面,还是在专业层面,比如一个专门做"把人连接起来、并汇集关于高风险 DID 之信息"的权威。

DID 网络中的某些类型的信息很适合无条件地相互交换(暴力犯罪、欺诈等)。然而,另一些类型的信息,共同体可能会视为仅限于在共同体内部使用(相当于公民身份、为共同体提供的服务等)。这类信息能否被传播,取决于共同体成员所宣告的政策。

一个共同体在自己的圈子内守护它的隐私,作为回报,则以无条件的方式交换对彼此都有益的信息。
