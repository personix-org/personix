# 验证者

任何 DID 都可以充当验证者,或直接充当,或通过委托给第三个 DID 的验证权来充当。为了让我——或我的代理人——能够进行验证,我应当在网络上可达(在线)。并非每个人都愿意作此承诺,所以一份 DID 记录可以按优先顺序列出若干替补者,在该 DID 离线时由他们代为履行验证职能。

网络中每一个活跃的 DID 都会公开宣告自己的政策。验证时,它依据政策中的规则来判断两件事:对方的声誉,以及签发者打算发布到声誉网络的那条声明,内容和形式是否合格。政策里还包括一条计算验证服务费用的公式。这一切就绪之后,我只需等待。流经网络的声明在统计上数量庞大,网络的算法迟早会在某次迭代中抽中我,让我去验证签发者正在签发的信息。签发者可以事先算出,一个行为正确的验证者会作何反应,但他无法省掉实际联系对方(或对方的替补者)这一步。即便签发者早就知道通不过,与被选中的验证者走完这一轮,仍然要由签发者自己来做。

我们怎么知道,签发者是在正确的一组候选验证者 DID 上运行选择算法的?每个 DID 除了公开宣告自己的政策,还会发布自己在声誉网络中的社交网络当前包含哪些标识符。如果签发者把自己的社交网络圈成一个只会重复自家观点的封闭小圈子,那么经由它发布的信息,几乎不会被其他社群更广泛地接受。我花高昂的代价把一条激进的声明推进网络,并不意味着我在判断对方声誉时,会给这条声明任何分量。有些声明是我的社群推着我去考虑的(对加害者的判罚与限制)。另一些则完全由我自己说了算,我自己决定,是否把某条信息的经济价值计算在内。
