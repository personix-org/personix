# 验证者

任何 DID 都可以充当验证者,或直接充当,或通过委托给第三个 DID 的验证权来充当。为了让我——或我的受托人——能够进行验证,我应当在网络上可达(在线)。并非每个人都愿意作此承诺,这正是为什么一份 DID 记录可以按优先次序列出替补者,由他们在该 DID 离线时代其履行这一职能。

网络中每一个活跃的 DID 都会公开宣告自己的政策。它通过该政策中定义的规则,在验证过程中判断对方的声誉,以及发行者已标记要发布到声誉网络的那条主张的内容与形式。政策的一部分是用来计算验证服务费用的计算公式。这一切就位之后,在流经网络的、统计上大量的主张中,我便等待网络的算法把我抽到发行者那一侧,在某次迭代中指派我去验证正在发行的信息。发行者可以预先计算出一个行为正确的验证者会如何反应,却无法避免实际去联系他们(或他们的替补者);即便发行者事先知道通不过,与被选中验证者的这次迭代也必须由发行者执行。

我们怎么知道发行者是在正确的一组候选验证者 DID 上运行验证者选择算法的?每个 DID 除了公开宣告自己的政策之外,也会发布它在声誉网络中社交网络的当前标识符清单。如果一个发行者把自己的社交网络定义成一个只是回响并强化自身观点的社交气泡,那么通过它发布的信息几乎不会被其他共同体更广泛地接收。我不惜高昂代价把一条激进主张推入网络这一事实,并不意味着在判断对方声誉时,我会给它任何分量。有些主张是我的共同体推着我去纳入考量的(对冒犯者施加的判罚与限制);另一些则完全由我作主——我自己决定纳入或排除某一条信息的经济价值。
