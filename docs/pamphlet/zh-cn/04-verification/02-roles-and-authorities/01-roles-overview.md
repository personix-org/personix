# 角色总览

在关于网络及其基本属性的那一章里,我们已经简要提到过其中一些角色。现在是时候更细致地再看一遍,并加入我们为使网络更稳健所需要的其他角色。每一笔验证交易都涉及若干角色——让我们看看它们如何行事。

> [!note] 验证交易中的角色
> 每一次验证最多涉及六个不同的角色,汇总于下表。它们全都可以在去中心化声誉网络中拥有自己的 DID。

| 角色 | 描述 |
| --------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **发行者(Issuer)** | 把信息发布到网络的人——主张某事发生了(创建、编辑或解散了一个 DID,一条主张,某个 DID 的政策,等等) |
| **主体(Subject)** | 信息所关于的人——主张的对象 |
| **权威(Authority)** | 一个可信实体,通过调查主张、审阅所出示的证据或主动收集证据,把自己的名声押在主张的质量上 |
| **观察者(Observer)** | 一个独立的第三方,记录验证者如何处理主张——确保验证者既不保持沉默,也不偏离其所宣告的政策 |
| **验证者(Verifier)** | 一个由算法选出、处理该交易的参与者 |
| **受托人(Delegate)** | 代表另一个参与者行事的人 |
