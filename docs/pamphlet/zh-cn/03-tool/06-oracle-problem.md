# 预言机问题——架起数字世界与物理世界的桥梁

"预言机问题"(oracle problem)一词近来最常与加密货币、区块链和去中心化系统的世界相联系。一般而言:你如何确保进入数字系统的数据忠实地对应于物理世界里实际发生的事情?系统本身无法核实某人是否真的伤害了另一个人,或某份合同是否真的被违反了——它只看得到数字记录。

这里我们通过权威来解决这个问题——权威是把自己的声誉押在"数字记录对应于物理现实"之上的实体。权威的声誉越高,记录就越可信。
