# 自愿、责任与自由

自愿是个体性的:我为自己作决定。责任在我的决定影响到他人时产生——反馈随之启动。自由既非馈赠,也非权利——它是自愿与朝向责任的压力之间成千上万次双边互动、在全社会范围内取平均后的一个现象学[^phenomenological]结果。网络并不规定这个平均值——它从验证者的价格信号中,以及从共同体成员为自己设定的、预先公告的验证政策中涌现[^emergent]出来。

一个共同体内的个体对自由有多大的偏好,取决于他对"自己愿意吞下多少加诸他人之物"的感受。对于那些不言自明、对所有人都有益的事情,并不存在道德困境——谋杀是错的。接下来是一些选项滑入"被许可的特权"这一位置的情形:证明你的技能,我们才让你上路,这样你把我们撞死的机会就小些。最后还有一些事情,个体会说——这对我不值得,我不会禁止邻居烧树叶,因为我自己也烧,或者因为我做着别的限制他人舒适的事情,而他们反过来也可能想禁止我。如果历史上我们把自由的边界画在"他人自由开始的地方",那么一个建立在去中心化身份之上的声誉社交网络,在这一点上比集中式代议民主做得更好——在代议民主里,比如民选代表这一特权阶层试图让自己免于对个人通信的监控,却毫不犹豫地把这种监控强加给他们的选民,借助形形色色见不得人的借口与操纵。

[^phenomenological]: **现象学的(Phenomenological,源自希腊文 *phainómenon*——显现之物)**——一般而言:一种考察现象的取向,通过观察从现象中得出什么,把现象当作它们在直接经验中呈现的样子来考察,而不预设关于底下微观世界的解释性理论。这里:自由不是一条自上而下界定的抽象原则,而是一个被观察到的现象——是人与人之间成千上万次微观互动的结果,从我们实际如何彼此相待中涌现出来。

[^emergent]: **涌现的(Emergent,源自拉丁文 *emergere*——浮现)**意味着"从更简单部分的互动中自发地产生,而无人设计或指挥"。一群鸟成队形飞行,尽管没有任何一只鸟对队形有计划——队形从每一只鸟简单的规则中涌现出来。同样地,在声誉网络里,没有人设计整体的行为规则——它们从成千上万个个体决策中涌现出来。
