# 为什么网络不可审查

到目前为止,我们描述了网络能做什么。现在让我们聚焦于:为什么它无法被关闭或审查。

网络很可能建立在 Tor 网络与洋葱路由(一种利用混合网络原理来掩盖网络流量的方式)的原则之上——这是一种技术:通信穿过若干层加密,没有任何单一节点能同时知道发送者和接收者。中心机构无法越过你的肩膀窥视,因为根本无处可窥。

你可以去对抗它,但你无法取胜——除非你把整个国家投入极权式监控,监控到个体网络数据包的层次,监控到每一件连入互联网并在该声誉网络上通信的硬件上的底层操作。而这恰恰是集中主义所面临的选择:要么接受公民手握一件你够不着的工具,要么以极权控制之名把自己挖进经济停滞的黑暗角落。

我们别抱幻想——即便是民主政体,在其为集中主义而战时也会尝试这么做。他们宁愿给人们戴上镣铐,也不愿交出权力。
