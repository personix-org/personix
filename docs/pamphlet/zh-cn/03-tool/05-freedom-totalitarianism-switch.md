# 自由—极权开关(以及委托)

DID 网络内部一个简单的机制,就能把整个体系推向更大的自由或更大的控制:一个 DID 在每一段时间内可以发布的记录数量。当记录保持稀缺时,每一条都分量十足——那就是自由。当记录泛滥、连琐事都覆盖时,那就是极权。你用每一条发布的记录来选择方向。网络本身既非自由亦非极权——它是中性的基础设施。它变成什么,由人们如何使用它来决定。

在我自己的验证政策里,给我社交网络中(各社群之内)的一个普通 DID 设一个上限,是合理的。这个上限指的是发布者每段时期内可以签发的声明数量(声明泛指任何可验证的陈述,这里指发布到声誉网络的一条记录)。一旦超过上限,我就不再把他们纳入考量,也不认为他们的验证请求与我相关。

我心里有一个凭直觉定下的数字——每年只有几条。这种带筛选性质的做法,或许显得相当封闭。但我有正当理由让申请人做一个选择:从他们已经签发的记录里挑出一条,请验证者将其撤销,也就是让它失效。如果申请人恰好真的遭遇了好几桩互不相干的冤屈,这个要求就相当苛刻,我这样做,无疑会加深他们与社群之间的疏离感。

![THE FREEDOM-TOTALITARIANISM SWITCH](../../Info%20Graphics/v5/v5-06-prepinac-svoboda-totalita.webp)

因此,更有效的办法似乎是:把自己向声誉网络发布信息的部分权利委托出去,交给一个社群或一个权威机构,由它按内部规则、以互助的方式决定如何分配这些权利。一个群体必须有能力照顾它认为处于弱势的人。只要被委托的权利尚未使用,社群成员随时有权撤销自己的委托。

![DELEGATION OF THE RIGHT TO PUBLISH](../../Info%20Graphics/v5/v5-06c-delegace.webp)

> [!note] 自由与极权
> 一个看守并限制所发布记录数量的社会会更自由;一个记录过剩的社会则倾向于走向极权。人们可以设想把发布记录的权利委托给别人。

> [!note] 文化上的适应
> 人们大体上都爱打探彼此的私事。各文明之间,历史经验和人口密度各不相同,因此在各文明和社群内部,人们愿意在多大程度上互相打探,也各不相同。亚洲国家倾向于对社会中的自由持更严格的看法;欧洲和美洲国家在某些方面则倾向于更自由的看法。无论这一类比多么不精确,在去中心化声誉社交网络的语境下,可以说:各个社群的设置并不歧视任何人,每个社群都可以按自己认为合适的方式来配置其内部的通信。
>
尽管存在差异,仍会有一些被全球范围内公认的标准(随机杀人对谁都没好处)。其他设置将是社群特有的,还有一些甚至是个人特有的。其优势在于:通过相互沟通,并通过观察周遭的设置,可以寻求共识——从双边安排,到社群层面的安排,再随时间推移,凭借配置最佳的社群的经济主导地位,乃至在全球层面达成共识。
>
