# 自由—极权开关(以及委托)

DID 网络内部一个简单的机制,就能把整个体系推向更大的自由或更大的控制:一个 DID 在每一段时间内可以发布的记录数量。当记录保持稀缺时,每一条都分量十足——那就是自由。当记录泛滥、连琐事都覆盖时,那就是极权。你用每一条发布的记录来选择方向。网络本身既非自由亦非极权——它是中性的基础设施。它变成什么,由人们如何使用它来决定。

在我自己的验证政策里,为我社交网络中——在各共同体内——的一个泛用 DID 设定一个上限是合理的:发布者在每段时期内可以发行的主张(泛指任何可验证的陈述;这里指:发布到声誉网络的一条记录)数量,超过这个上限,我就不会把他们纳入考量,也不会认为他们的验证请求相关。

我心里揣着一个直觉性的数字——每年个位数的低值。这样一种审查式的做法,或许显得相当孤立主义。但我可以正当地把申请人置于一个选择面前:从他们已经发行的记录中挑一条,请验证者撤销它,即令其失效——在一种申请人恰巧真的成了多起相互独立之冤情的受害者的处境下,这是一个相当咄咄逼人的要求,而我这样做无疑会加深他们与共同体疏离的感受。

![THE FREEDOM-TOTALITARIANISM SWITCH](../../Info%20Graphics/v5/v5-06-prepinac-svoboda-totalita.webp)

因此,一个更有效的选项似乎是这样一种能力:把自己"向声誉网络发布信息"的部分权利委托给一个共同体或一个权威,由后者随后——以团结互助的方式,按其内部规则——决定如何分配这些权利。一个群体必须能够照顾它认为处于弱势的人。共同体成员有权在任何时候,只要被委托的权利尚未被使用,就撤销自己的委托。

![DELEGATION OF THE RIGHT TO PUBLISH](../../Info%20Graphics/v5/v5-06c-delegace.webp)

> [!note] 自由与极权
> 一个看守并限制所发布记录数量的社会会更自由;一个记录过剩的社会则倾向于走向极权。人们可以设想把发布记录的权利委托给别人。

> [!note] 文化上的适应
> 人们大体上都喜欢看进彼此的盘子里。在各文明之间,我们在历史经验和人口密度上有所不同——因此在"我们想在各文明和共同体内部多大程度上看进彼此的盘子"这件事上也有所不同。亚洲国家倾向于对社会中的自由持更严格的看法;欧洲和美洲国家在某些方面则倾向于更自由的看法。无论这一类比多么不精确,在去中心化声誉社交网络的语境下,可以说:各个共同体的设置并不歧视任何人,每个共同体都可以按自己认为合适的方式来配置其内部的通信。
>
尽管存在差异,仍会有一些被全球范围内公认的标准(随机杀人对谁都没好处)。其他设置将是共同体特有的,还有一些甚至是个人特有的。其优势在于:通过相互沟通,并通过观察周遭的设置,可以寻求共识——从双边安排,到共同体层面的安排,再随时间推移,凭借配置最佳的共同体的经济主导地位,乃至在全球层面达成共识。
>
