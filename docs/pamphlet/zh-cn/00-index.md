# Personix — 不妥协的变革

### 一个不可审查、不可腐蚀的去中心化声誉网络

> [!note] 副标题的含义
> 四个词承载了整个主张。**不可审查**——工具和网络无法被国家、互联网服务商或任何外部权威压制;审查它们的代价高得惊人。**不可腐蚀**——网络内部的人也无法被悄悄收买:每一个行为者的行为都可以公开地与其宣告的政策相对照,因此贿赂就是一个可被证明的不一致,进而等于声誉上的自杀。**去中心化**——没有任何单一节点、公司或司法管辖区能被俘获来使整个体系崩溃。**声誉网络**——在其中流动的价值不是金钱、不是选票、不是许可,而是各共同体因彼此讲真话而相互授予的、缓慢积累、需靠努力赢得、也可能失去的信用。这四个属性合在一起,描绘出取代国家信任垄断的最小可行继任者。
