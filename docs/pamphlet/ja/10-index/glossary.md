# 用語集

| 用語 | チェコ語 | 意味 |
|------|-------|---------|
| **権威（Authority）** | Autorita | 情報を検証し、それに自らの評判を賭ける信頼された主体（人、組織）。専門化されている場合もある（捜査、法律、技術）。 |
| **主張（Claim）** | Tvrzení | 一般には、任意の検証可能な言明。ここでは、評判ネットワークに公開された記録 — 暗号的に署名され検証された、出来事、性質、関係についての言明。例：「私は自治体Xの住民である」あるいは「この人物は契約に違反した」。 |
| **区画化（Compartmentalization）** | Compartmentalizace | 一般には、情報を孤立した単位に分離し、一つの単位を露見させても他の単位を危険にさらさないようにすること。諜報機関から知られる原理。ここでは、独裁体制における並行するDIDアイデンティティ — 一つが露見しても他は明かされない。 |
| **一貫性ハッシュリング（Consistent Hash Ring）** | Hash ring | 検証者を選定するためのアルゴリズム的な仕組み — リング上の位置は、ソーシャルグラフ内のDID文書のハッシュによって決定される。非決定的でありながら検証可能な選定を保証する。 |
| **DID** | DID (Decentralizovaná identita) | 中央権威なしに、あなた自身が作成し管理するデジタルアイデンティティ。あなたの秘密鍵で暗号的に署名される — 誰もそれを取り消したり偽造したりできない。 |
| **DID文書（DID Document）** | DID dokument | あなたのDIDアイデンティティを記述する公に利用可能なデータファイル — 公開鍵、ネットワークアドレス、メタデータを含む。ネットワークであなたのアイデンティティを検証するために用いられる。 |
| **デューデリジェンス（Due Diligence）** | Due diligence | 一般には、商業的あるいは法的な関係に入る前の相手方の綿密な検証 — その履歴、財務、評判、リスクを調べること。ここでは、評判ネットワークにおいては、検証された記録の入手可能性のおかげで、より速く、より自動的に行われる。 |
| **経済的中立性の原理（Economic Neutrality Principle）** | Princip ekonomické neutrality | ネットワークにおける正直な振る舞いは、経済的にはゼロに近い — 公開のコストは検証への報酬として返ってくる。不正な振る舞いは純損失である。 |
| **創発的（Emergent）** | Emergentní | 誰かが設計したり指図したりすることなく、より単純な部分の相互作用から自発的に生じること。鳥の群れは計画なしに編隊を組んで飛ぶ — 編隊は各個体が従う単純な規則から創発する。 |
| **創発する社会契約（Emergent Social Contract）** | Emergentní společenská smlouva | 上から（法）ではなく下から — 共同体内の繰り返される相互作用とコンセンサスから — 生じる振る舞いの規則。 |
| **ESR** | Electronic Spending Register | 公共支出を透明に追跡するための提案されたシステム — 国家のあらゆる実現された支出が計画された支払いと突き合わされる。チェコのEETに触発されているが、国家に対して向けられている。 |
| **ハッシュ（Hash）** | Hash (otisk) | 一般には、任意の入力から一意な固定長の「指紋」を生み出す一方向の数学関数 — 文書の指紋のようなもの。同じ入力は常に同じ出力を生むが、出力から入力を導き出すことはできない。ここでは、ハッシュリング上の位置を決定し、文書の完全性を検証するために用いられる。 |
| **ジャストインタイム資金供給（Just-in-Time Funding）** | Just-in-time financování | 透明性を条件とする国家資金供給 — 国家がESRを受け入れ、その支出を突き合わせたときにのみ金は流れる。協力を強いるための梃子。 |
| **メリトクラシー（Meritocracy）** | Meritokracie | 一般には、地位が、形式的な肩書き、コネ、あるいは相続された特権ではなく、実際の功績と証明された能力によって決まるシステム。ここでは、評判ネットワークは、共同体に明白に貢献する者を自然に優遇する — 彼らの声は、役職によってではなく実績によって、より大きな重みを持つ。 |
| **オニオンゲートウェイ（Onion Gateway）** | Onion gateway | オニオンネットワーク上のDIDアイデンティティのネットワークアドレス。DID文書とは別物 — アイデンティティを失うことなく変更できる（ドメインの背後のIPアドレスを変えるのと同様）。 |
| **オニオンルーティング（Onion Routing）** | Onion routing (Tor) | ネットワークの検閲不能性を保証する通信プロトコル。メッセージは層状に暗号化される — 各ノードは一つの層を剥がすが、経路の全体は知らない。 |
| **オラクル問題（Oracle Problem）** | Oracle problém | 一般には、デジタルシステムに入ってくるデータが、物理世界で実際に起きたことに忠実に対応することをどう保証するか。この用語はブロックチェーンの領域に由来する。ここでは、デジタルの記録が物理的な現実に対応するという保証として自らの評判を賭ける権威を通じて対処される。 |
| **現象学的（Phenomenological）** | Fenomenologický | 一般には、諸現象を、あらかじめ与えられた理論なしに、それらから何が帰結するかを観察することによって、直接の経験に現れるがままに研究する取り組み方。ここでは、自由、社会契約、振る舞いの規範は観察される現象である — 上から定義される原理ではなく、人々のあいだの何千もの微視的な相互作用の帰結。 |
| **方針（Policy）** | Policy (politika) | 一般には、ある文脈における振る舞いを支配する規則や原理の集合。ここでは、DIDネットワークのすべての参加者が自らの方針を宣言する — 他者の特定の振る舞いにどう応じるか、どの規則に従うか、どの罰を釣り合いが取れているとみなすか。方針の総体が創発する社会契約を形づくる。 |
| **プロキシ（Proxy）** | Proxy | 一般には、代役あるいは仲介者 — 別のものに代わって行動するシステムや主体。ここでは二つの文脈で用いられる。（1）公共支出を計画された支払いと突き合わせるプロキシとしてのESR。（2）オブザーバーの仕掛けにおける、公開者と検証者のあいだのプロキシとしてのオブザーバー。 |
| **公開者（Publisher）** | Vydavatel | 記録（不正、是正などについての主張）を作成し公開するネットワーク参加者。公開のコストを負う。 |
| **評判に基づくソーシャルネットワーク（RSN）** | Reputační síť | 参加者が現実世界の振る舞いについてフィードバックを交わす分散型ソーシャルネットワーク。記録は作るのに費用がかかり、読むのは安い。 |
| **評判シグナル（Reputation Signal）** | Reputační signál | ネットワークにおける個々の記録 — 肯定的なもの（危害の是正、義務の履行）あるいは否定的なもの（不正、契約違反）。累積的に、シグナルは評判プロファイルを形づくる。 |
| **ソーシャルグラフ（Social Graph）** | Sociální graf | あなたの連絡先と、あなたの連絡先の連絡先のネットワーク。アルゴリズムは設定可能な深さ（たとえば3段階）で検証者を探す。グローバルなブロックチェーンはない — ネットワークは自然に、重なり合う共同体を形づくる。 |
| **税の配分（Tax Allocation）** | Alokace daní | 納税者が自分の税の一部がどこへ行くかを決める仕組み。配分可能な割合は年を追うごとに増えていく。 |
| **実績（Track Record）** | Track record | 一般には、ある人物や組織の過去の結果、成功、失敗の履歴。ここでは、ネットワークにおけるあるDIDアイデンティティの過去のすべての相互作用 — 検証された主張、受け入れられた記録と拒否された記録 — の総和であり、そこからその評判が導き出される。 |
| **検証者（Verifier）** | Ověřovatel | 記録を検証し公開するためにアルゴリズム的に選ばれた参加者。情報の真実性に自らの名声を賭ける。 |
