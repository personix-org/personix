# 役割の概観

これらの役割のいくつかには、ネットワークとその基本的な性質についての章ですでに簡単に触れた。今こそ、それらをもう一度より詳しく見て、ネットワークをより堅牢にするために必要な追加の役割を加えるときである。すべての検証トランザクションには複数の役割が関わる — それらがどう振る舞うかを見てみよう。

> [!note] 検証トランザクションにおける役割
> それぞれの検証には最大で六つの異なる役割が関わる。それらを下の表にまとめた。それらはすべて、分散型評判ネットワークにおいて自分自身のDIDを持つことができる。

| 役割 | 説明 |
| --------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **発行者（Issuer）** | ネットワークに情報を公開する人 — 何かが起きたと主張する（DIDが作成、編集、解消された、ある主張、あるDIDの方針、など） |
| **主体（Subject）** | 情報が対象とする人 — 主張の名宛人 |
| **権威（Authority）** | 主張を調査し、提示された証拠を精査するか、あるいは能動的に証拠を集めることによって、主張の質に自らの名を賭ける信頼された主体 |
| **オブザーバー（Observer）** | 検証者が主張をどう扱うかの記録を保つ独立した第三者 — 検証者が沈黙したり、宣言した方針から逸脱したりしないことを確かめる |
| **検証者（Verifier）** | トランザクションを処理する、アルゴリズム的に選ばれた参加者 |
| **委任先（Delegate）** | 別の参加者に代わって行動する人 |
