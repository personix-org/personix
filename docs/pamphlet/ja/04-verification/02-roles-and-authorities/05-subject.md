# 主体

評判ネットワークに公開された情報が対象とする者たちは、その担い手であり、言い換えれば主体である。評判ネットワークにおけるインセンティブは、主体が自分自身の規則によって正しく公正に振る舞うあらゆる理由を持ち、共同体によって規則遵守のある種の黄金の中庸へと押しやられるように設定されている。主体は、自分が宣言した規則が要求する以上に道徳的に振る舞うインセンティブすら持つ — あらかじめ宣言された方針は、共同体が何らかの評価や措置を遡及的に適用するコンセンサスに到達することを妨げない。この角度から見れば、法秩序に対する評判ネットワークという代替案は、予想されるとおり、規則の文言よりもその精神によってより強く駆動される。
