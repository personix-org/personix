# 自分についての情報を提供する

互いを知らない二人のDIDの主体が経済的な関係に入るとき、私たちは相手方に代わって自分自身の共同体への要求に署名し、私たちについての情報を提供するよう共同体に求めることができる。しかしこれは、共同体とは何かについての非常に素朴な考え方である。共同体は閉じた集合ではない — 一つのDIDが複数の共同体の参加者でありうる。

共同体は、ある参加者の視点からすれば、その者のソーシャルネットワークにおいて自らを現す現象学的な現象のようなものである。それは常に明示的に境界づけることが理にかなうものではない。村の住民は共同体を形づくりうるが、週末にしかそこに来ない人は、その同じ村の別の共同体にも属しているかもしれない。共同体は、サッカーチームとそのファン、その関係者、そして関わるすべての人の家族が一緒になったものでもありうる。ある国民、あるいはある国家の市民も、共同体あるいは複数の共同体を形づくりうる。一つのDIDを異なる角度から見ると、異なる（そしてしばしば直観的な）共同体の見方が得られる。

したがって境界にあるDIDは共同体どうしの架け橋であり、そして — 現実の生活とまったく同じように — アマチュアのレベルであれ、あるいは人々をつなぎ危険なDIDについての情報を集約することを専門とする権威のようなプロのレベルであれ、他の共同体のメンバーについての情報を提供する役割を果たす。

DIDネットワークにおけるある種の情報は、無条件の相互交換によく適している（暴力犯罪、詐欺など）。しかし他の種類の情報は、共同体がその内部での使用に制限されるものとして扱いうる（市民権に相当するもの、共同体に提供された奉仕など）。そのような情報が広められうるかどうかは、共同体のメンバーの宣言した方針にかかっている。

共同体は自らの圏内でプライバシーを守り、その見返りに、無条件の基盤の上で相互に有益な情報を交換する。
