# 創発する社会契約 — 方針

これまで私たちは、主張がどう検証されるか、そして各役割がどんな部分を担うかを記述してきた。今度は、何千もの個々の方針がどうやって、現実の社会契約のように機能する何かになるのかに目を向ける。社会契約と強制された連帯という左派の夢に似たものは何一つない。

すべての参加者は、自らの道徳（方針）に基づいて自分自身の方針を宣言する — 何を受け入れ可能とみなすか、そして他者の特定の振る舞いにどう反応するか。あるDID（共同体）が知るネットワーク全体のすべての方針の総体が、創発する倫理 — 誰も設計しなかった観察可能な規範 — を生み出す。これらの創発する規範は、二者間の価格シグナルに支えられて、測定可能な社会契約を形づくる。誰も生まれたときに署名しなかった理論的な構築物ではなく、実際の振る舞いに裏打ちされた経験的に観察可能な規則である。

> [!note] 社会契約
> 人々は「社会契約」が撞着語法ではないかと議論する。誰も何にも署名しないのに、それは中央集権的な社会における立法上・行政上の行動を正当化するために持ち出される。
>
> 分散型ネットワークにおける相互作用の現象学的な分析は、ある種の創発する規則 — グローバルなものやローカルなもの — を明らかにしうる。これら広く共有された規範を私たちは何と呼ぶべきか。社会契約か。共同体と同じように、共同体の社会契約は正確に観察し境界づけることはできない — 共同体に対するあらゆる角度が、異なる社会契約をもたらす。

> [!note] 価値観に基づく方針
> 「価値観に基づく方針」を意思決定の基盤として扱うことも、同じように誤りを招く。価値観は、ある時点で一般に選好される規則の現象学的なクラスターのようなものである。それらは進化し、時とともに一定ではない。
