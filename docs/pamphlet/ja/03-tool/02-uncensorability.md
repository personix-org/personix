# なぜネットワークは検閲不能なのか

これまで私たちはネットワークが何をできるかを記述してきた。今度は、それがなぜ停止させられたり検閲されたりできないのかに焦点を当てよう。

ネットワークはおそらく、Torネットワークとオニオンルーティング（Mixnetの原理を用いてネットワークトラフィックを覆い隠す方法）の原理の上に構築される — 通信が複数の暗号化の層を通過し、いかなる単一のノードも送信者と受信者の両方を同時には知らないという技術である。中央機関はあなたの肩越しにのぞき込むことができない。のぞき込む場所がどこにもないからである。

あなたはそれと戦うことはできるが、勝つことはできない — 国全体を、個々のネットワークパケットのレベルで、そしてインターネットに接続し当該の評判ネットワークで通信するあらゆるハードウェア上の低水準の動作のレベルで、全体主義的な監視へと突き落とさないかぎりは。そしてそれこそが中央集権主義の直面する選択である。市民があなたの手の届かないツールを持つことを受け入れるか、それとも全体主義的統制の名のもとに経済的停滞の暗い片隅へと自らを掘り進めるか。

幻想を抱くのはやめよう — 民主的な体制ですら、中央集権主義のための戦いにおいてこれを試みるだろう。彼らは権力を手放すくらいなら、人々に鎖をかけるほうを選ぶ。
