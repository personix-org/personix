# 自由と全体主義のスイッチ（そして委任）

DIDネットワーク内の単純な仕組みが、システム全体をより大きな自由へ、あるいはより大きな統制へと動かしうる。それは、あるDIDが一定の期間に公開できる記録の数である。記録が希少なままなら、一つひとつが重みを持つ — それが自由である。記録が豊富で些末なことまで覆うなら、それが全体主義である。あなたは公開する記録の一つひとつで方向を選ぶ。ネットワーク自体は自由でも全体主義でもない — それは中立的なインフラである。それが何になるかは、人々がそれをどう使うかによって決まる。

自分自身の検証方針の内部では、私のソーシャルネットワークにおける一般的なDIDに対して — 諸共同体の内部で — 公開者が一定期間に発行できる主張（一般に検証可能なあらゆる言明。ここでは評判ネットワークに公開される記録）の最大数を、私がそれを考慮に入れ、その検証要求を関連あるものとみなすための条件として設定することには意味がある。

私は直観的な数字を念頭に置いている — 年に一桁台の低い数である。そのような検閲的な取り組み方は、いくぶん孤立主義的に見えるかもしれない。だが私は正当に、申請者に選択を迫ることができる。すでに発行した記録の一つを選び、検証者にそれを取り消すよう、すなわち無効にするよう求めよ、と。これは、申請者が偶然にも本当に複数の独立した不正の被害者になってしまった状況では、かなり攻撃的な要求であり、私はそれによってきっと、申請者の共同体からの疎外感に寄与してしまうだろう。

![THE FREEDOM-TOTALITARIANISM SWITCH](../../Info%20Graphics/v5/v5-06-prepinac-svoboda-totalita.webp)

したがってより効果的な選択肢として現れるのは、評判ネットワークに情報を公開する自分の権利の一部を、共同体あるいは権威のために委任できることである。委任された共同体や権威は、その後 — 自らの内部規則に従って連帯的な仕方で — それらをどう配分するかを決める。集団は、自らが不利な立場にあるとみなす者たちの面倒を見られなければならない。共同体のメンバーは、委任された権利が使われるまではいつでも、自らの委任を取り消す権利を持つ。

![DELEGATION OF THE RIGHT TO PUBLISH](../../Info%20Graphics/v5/v5-06c-delegace.webp)

> [!note] 自由対全体主義
> 公開される記録の量を見張り、制限する社会はより自由になる。記録が過剰な社会は全体主義へ傾く。記録を公開する権利を誰か他人に委任することも構想できる。

> [!note] 文化的適応
> 人々はおおむね、互いの皿の中をのぞき込むのを好む。諸文明を通じて、私たちは歴史的経験と人口密度において異なる — したがって、諸文明や諸共同体の内部で、互いの皿の中をどれほど見たがるかにおいても異なる。アジアの国家は社会における自由をより厳格に見る傾向があり、ヨーロッパやアメリカの国家は、ある側面ではより自由に見る傾向がある。この対比がどれほど不正確であろうと、分散型評判ソーシャルネットワークの文脈では、個々の共同体の設定は差別せず、各共同体は自らの内部の通信を思うままに構成できる、と言える。
>
差異にもかかわらず、地球全体で承認される標準は存在するだろう（無差別な殺人は誰の利益にもならない）。他の設定は共同体固有のものとなり、さらに他の設定は個人的に固有のものにさえなる。利点は、相互の通信を通じて、また周囲の設定を観察することによって、コンセンサスを求められることである — 二者間の取り決めから共同体間の取り決めへ、そして時とともに、最もよく構成された共同体の経済的優位のおかげで、グローバルなレベルでさえ求められる。
>
