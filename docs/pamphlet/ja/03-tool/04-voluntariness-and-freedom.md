# 自発性、責任、そして自由

自発性は個人的なものである。私は自分自身で決める。責任は、私の決定が他者に影響を及ぼすときに生じる — フィードバックが働きだす。自由は贈り物でも権利でもない — それは自発性と責任へ向かう圧力とのあいだの何千もの二者間の相互作用を、社会全体で平均した現象学的[^phenomenological]な結果である。ネットワークはこの平均を指図しない — それは検証者の価格シグナルから、そして共同体のメンバーが自らに設定するあらかじめ告知された検証方針から創発する[^emergent]。

共同体の内部の個人がどれほど自由を選好するかは、自分が他者に課すものを、自分自身どれほど飲み込む気があるかという感覚にかかっている。自明で万人に有益なことについては、道徳的なジレンマはない — 殺人は悪い。次に、選択肢が許された特権の位置へと移る場合がある。技能を証明せよ、そうすれば道路に出ることを許そう、そうすればあなたが私たちを殺す可能性が減る、というように。そして最後に、個人がこう言う事柄がある — 私にとっては割に合わない、自分でも落ち葉を燃やすのに隣人にそれを禁じたりはしない、あるいは私自身が相手の快適さを制限する何か別のことをしていて、相手が今度はそれを私に禁じたがるかもしれないからだ、と。私たちが歴史的に、他人の自由が始まるところに自由の境界を引いてきたのなら、分散型アイデンティティの上に築かれた評判ソーシャルネットワークは、中央集権的な代表制民主主義よりもこれをよりよく満たす — 中央集権的な代表制民主主義では、たとえば選ばれた代表者という特権層が、個人的通信の監視から自らを免除しようとしながら、あらゆる陰の口実や操作を用いて、自分たちの有権者にはそれを課すことをためらわない。

[^phenomenological]: **現象学的（phenomenological、ギリシャ語の *phainómenon* — 現れるもの — から）** — 一般的には、諸現象を、その下の微視的世界にあらかじめ与えられた説明理論を用いることなく、それらから何が帰結するかを観察することによって、直接の経験に現れるがままに検討する取り組み方。ここでは、自由は上から定義される抽象的な原理ではなく、観察される現象 — 私たちが実際に互いをどう扱うかから創発する、人々のあいだの何千もの微視的な相互作用の帰結 — である。

[^emergent]: **創発的（emergent、ラテン語の *emergere* — 現れ出る — から）** とは、「誰かが設計したり指図したりすることなく、より単純な部分の相互作用から自発的に生じる」ことを意味する。鳥の群れは、どの鳥も編隊の計画を持たないのに、編隊を組んで飛ぶ — 編隊は各個体の単純な規則から創発する。同様に、評判ネットワークにおいても、全体の行動規則を誰も設計しない — それらは何千もの個々の決定から創発する。
