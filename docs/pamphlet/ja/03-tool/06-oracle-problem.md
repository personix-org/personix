# オラクル問題 — デジタル世界と物理世界を橋渡しする

「オラクル問題」という用語は、近年もっぱら暗号通貨、ブロックチェーン、分散型システムの世界と結びつけられてきた。一般には、デジタルシステムに入ってくるデータが、物理世界で実際に起きたことに忠実に対応することをどう保証するか、という問題である。システム自体は、誰かが本当に誰かに危害を加えたのか、あるいは契約が本当に破られたのかを検証できない — それはデジタルの記録しか見ないからである。

ここでは私たちはこれを権威 — デジタルの記録が物理的な現実に対応することに自らの評判を賭ける主体 — を通じて解決する。権威の評判が高いほど、記録は信頼できる。
