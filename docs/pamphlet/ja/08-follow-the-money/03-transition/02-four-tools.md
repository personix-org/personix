# 互いを支え合う四つのツール

これまでDID評判ネットワークは、主に正義とコンセンサスに役立つように見えたかもしれない。私は、それが自らを安定させ攻撃に耐えられると信じている — 形式的な肩書きではなく実際の功績に基づいて、メリトクラシー的に。だが評判だけでは国家に譲歩を強いることはできない。経済がそれを強い、そしてそれを通じてかけられる圧力が強いる。

私たちが、金に強く圧力をかける追加のツールの管理者としてDIDアイデンティティを使うことを妨げるものは何もない。市民の側の完全な自発性から始めるな — 国家が止められない方向を設定せよ。移行は、互いの背中を支え合う四つの具体的なツールの上に立つ。そのどれも単独では十分ではない。
