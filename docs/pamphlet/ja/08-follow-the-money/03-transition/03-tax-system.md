# 単純な税制 — 入口の誘い

第一のツールは、DIDインフラの上に築かれた単純で透明な税制である。すべての所得に対する単一の比例税率。例外なし、免税期間なし、法人向けの控除なし、優遇措置なし。すべての支払いは、それを支払ったDIDと監査可能な形で結びつく。相互照合は容易である。

税率は、納税者の一部にとって古いシステムよりもいくぶん有利に設定される — それが入口への誘いである。税負担は年を追うごとに下がり、システムはますます魅力的になり、移行は勢いを増していく。システムは同時に記録の保持者であり徴収者でもある — 仲介者なし、不透明さなし。
