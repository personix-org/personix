# Personix — 妥協なき変革

### 検閲不能かつ買収不能な分散型評判ネットワーク

> [!note] 副題の意味
> 四つの言葉が提案の全体を担っている。**検閲不能** — ツールとネットワークは、国家、ISP、あるいはいかなる外部の権威によっても沈黙させられない。それらを検閲するコストは天文学的である。**買収不能** — ネットワーク内部の人間もまた、ひそかに買収されることはない。すべての行為者の振る舞いは、その者が公言した方針と公然と比較可能であり、したがって賄賂は証明可能な矛盾となり、それゆえ評判上の自殺行為となる。**分散型** — 単一のノード、企業、あるいは司法管轄が乗っ取られて全体を崩壊させることはできない。**評判ネットワーク** — そこを流れる価値は、貨幣でも、票でも、許可でもなく、真実を語ることに対して共同体が互いに与え合う、ゆっくりと獲得され失われうる信用である。これら四つの性質が組み合わさって、信頼に対する国家の独占の、実行可能な最小限の後継を描き出す。
