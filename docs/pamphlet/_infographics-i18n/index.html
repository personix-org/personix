Texty (klikni → kresli)

Ovládání

Obdélník: klikni text → táhni rámeček. Posun tažením, rohy zvětší, modré kolečko natočí, Del smaže.

〰️ Cesta (ohýbaný text): přepni nahoře, klikni text vlevo, pak klikej body podél oblouku (3–6 stačí). Enter nebo dvojklik ukončí. Titulek se do toho tvaru vysází.
Tloušťku (výšku písma) měníš ↑↓ u vybrané cesty. Body přetáhneš myší.

Oprava textu rámečku: klikni rámeček → text vlevo → R.
Kopírování ⌘C/⌘V. Ukládá se samo. N/P další/předchozí.
