# Oraakkeliongelma — silta digitaalisen ja fyysisen maailman välillä

Termi ”oraakkeliongelma” on viime aikoina yhdistetty useimmiten kryptovaluuttojen, lohkoketjujen ja hajautettujen järjestelmien maailmaan. Yleisesti: kuinka varmistetaan, että digitaaliseen järjestelmään syötettävä data vastaa uskollisesti sitä, mitä fyysisessä maailmassa todella tapahtui? Järjestelmä itse ei voi todentaa, vahingoittiko joku todella toista, tai rikottiinko sopimusta todella — se näkee vain digitaaliset tietueet.

Tässä ratkaisemme tämän auktoriteettien kautta — tahojen, jotka panttaavat maineensa siihen, että digitaalinen tietue vastaa fyysistä todellisuutta. Mitä korkeampi auktoriteetin maine, sitä uskottavampi tietue.
